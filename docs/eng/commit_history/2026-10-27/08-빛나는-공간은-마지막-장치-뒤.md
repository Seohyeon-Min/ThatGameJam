# Put the Sunlit Rest Area right after the last device (ADR 0006)

## Why

The user said the design doc's Sunlit Rest Area is not a special area. In stage 1 the baby crossed the leaning log and then walked on over more ground to reach it; the user said the stage can just end at a glowing, portal-like spot right after the log, and that future stages should be built with the same idea.

## What changed

| What | Where |
|------|-------|
| Stage 1. The far bank shrank to z 22.5 to 27, and the end of the baby's route moved from z 30 to z 25. The light sits on the route's last point. The camera area shrank to z 0 to 25 | `AgentScripts/BuildSamTestScene.cs` `BuildStage1` |
| Fog scene. It ends right after the 3-2 exit (z 37.5) | Same file, `BuildFogStage` |
| A helper that makes the sunlit spot one narrow pillar of light. It replaces code that was repeated in three places | Same file, `RestLight` |
| Rebuilt both test scenes | `Assets/00_Scenes/Sam_Test.unity`, `Sam_Fog_Test.unity` |
| Decision and rejected alternatives | ADR 0006 |
| Described the Sunlit Rest Area as the end of the route, not a `RestArea` component. The code already worked this way | `implementation_plan.md` 3.1, 3.2, 4.3, 4.6 |

## Verification
