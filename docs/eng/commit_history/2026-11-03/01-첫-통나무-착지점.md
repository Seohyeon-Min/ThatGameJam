# Replace the 4.9 m leap off the end of the first log with a landing point

## Why

The user found it while working out the playtime. On stage 1's baby route in `Main`, the point right after the first log's
`BalanceBeamEnd` (`Point_74`, z 18.1, height 0.28) was the leaning log's `StopPoint` (`Point_75`, z 23.0). `Baby.WakeAndWalk` moves
the segment after a `BalanceBeamEnd` as one `Girl_Jump` (`JumpTo`, 1.5 s), so the baby leapt 4.9 m in one go. The other jumps on the
same route are 0.3 to 1.2 m.

In `Sam_Test` the stop point sits right past the end of the log (z 18), so this segment was short. In `Main` the leaning log was moved
further along, which opened a gap between the end of the log and the stop point.

## What changed

| What | Where |
|------|------|
| If the point after a `BalanceBeamEnd` is farther than 1.2 m, a landing point `<end point name>_Land` goes on the ground 0.4 m past the end of the log toward the next point (0.6, 0.8, 1.0 m if the log still reaches there). Its height is the ground from a ray down on the `Ground` layer with the log left out, or else the terrain. Only this short segment is a jump; she walks the rest | `AgentScripts/FixStage1LogLanding.cs` `Run` |
| An entry point that only reports the length of every jump segment on every route | same file, `Report` |

The other route points, the `BalanceBeamStart`/`End` markers and the `StopPoint` stay as they are. No runtime code changed.

## Verification

Unity could not be run in the session that wrote this record. Below are the commands to run and what to check.

| What | Check |
|------|------|
| `unity command script run --file AgentScripts/FixStage1LogLanding.cs --entry FixStage1LogLanding.Report` (Main, Edit Mode) | Stage1 shows `Point_74->Point_75 4.91 m` |
| same file, `--entry FixStage1LogLanding.Run` | `Point_74_Land` appears; the jump is about 0.4 m, then a walk of about 4.5 m. Main is saved |
| `Report` again | every jump on Stage1 is 1.2 m or less |
| Scene view | the cyan jump arc at the end of the log in the `BabyRoute` gizmo is short, and the landing point is on ground, not water |
| `VerifyStage1Logs.Play`, `Natural` | pass. The baby hops down off the end of the log, then walks and stops in front of the leaning log |
| Console during Play | 0 errors |

## Left

- Whether the landing point is on ground has to be checked by eye in the Scene view. The script measures the ground height but does not tell water from ground.
- `BuildSamTestScene.SetupStage1Logs` was not changed: the `Sam_Test` layout (stop point right past the end of the log) does not have this problem.
