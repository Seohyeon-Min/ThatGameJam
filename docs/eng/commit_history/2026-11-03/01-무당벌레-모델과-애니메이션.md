# Ladybug model with Idle and Crawl animations

## Why

The user wanted a simple ladybug model to use as an interactive creature in the game jam. He asked for it to be made in Blender and exported as FBX, with the Unity import settings and prefab set up too, but no git commit. His conditions were:

- two animations, idle and crawl
- about half the size of a rabbit
- solid-color materials

The `sam` branch has a rule against creating art assets on our own. This model was requested directly by the user.

## Key decisions

- **Size.** The rabbit README puts an adult rabbit's body at about 1.2 m, and the game uses it at scale 1. So the ladybug model itself is about 0.6 m long (about 0.7 m with antennae) and about 0.3 m tall, and the prefab stays at scale 1.
- **Facing and rig.** Like the rabbits, it is exported facing Unity +Z. The rig is Generic with root bone `Root`, and the animations are in place. In Blender the feet are driven by IK. Only the IK result is baked into the FBX, and the non-deforming IK bones are not exported.
- **Crawl.** It uses a tripod gait: front L, mid R and back L step together, alternating with the other three. One cycle is 0.8 s, and a planted foot moves 0.08 m back over 0.4 s. So moving it at **0.2 m/s** keeps the feet from sliding.
- **Materials.** At first I made three `WC_Ladybug*` materials by copying `Pastel/WC_FlowerRed` (SoftPastel) and remapped to them. But the project has not yet settled on one watercolor material for the Main scene (`SoftPastel`, `WatercolorFlat` or `WatercolorLit`). The rabbits and the bird also keep their FBX solid-color materials (URP Lit). So I undid the remap and deleted the three materials. For now it uses the solid-color materials inside the FBX.
