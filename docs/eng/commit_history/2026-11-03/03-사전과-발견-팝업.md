# Encyclopedia, discovery popup, and easter egg list document

## Why

The director's request (`order_from_director.md`) includes an encyclopedia system. It records found interactions, shows a popup when one is found (like a Steam achievement), slides up from the bottom when a key is pressed, and blurs the background behind it. The user asked for it in `Sam_model_test`. Instead of real interactions, clicking a rabbit counts as finding one. The 13 easter eggs in the same file are not to be built yet, only written up as a document.

What the user decided:

- In-game text is English only, with the built-in font (`LegacyRuntime.ttf`)
- Found entries are remembered for one play session only. Nothing is saved
- Entries not found yet show `???`
- Each click on the rabbit finds the next entry not found yet
- The blur uses URP depth of field
- The key is `` ` `` instead of ESC. The source says ESC, but Main's intro and cutscene use ESC to skip in development builds
- The game pauses while the encyclopedia is open. Background sound may keep playing; sound effects must not play
- The 13 slots keep the director's list as it is

## Key decisions

- **Stopping sound effects.** The FMOD project has only the Master bus, so there is no bus to stop just the effects. The current effects (footsteps, wing flaps) come from animation events, so they stop with `timeScale` 0. The other one, the right-click cry, is blocked in `SoundManager`. Wind and music keep playing. If effects that play regardless of time appear later, an SFX bus in FMOD that is paused would be better.
- **Entries as assets.** When real interactions exist, their components reference the entry asset directly and call `Discover`. No lookup by number or name string.
- **No runtime creation.** Slots, popup and Volume are saved in the prefab by the builder. At runtime only text, colour, position and weight change.
- **Text size.** In the first slots (300 × 190) long titles were cut off. Slots are now 310 × 230 with Best Fit on title and description.

## Cross-model review

GPT-6.1 Sol. Lenses: correctness, security, robustness (including `timeScale` and static state). Three reviews of the C# changes.

| Severity | Finding | Resolution |
|------|------|------|
| warn | Passing an entry not in the list, or null, to `Discover` throws and pollutes the found set (all three times) | **Dismissed.** Entries are references set in the editor. A wrong one should throw visibly. The project avoids excessive defensive code |
| warn | If another component calls `Discover` before `Start`, `Start` overwrites the slots as not found | **Fixed.** `Start` and `Discover` both draw slots and the count from the found set through `ShowCard` |
| warn | Disabling the component while open leaves the page and blur on screen | **Dismissed.** The page and Volume are under the same root, so disabling the root turns them off too. Nothing disables the component alone. A fix was tried and reverted because it called a child's `SetActive` while the parent was being deactivated |
| warn | Five columns overflow on narrow screens | **Fixed.** CanvasScaler is now Expand, so the 1920 × 1080 layout fits at any aspect ratio |
| warn | `IsOpen` turns false as closing starts, so input gets through while the page slides down | **Dismissed.** Intended. Time resumes the moment it closes, and input comes back with it |
