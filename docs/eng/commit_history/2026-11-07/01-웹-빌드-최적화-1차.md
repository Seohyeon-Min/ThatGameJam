# Web build optimization, first pass: Web on the PC quality level, smaller download (ADR 0037)

## Why

The director asked for Web build optimization. Three read-only audits (assets, rendering, scripts) ran, and the user asked for step 1 (decide the renderer the Web uses) and step 2 (settings-only size cuts) first. Step B, cutting frame hitches, is for the next session.

## What changed

| What | Where |
|------|-------|
| WebGL default quality level Mobile → PC, and the Editor on PC | `ProjectSettings/QualitySettings.asset` |
| PC renderer: Forward+ → Forward, SSAO off, depth prepass forced (`OcclusionFade` uses it) | `Assets/Settings/PC_Renderer.asset` |
| PC RP asset: Opaque Texture off, shadows 2048 · 2 cascades · 40 m · Soft Medium | `Assets/Settings/PC_RPAsset.asset` |
| Copied `ForestMist`, `DreamFog`, `AboveFog`, `BabyPrism`, only on PC before, to the Mobile renderer, with the PC layer masks. Unused now | `Assets/Settings/Mobile_Renderer.asset`, `AgentScripts/SyncWebRenderer.cs` |
| Lowered the WebGL max size of 18 textures (girl, icy trees, flowers, grass, berries, `fox_temp`, `EncyclopediaBase`). Sources and other platforms unchanged | each `.png.meta`, `AgentScripts/ApplyWebImportSettings.cs` |
| Animation compression Off → Optimal on the Rabbit, BabyRabbit, Bird and Squirrel FBXs | each `.fbx.meta` |
| WebGL: Managed Stripping Minimal → High (`Assets/link.xml` keeps `Assembly-CSharp` and `FMODUnity`), IL2CPP OptimizeSpeed → OptimizeSize, Strip Unused Mesh Components on, splash off. ## Key decisions

- The Web uses the single `PC` quality level. `Mobile` was set up as the Web renderer first, but the shadows got much worse, so it changed. [ADR 0037](../../decisions/0037-web-build-uses-the-pc-quality-level-and-vorbis-for-long-music.md).
- Only the long music is Vorbis; short effects stay PCM (user's decision). This keeps JU's reason for PCM.

## Verification

| What | Result |
|------|--------|
| WebGL build (`BuildPipeline.BuildPlayer`, Release) | Succeeded, 0 errors. Total 33.4 MB: data 12.4 MB (16.8 in the 11-03 build), wasm 6.5 MB (9.7), `Master.bank` 13.9 MB |
| Browser play (user, local server adding the Brotli headers) | Fog and shadows fine. Sound stutters at game start, the clouds, season changes, early fog and the ending. After the larger DSP buffer the stutter lasts longer |
| Editor console | 0 compile errors |
| Texture and clip sizes (Editor) | `fox_temp` 512 DXT5, girl head 512 DXT1, Rabbit clips 16.5 MB → 2.5 MB. `EncyclopediaBase` stays 1024x579 RGBA32 (not a multiple of 4, so no block compression) |

Found while building: FMOD has two `event:/Ambience/water` events (JU, `2f54b8c`). FMOD Unity's bank refresh fails in its event cache, so `Assets/StreamingAssets/Master.bank` was never copied, and this PC's Web builds carried the 11-02 bank. This time the new bank was copied by hand (git does not track that file).
