# Leave the player's bird out of encyclopedia photos, and photograph the ladybug after one second of crawling

## Why

The user asked for it. The flower in the snow was photographed right where the bird had pecked, so the bird covered the flower in the encyclopedia photo. Except for the migrating birds, photos are taken without the bird. The stump ladybug took too long before its photo. The crawl is shortened so the photo comes about one second after it crawls out.

## What changed

| What | Where |
|------|-------|
| `Discover` takes `showBird`. When off, the bird's renderers are turned off with `forceRenderingOff` only while that one photo renders. The render request draws right away, so the game view is not affected | `Assets/02_Scripts/Encyclopedia/Encyclopedia.cs` |
| `Discovery.showBird` (off by default) | `Assets/02_Scripts/EasterEggs/Discovery.cs` |
| Migrating birds and the cliff echo (a photo of the bird) have `showBird` on | `Assets/03_Prefabs/EasterEggs/MigratingBirds.prefab`, `CliffEcho.prefab` |
| `CrawlTo` pulled back along the same line, to `crawlSpeed × ladybug scale × 1 s`. Prefab 1.03 → 0.10 m, the scene's `broken tree/Tube 1` 0.75 → 0.14 m | `Assets/03_Prefabs/EasterEggs/StumpLadybug.prefab`, `Assets/00_Scenes/Main.unity` |
| A line saying the photo leaves the bird out | `docs/kor/easter_eggs.md` |

Saving Main changed the fileIDs of meshes stored in the scene and wrote `clickedThrough: []` and `showBird: 0`. The only changed value is `Tube 1`'s `CrawlTo`.

## Verification

| What | Result |
|------|--------|
| Play Mode, Main. Bird placed over the flower in the snow, `Discover` called with `showBird` on and off, photos saved as PNG | On: the bird covers almost the whole picture. Off: only the snow pile, no bird and no bird shadow. All bird renderers were back on afterwards |
| Distance / speed for both ladybugs | 1.00 s each |
| Cross review (gpt-6.1-sol) | 2 warns |

## Review

- Renderers whose `forceRenderingOff` was already on are set back to off → not changed. This is the only code that sets `forceRenderingOff` on the bird's renderers (`HiddenUntilSeason` is not on the bird).
- If the render request throws, the bird stays hidden → not changed. No such failure has been seen, and code for failures that have not happened is not added in advance.
