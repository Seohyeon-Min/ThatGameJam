# Web build optimisation, part 2: season change spread over frames, ring cache, merged flower and grass meshes (ADR 0039)

## Why

In the web build the sound breaks up at the game start, the clouds, each season change, the start of the fog and the ending. FMOD mixes on the main thread, so when a frame stalls the sound stalls too. This is stage B of `order_from_director.md` (cut the stalls). The user answered questions 1 to 4: measure with Autoconnect Profiler; merge meshes on `sam`; bake the textures in a separate commit; leave the fog, whose look must not change.

## Key decisions

- [ADR 0039](../../decisions/0039-web-build-frame-stalls-reduction.md): spreading, the ring cache, which prefabs to merge and why not the leaf cards, what was not done (fog, snow, clouds).
- The largest stall measured was first shader use (up to about 690 ms a frame). Not in this scope; listed as remaining.
- The scene (`Main.unity`) was not saved: the Editor re-sorts the merge-script-written scene on save and about 1.66 million lines change. All changes went into prefabs and assets.

## Cross-model review

GPT-6.1 Sol. Two lenses: correctness and robustness; look/behaviour preservation and performance.

| Finding | Resolution |
|---------|------------|
| warn. NRE on a season change in a scene without the baby | **Fixed.** Without the baby the generator's position is the centre |
| warn. Grid blending: one missed corner hides the point, and it floats or sinks at steps (both lenses) | **Fixed.** Blends only when all four corners hit within 0.1 m; otherwise raycasts at the point |
| warn. A per-frame number alone may lag the ring at a low frame rate (trees, flowers/grass) | **Fixed.** Within the ring radius + 2 m they change that frame, past the number |
| warn. Four-argument `Mathf.Max/Min` allocates a params array (confirmation review) | **Fixed.** Nested two-argument calls |
| warn. 3D distance from the baby compared with the ring radius (a ground distance) (confirmation review) | **Fixed.** Compared in XZ (`TreeGenerator.FlatDistance`) |
| warn. Blending misses holes or bumps smaller than a 0.3 m cell (confirmation review) | **Rejected.** The old code also cast only every 0.3 m around the ring; same spacing |
| warn. A change with no photo (no SeasonWipeFeature, etc.) shows trees changing over several frames (final review) | **Rejected.** The game's renderer has SeasonWipeFeature (ADR 0037). Without it, it still ends within about 0.2 s |
| warn. Merged flowers' pencil strokes change length | **Rejected.** The shader shortens strokes by renderer bounds and the flowers are small on screen. ADR 0039 alternative 3. The user checks in play |

After the fixes, the final review's only finding was the no-photo one, rejected.

## Remaining

- First-use shader stalls. The shader variants the web player uses must be collected (`GraphicsStateCollection` or ShaderVariantCollection) and built during loading. The Editor's variant tracking doesn't count variants already cached, so it couldn't be used.
- Fog (half resolution, fewer steps, fewer planes). Not done because its look would change.
- Intro cloud puff count: its look would change. The snow area was already fitted in ADR 0024.
- Merging leaf cards: needs shader and bake tool changes.
- In the web build `event:/Ambience/water` and `event:/Ambience/birdsTweeting` are not found (`EventNotFoundException`). Suspected cause: they are looked up before the web build's asynchronous bank load finishes. Not confirmed.
- In the web build `OnTriggerEnter2D`/`OnTriggerExit2D` script errors appeared 8 times, probably from removing physics2d in part 1. Not confirmed.
