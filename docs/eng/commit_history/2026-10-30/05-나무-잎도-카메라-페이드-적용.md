# Made tree leaves fade with the camera too, like the trunks already do

## Why

Repo owner's request: "the leaves of the inner trees should also become transparent when they overlap the camera." Tree trunks already dissolve when blocking the view between the camera and a character (`WatercolorFlat`'s `_CameraFade`), but leaves didn't get that effect.

## Why it wasn't applied

The material used by the `Leaves` nodes on the `Tree_1~4_Leafy` prefabs (`Assets/01_Arts/Materials/Test/TreeLeaves_1~4.mat`) was never actually the `ThatGameJam/WatercolorFlat` shader — it was the default **URP Lit** shader. The folder name (`Materials/Test`) suggests it was always a placeholder. Trunks (`Trunk`/`Branch`/`TrunkTop`) use a baked `..._watercolor.mat` per tree and got the fade correctly; the leaf material was on a different shader entirely, so it never even had a `_CameraFade` property to begin with.

## What changed

| What | Where |
|------|-------|
| Switched the shader on all four `TreeLeaves_1~4.mat` from URP Lit to `ThatGameJam/WatercolorFlat`, keeping each tree's existing flat green/yellow/teal base color. Set `_HasPattern=0` (leaves have no baked 3D pattern like the trunks do, so flat color only), `_CameraFade=1`, same distance/range as the trunks (2 / 1.5) | `Assets/01_Arts/Materials/Test/TreeLeaves_1.mat` through `TreeLeaves_4.mat` |

## Key decisions

- The leaf mesh itself is a sphere-primitive placeholder blob, so the art still looks like a WIP asset. Left the mesh and textures untouched and fixed only the shader/property gap the request was actually about.
- Did not turn on `_HasPattern`. The trunk's baked pattern (`Pattern.asset`/`Chaos.asset`) uses per-vertex UV3 coordinates baked specifically for that trunk mesh; applying it to the leaf spheres would map incorrectly. Went with flat color plus the base watercolor shading (paper/shadow/outline) only, which the shader's own comment says is exactly what `_HasPattern` off is for.

## Verification

| What | Result |
|------|--------|
| Console after switching the materials' shaders | `console status` → `compilationFailed: false`, `consoleErrors: 0` |
| `material get_properties` on all four materials | Confirmed `shader: ThatGameJam/WatercolorFlat`, `_HasPattern: 0`, `_CameraFade: 1` |
| In Play Mode, found a leaf renderer, framed the camera directly on the line between it and the baby (set while paused), and captured it | The same dithered-noise dissolve pattern that the trunks show appeared across the leaf blob's surface — confirmed the fade is actually applied, by eye |
| `git status` | Only the four materials changed; scene and prefabs untouched (they reference the materials by guid, nothing else needed updating) |

## Remaining

- The leaf mesh is still a sphere placeholder; once real leaf art arrives, this material setup (`_HasPattern` in particular) may need revisiting.
