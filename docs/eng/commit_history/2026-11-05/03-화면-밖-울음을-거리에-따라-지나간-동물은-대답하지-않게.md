# The off-screen cry by distance, and a passed animal doesn't answer (ADR 0032)

## Why

The user's feedback after ADR 0031. An off-screen animal's cry always showed half and at one size, whatever the distance. Crying past the first animal, the first animal still answered. The cause and the decision are in [ADR 0032](../../decisions/0032-off-screen-cry-by-distance-and-passed-animals-dont-answer.md).

## What changed

| What | Where |
|------|------|
| `AnswerAhead`: the first animal ahead of the bird in Z answers. The dead-end rule, `animalAt`, `wayStart` and `AllWays` are gone | `FogMaze.cs` |
| The off-screen cry's size and the width that shows follow the distance to the bird. It goes to the screen's rectangle moved in, so it stays continuous at the corners | `FogForkAnimal.cs` `PlaceCry` |
| `ringRadius` 1.8, `nearDistance` 25, `farDistance` 70, `nearShown` 2/3, `farShown` 0.2, `farScale` 0.4, `edgeDepth` 4 | `FogForkAnimal.prefab` |
| 4.12 | `docs/kor/implementation_plan.md`, `docs/eng/implementation_plan.md` |

The values the new fields got when first added stayed on the instances in the Editor's memory, so changing the code defaults did not reach Play Mode. So the values were written on the prefab asset and saved.
