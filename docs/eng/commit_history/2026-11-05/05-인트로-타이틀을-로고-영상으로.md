# The intro title's grey box becomes the logo video

## Why

The director's request (`order_from_director.md` item 1). Remove the grey title box in the intro (the first scene, the bird flying above the clouds) and play the game's logo video `primavis_anim.webm`.

## What changed

| What | Where |
|------|------|
| The logo video. The Web build can only play a video from a URL, not a VideoClip asset, so it is in StreamingAssets | `Assets/StreamingAssets/primavis_anim.webm` |
| `IntroCanvas/Title`: the grey `Image` removed; `RawImage`, `AspectRatioFitter` (16:9 inside the screen), `VideoPlayer` (URL, render texture, no audio, no loop) and `StreamingVideo` added. `IntroSequence.title` points at the new `RawImage`. Its fade and hiding are unchanged | `Main.unity` |
| Sets the StreamingAssets URL when it turns on, and plays. The URL is only known at run time. The render texture keeps its last picture, so it is cleared to transparent before playing | `Assets/02_Scripts/Flow/StreamingVideo.cs` |
| The 1920×1080 render texture the video draws into | `Assets/01_Arts/Video/TitleLogo.renderTexture` |
| Builder for the above | `AgentScripts/SetupTitleVideo.cs` |

## Decisions

- The first video was VP9. Unity decodes only VP8 webm itself, so the Editor reported `Unsupported video codec 'VP9'`. The director re-encoded it as VP8 with alpha (a VP8 in between had no alpha, and its background was black).
- It fills the screen at 16:9, since the video is laid out as a 1920×1080 screen. It plays once.

## Verification

| What | Result |
|------|------|
| Play Mode, captures after the intro starts | The "primavis" logo appears over the clouds with a transparent background. 0 console errors |
| Before and after clearing the render texture | Before, the previous Play's black-background frame showed for about 3 s. After, nothing shows until the first frame |

Not checked in a Web build. Safari may not support webm alpha.
