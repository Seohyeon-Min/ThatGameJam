# The bird perches on roadside tree branches and, idle for 2 s, goes to the nearest one (ADR 0009)

## Why

The director reversed Q7 (roadside trees as decoration only). Every tree has a branch and a perch point to land on. If the player does nothing and the bird stays still for 2 seconds, the bird goes to the nearest branch and perches. Clicking also perches it.

## What changed

| What | Where |
|------|-------|
| Every one of the 8 tree prefabs has a perch branch (`PerchBranch`, nearly level, 1.8 long, from height 2.6) and a perch point (`PerchPoint`) with a `Perchable` (an idle spot) and a trigger sphere of radius 0.6 on the `Interactable` layer | `AgentScripts/BuildSamTestScene.cs`, `Assets/03_Prefabs/Trees/` |
| `Perchable` gets an idle-spot flag (`idleSpot`) and a list of all perchables | `Assets/02_Scripts/Core/Perchable.cs` |

| Two ranges: where it flies (road and screen) and where it perches (screen). Clicked perches and staying perched also use the screen range. Flying moves toward the clamped target, so taking off from an off-road branch glides back onto the road (before, it jumped) | `BirdController.cs`, `Assets/02_Scripts/Flow/BirdCamera.cs` |
| Wait time `birdIdlePerchDelay` = 2 | `Assets/02_Scripts/Core/GameTuning.cs` |
| Rebuilt `Sam_Test` only | `Assets/00_Scenes/Sam_Test.unity` |
| The decision and rejected alternatives | ADR 0009 |

## Key decisions

- The bird never lands on a device such as the log by itself. If it solved a device alone, there would be nothing left for the player to help with
- The road range is not widened; only perching works anywhere on screen. The bird still flies on the road (ADR 0007)
- `GameTuning.asset` is unchanged; the new value is read with the code default (2)
- The fog map (`Sam_Fog_Test.unity`) was neither rebuilt nor tested. The changed code is used there too

## Verification

By script in Play Mode. Not with a real mouse.

| What | Result |
|------|--------|
| Do nothing after start | The bird went from (1.5, 2.5, -1) to the nearest branch (3.2 away) and perched |
| While perched, click another branch on screen (`Click` via reflection, with the same raycast as in play) | It went to that branch (off the road, x 7.68) and perched |
| From an off-road branch, click the ground at (0, 4) | It flew onto the road and hovered at (0, 2.5, 4). 2 s later it went to the nearest branch and perched |
| 57 perches registered (56 trees + the log) | It never perched on the log by itself |
| Console | 0 errors, 0 warnings |

The virtual mouse did not work this time. Clicks went to the wrong place, and the virtual mouse's position read from another script call was always (0, 0). So the click handling was checked by calling `Click` directly. The Input System settings and the virtual device changed for the test were restored.

When testing started, the editor was in Play Mode (apparently the user's run). Recompiling the scripts made `DevTools` throw null exceptions in that session. Play Mode was stopped before going on.
