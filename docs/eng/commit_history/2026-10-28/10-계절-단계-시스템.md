# Season level system and a debug red tint

## Why

The director asked for it (Season Transition System). A common system raises the season level when the baby falls asleep at a sunlit spot. Functions and events such as `AdvanceSeason()` and `OnSeasonChanged(int stage)` let VFX and environment assets hook on later. There are no assets yet, so no real environment change is made. Changing the level and firing the event must be testable from the Inspector. As a debug aid the surroundings turn red, removable later.

## What changed

| What | Where |
|------|-------|
| `Season`: a level (from 0), `AdvanceSeason()`, `SetSeason(int)`, and an Inspector-connectable `OnSeasonChanged(int)` event, raised once at the start and on every change | `Assets/02_Scripts/Flow/Season.cs` (new file) |
| Inspector buttons "Advance Season" and "Apply Level" (applies the typed level and raises the event). Play Mode only | `Assets/02_Scripts/Flow/Editor/SeasonEditor.cs` (new file) |
| Debug-only `SeasonDebugTint`: per level, every renderer but the baby's and the bird's goes redder (strongest at level 4). Tinted through property blocks, so no material changes. Disabling or deleting it restores them | `Assets/02_Scripts/Flow/SeasonDebugTint.cs` (new file) |
| The season advances when a stage ends (asleep, or the dev skip). Stage ends after the last stage are ignored. The per-stage `seasonEffect` event is replaced by this and deleted | `Assets/02_Scripts/Flow/GameFlow.cs`, `Assets/02_Scripts/Flow/Stage.cs` |
| Builder: `Season` on the `GameFlow` object, and a separate `SeasonDebugTint` object. Deleting that object drops the debug tint | `AgentScripts/BuildSamTestScene.cs`, `Assets/00_Scenes/Sam_Test.unity` |
| The dev "Next stage" description | `Assets/02_Scripts/Flow/DevTools.cs` |
| The season system | `implementation_plan.md` 3.1, 4.6, 4.15, 6.1 |

## Verification

Done in Play Mode with scripts and a screen capture.

| What | Result |
|------|--------|
| `script recompile`, builder `Build` | 0 errors and warnings |
| Start | Level 0, no tint |
| Dev skip twice | Level 1 (ground light pink), level 2 (redder). The bird and the baby are not tinted |
| `SetSeason(0)`, `SetSeason(4)` | The tint went away, then the deepest red |
| `SeasonDebugTint` disabled, then enabled | The tint went away, then came back at the current level |
| More dev skips after the last stage | The level stays at 2 |
| Screen | Ground, trees, the log, and the sunlit spot red; the bird unchanged |

The Inspector buttons were not clicked by hand. The same functions were called from a script.

## Cross-model review

Codex. Correctness (when the season rises, tinting and restoring), security, and robustness lenses. Scope: the diff of `Assets/02_Scripts` and the builder.

| Finding | Resolution |
|---------|------------|
| blocker. This Unity has no parameterless `FindObjectsByType<T>()`, so it does not compile | Dismissed. 6000.4 has it and it compiles with 0 warnings. It was the `FindObjectsSortMode` overload that warned as deprecated, which is why it was changed |
| warn. `Sam_Fog_Test`'s `GameFlow` has no `Season`, so a stage end throws | Dismissed. The fog map is not rebuilt, by the user's instruction. Its baby is the old capsule, so that scene already does not work |
| warn. After the last stage, each dev skip still raises the season | Fixed. Once the last stage has ended, later stage ends are ignored. Three skips stayed at level 2 |
| warn. It overwrites and clears other systems' property blocks | Dismissed. Nothing uses property blocks now, and the tint is debug-only |
| warn. Disabled and re-enabled, the tint does not come back until the next change | Fixed. Enabling re-tints at the current level. Checked by toggling it |
| nit. Advancing from `int`'s maximum overflows | Dismissed. Not reachable in practice |

The confirmation review after the fixes returned `LGTM - no blockers`.
