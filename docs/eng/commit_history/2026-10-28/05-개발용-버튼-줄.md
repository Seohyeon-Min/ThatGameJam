# Dev tools become a button row at the top of the screen; time scale cycles 1x, 2x, 3x

## Why

The director asked for it (Stage Debug Controls). The current dev tools (F1 to F4) should work as buttons inside the game screen. The time scale changes to X1, X2, X3 on each press. The buttons sit at the top of the screen, and hovering one shows what it does.

## What changed

| What | Where |
|------|-------|
| Four buttons at the top centre: time scale (`x1` → `x2` → `x3` → `x1`), `Natural` (resolve on its own), `By bird` (resolve as if the bird did it), `Next stage`. Hovering shows a description under the buttons. The baby state and timer line moved under the buttons | `Assets/02_Scripts/Flow/DevTools.cs` |
| F1 to F4 stay. They do the same as the buttons. F1 also cycles 1x, 2x, 3x | `DevTools.cs` |
| A left click on the button row does not move the bird | `Assets/02_Scripts/Bird/BirdController.cs` |
| The time scale and dev tool sentences | `implementation_plan.md` 4.18, 6.1 |

## Important decisions

- Drawn with IMGUI (`OnGUI`). `DevTools` already drew its status with `OnGUI`. The tool is on only in development builds, so no Canvas, EventSystem, or font asset was added
- The text is English. The built-in font has no Korean, so Korean would not show in a web build
- The keyboard shortcuts were kept. The director asked for buttons, not for removing the keys
