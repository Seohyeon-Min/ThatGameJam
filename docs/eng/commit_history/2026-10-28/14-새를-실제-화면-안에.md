# Keep the bird inside the actual screen; the camera zone unlocks near the map's edge (ADR 0015)

## Why

The user wanted the camera lock to feel clearer, and chose to lengthen the unlock distance so it unlocks almost at the map's edge. But the check keeping the bird on screen was a fixed box (x ±6, z ±5) around the camera's point, so while locked the bird could not leave it. A lock area larger than that would never unlock. The actual screen in the quarter view is a slanted four-sided patch and showed over 20 m on the far side.

## What changed

| What | Where |
|------|-------|
| The bird's screen check uses the actual screen. The four corners 8% in from the screen's edges are cast onto the flying-height plane to make a quad, which is clipped by the fly area into the polygon where they overlap. A target outside it moves to the nearest point on its edges | `Assets/02_Scripts/Bird/BirdController.cs` (`Limit`, `ClipToArea`) |
| Branches it may perch on: the perch point is turned into screen coordinates and checked against the edges. The area's front and back ends still apply | `BirdController.cs` (`OnScreen`) |
| The fixed box (`birdRange`) is gone. `BirdCamera` passes only the fly area | `Assets/02_Scripts/Flow/BirdCamera.cs` |
| The log's camera zone: lock area x ±10, z 10 to 24; camera area 3 × 1 (centred at z 17) | `AgentScripts/BuildSamTestScene.cs`, `Assets/00_Scenes/Sam_Test.unity` |
| The decision and dropped alternatives | ADR 0015 |
| Bird movement, camera | `implementation_plan.md` 3.1, 4.1, 4.7, 6.1 |

## Verification

Done in Play Mode with scripts.

| What | Result |
|------|--------|
| `script recompile`, builder `Build` | 0 errors |
| Locked, then far right (+X, camera side) | Reached x 13 (the area's edge), unlocked |
| Locked, then far left (−X) | Perched on a branch at x −13.9, unlocked |
| Locked, then back (z 0) | Reached z 0, unlocked |
| Locked, then ahead (z 40) | Stopped at z 25 (the sunlit spot), unlocked |
| Locked, then the camera-side corner (30, 0) | Reached (11.4, 1.6), unlocked |
| Click past the sunlit spot (z 27) | Landed on a branch, `Refuse` |
| Console | 0 errors and warnings |

At first the clamp was done in screen coordinates. With a target at the camera-side map corner (13, 0), the bird flew to the far side of the map (towards z 36). That point was behind the camera's near plane, so its screen coordinates were mirrored. It now casts the screen's four corners to the flying height and clamps in the world.
