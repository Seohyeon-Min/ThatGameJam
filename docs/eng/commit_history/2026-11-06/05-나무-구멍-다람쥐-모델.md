# Put the squirrel model into the tree-hollow squirrel

## Why

User request. The user put a squirrel model (`SquirrelUnity-Animations-*.zip`, Generic rig, clips `Hop`, `SitIdle`, `SitIdle_LookAround`) in the project folder. It replaces the placeholder capsule in `HollowSquirrel`.

## What changed

| What | Where |
|------|-------|
| Brings in the FBX with the `.meta` from the zip's unitypackage (clip names, loops), the README, the clip json and the validation result. Builds an Animator Controller with one state per clip (default `SitIdle_LookAround`) and a prefab | `AgentScripts/SetupSquirrelModel.cs`, `Assets/01_Arts/Models/Squirrel/`, `Assets/03_Prefabs/Squirrel.prefab` |
| Removed the capsule and put in `Squirrel.prefab` at scale 0.35 (sitting height about 0.24 m) | `Squirrel` in `HollowSquirrel.prefab` |

The tree is turned 180° so the hollow faces the prefab's -Z. So the placement in `Main` (-45°, toward the camera) stays as it is | `thickTree` in `HollowSquirrel.prefab` |
