# Add a test bird, child, obstacles, and quarter-view camera in the `Sam_Test` scene

## Why

To check the core loop right away: the bird clears an obstacle, then the child moves on. The bird flies freely, including height, with WASD + wheel + E. The child walks a straight road. Work happens in a personal test scene instead of `Main.unity`.

## What changed

| What | Where |
|------|-------|
| Bird: WASD moves relative to the camera, the wheel changes height by 0.5, E clears the nearest obstacle within radius 1.5. Input actions are created in code, so the shared `InputSystem_Actions.inputactions` is unchanged | `Assets/02_Scripts/BirdController.cs` |
| Child: walks straight to the goal and stops when an `Obstacle` is ahead | `Assets/02_Scripts/ChildWalker.cs` |
| Obstacle: `Clear()` deactivates it | `Assets/02_Scripts/Obstacle.cs` |
| Fixed-angle quarter-view camera that follows the bird | `Assets/02_Scripts/QuarterViewCamera.cs` |
| Scene builder. It is outside `Assets`, so it is not compiled as game code. Running it again rebuilds the scene | `AgentScripts/BuildSamTestScene.cs` |
| Test scene: snow, straight road, two obstacles (z=6, 14), goal (z=24), child, bird | `Assets/00_Scenes/Sam_Test.unity` |
| Six temporary materials (URP Lit) | `Assets/01_Arts/Materials/Test/` |
| Pipeline project settings (defaults) | `ProjectSettings/Packages/com.unity.pipeline/EditorPipelineConfig.json` |

## Cross-model review

Codex. Correctness, security, and robustness lenses. Context given: Unity 6000.4, Input System only, WebGL target. Scope: staged diff of the five `.cs` files.

No findings. The result was `LGTM - no blockers`.

## Problems hit

- When the Editor window is not focused, the Input System disables the real keyboard (`backgroundBehavior = ResetAndDisableNonBackgroundDevices`). Queued state events did nothing. For the test only, the setting was changed and virtual devices (`InputSystem.AddDevice`) were used. Afterwards the devices were removed and the setting restored
- The installed Pipeline's command names differ from the skill docs. `editor_status` is `editor status`, and `set_autotick` is `editor set_auto_tick`
- `capture game_view --save_path Temp/...` saves into `Assets/Temp/`. The file was moved out and removed right away
