# Roadside tree prefab and perching on branches

## Why

The director wants trees placed on both sides of the road, and the bird should be able to sit on them. The user decided how it works.

- Press E near a branch that reaches toward the road to perch
- While perched, any WASD or wheel input takes off right away
- The perch range is a sphere of radius 1.0, twice the bird's 0.5 diameter
- E acts on whichever is nearer, a perch point or an obstacle. While perched, E does nothing
- The bird flies to the perch over 0.2 seconds
- Branch direction is set by rotating the tree when placing it
- A modest indicator shows when the bird is in range

## What changed

| What | Where |
|------|-------|
| Split the bird's state into flying, landing, and perched. While perched it is held with `isKinematic`. Taking off restarts from the current height | `Assets/02_Scripts/BirdController.cs` |
| Perch point. Enabled points register in a static list. When the bird is in range, the indicator (a yellow sphere) pulses in size | `Assets/02_Scripts/PerchPoint.cs` |
| Tree prefab: trunk (with collider), crown, one branch along local +Z, and a perch point at the branch tip. Crown and branch have no colliders | `Assets/03_Prefabs/Tree.prefab` |
| The builder creates the prefab and places six trees on both sides of the road at z=3, 10, 17, with branches facing the road | `AgentScripts/BuildSamTestScene.cs`, `Assets/00_Scenes/Sam_Test.unity` |
| Three temporary materials. The indicator uses URP Unlit | `Assets/01_Arts/Materials/Test/Trunk.mat`, `Leaves.mat`, `PerchIndicator.mat` |
