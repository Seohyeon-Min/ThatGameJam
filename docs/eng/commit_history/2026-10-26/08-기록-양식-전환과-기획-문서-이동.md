# Rewrite the records in the `record-format-example.md` format and move the design doc into `docs/`

## Why

The user added `docs/record-format-example.md` and asked to convert the existing records to that format. The user also asked to move `rough_game_design.md` into `docs/`.

## What changed

| What | Where |
|------|-------|
| Split the single session file into eight per-commit files | `docs/*/commit_history/2026-10-26/` |
| Replaced the dated decision files and `INDEX.md` with numbered ADRs 0001-0006. Sections: Context / Decision / Alternatives / Consequences | `docs/*/decisions/` |
| Added the READMEs from the format example | `docs/*/commit_history/README.md`, `docs/*/decisions/README.md` |
| Moved the original design doc (English) | `docs/eng/rough_game_design.md` |
| Korean translation of the design doc | `docs/kor/rough_game_design.md` |

## Key decisions

- The format example file is not mirrored. User instruction
- The design doc's original is English. It should be mirrored like other documents, so a Korean translation went into `kor`, and the original stays unchanged in `eng`
- The ADR 0006 of that time changed ADR 0001. Following the format rules, 0001 was not edited; 0006 linked 0001 under `Related:`. [09](09-결정-기록-정리.md) later deleted 0001 and renumbered 0006 to 0002
