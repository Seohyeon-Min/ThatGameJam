# 이스터에그 (자잘한 상호작용)

> 원본: 프로젝트 루트의 `order_from_director.md` (디렉터 지시). 2026-11-06 에 디렉터가 이 파일 끝에 거의 확정된 기획을 적었고, 이 파일은 그것을 기준으로 다시 정리했다. 그 전 목록(13개, 언 강물과 산천어, 호랑나비 포함)은 git 기록에 있다.
> 영어판: [`../eng/easter_eggs.md`](../eng/easter_eggs.md)
> 상태: 물웅덩이를 뺀 모두를 프리팹으로 만들어 `Main` 의 인트로 출발점 뒤(−Z) 공터에 두었다 ([ADR 0034](decisions/0034-이스터에그를-인트로-뒤-공터에-프리팹으로.md)). 스테이지 안의 자리는 아직 정하지 않았다.

찾은 이스터에그는 사전(Encyclopedia)에 기록된다. 이스터에그가 나타나면 게임이 그 순간 대상을 가까이 찍어 사진으로 넣는다. 유저가 누른 순간이 아니다. 사진에는 플레이어 새를 빼고 찍는다. 새가 대상을 가리지 않게 하기 위해서다. 새가 나와야 하는 철새와 절벽 메아리만 `Discovery` 의 `showBird` 를 켰다. 사전은 `` ` `` 키로 연다 (원본은 ESC 였으나 사용자가 바꿨다).

## 1. 배치 (디렉터 기획)

| 스테이지 | 이스터에그 |
|---|---|
| 인트로 | 새에 쌓이는 눈 (항상 있는 기믹이지만 눈이 내리는 인트로에서만 보인다) |
| 스테이지 1 | 그루터기 무당벌레, 눈 회오리, 눈 속의 꽃 |
| 스테이지 2 | 고드름 실로폰, 나무 구멍 다람쥐, 산수유 열매 |
| 스테이지 3 | 낭떠러지 메아리, 물웅덩이에 비치는 아기 |
| 모든 스테이지 | 철새 (게임당 1번, 스테이지 1 ~ 3 사이) |

## 2. 내용과 발동 조건

| # | 이름 | 발동과 내용 |
|---|---|---|
| 1 | 새에 쌓이는 눈 | 새가 날지 않고 한 자리에 가만히 있으면(땅에 서 있거나 가지에 앉아 있을 때) 위에 눈이 쌓인다 |
| 2 | 그루터기 무당벌레 | 고목이 쓰러진 뒤 남은 밑동을 클릭하면 새가 쪼고, 무당벌레가 기어 나온다 |
| 3 | 눈 회오리 | 쌓인 눈더미를 클릭하면 새가 그 위를 빙글빙글 돌며 회오리를 만든다 |
| 4 | 눈 속의 꽃 | 빛나는 눈을 클릭하면 새가 쪼아 구멍을 파고 꽃을 보여 준다 |
| 5 | 고드름 실로폰 | 나무의 고드름을 클릭하면 새가 가서 부리로 탁 쪼고, 쪼인 고드름이 제자리에서 흔들리며 소리를 낸다 (2026-11-06 디렉터 수정. 전에는 떨어져 아래 바위에 부딪혔다). 도레미파솔라시도 8개 |
| 6 | 나무 구멍 다람쥐 | 나무 구멍 근처에서 새가 울면 다람쥐가 빼꼼 나왔다가 다시 들어간다 |
| 7 | 산수유 열매 | 나무(덤불)의 열매를 클릭하면 새가 쪼아 먹고 가슴을 부풀린다 |
| 8 | 낭떠러지 메아리 | 마지막 맵에서 낭떠러지를 향해 새가 울면 메아리가 들린다 |
| 9 | 물웅덩이에 비치는 아기 | 스테이지 3 에서 물웅덩이 위를 지날 때 아기가 다른 존재로 비친다. 지금은 만들지 않는다 |
| 10 | 철새 | 카메라를 최대로 줌아웃하면 철새들이 지나간다. 바닥에 그림자가 진다 |

## 3. 스테이지 3 에서 조심할 것

- **물웅덩이**: 안개 아래 숨은 장애물에도 물웅덩이가 있다 (GDD 9.2). 반사 이스터에그의 웅덩이는 장애물 웅덩이와 생김새를 다르게 하거나, 아기 경로 밖이나 3-3 에 두는 게 안전하다.
- **울음에 반응하는 것**: 안개 미로에서는 울면 길 위의 동물이 대답한다. 다람쥐(스테이지 2)와 메아리(3-3)는 미로 밖이라 겹치지 않는다.
