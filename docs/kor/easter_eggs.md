# 이스터에그 (자잘한 상호작용)

> 원본: 프로젝트 루트의 `order_from_director.md` (디렉터 지시). 2026-11-06 에 디렉터가 이 파일 끝에 거의 확정된 기획을 적었고, 이 파일은 그것을 기준으로 다시 정리했다. 그 전 목록(13개, 언 강물과 산천어, 호랑나비 포함)은 git 기록에 있다.
> 영어판: [`../eng/easter_eggs.md`](../eng/easter_eggs.md)
> 상태: 물웅덩이를 뺀 모두를 프리팹으로 만들어 `Main` 의 인트로 출발점 뒤(−Z) 공터에 두었다 ([ADR 0034](decisions/0034-이스터에그를-인트로-뒤-공터에-프리팹으로.md)). 스테이지 안의 자리는 아직 정하지 않았다.

찾은 이스터에그는 사전(Encyclopedia)에 기록된다. 이스터에그가 나타나면 게임이 그 순간 대상을 가까이 찍어 사진으로 넣는다. 유저가 누른 순간이 아니다. 사전은 `` ` `` 키로 연다 (원본은 ESC 였으나 사용자가 바꿨다).

## 1. 배치 (디렉터 기획)

| 스테이지 | 이스터에그 |
|---|---|
| 인트로 | 새에 쌓이는 눈 (항상 있는 기믹이지만 눈이 내리는 인트로에서만 보인다) |
| 스테이지 1 | 그루터기 무당벌레, 눈 회오리, 눈 속의 꽃 |
| 스테이지 2 | 고드름 실로폰, 나무 구멍 다람쥐, 산수유 열매 |
| 스테이지 3 | 낭떠러지 메아리, 물웅덩이에 비치는 아기 |
| 모든 스테이지 | 철새 (게임당 1번, 스테이지 1 ~ 3 사이) |

## 2. 내용과 발동 조건

| # | 이름 | 발동과 내용 |
|---|---|---|
| 1 | 새에 쌓이는 눈 | 새가 날지 않고 한 자리에 가만히 있으면(땅에 서 있거나 가지에 앉아 있을 때) 위에 눈이 쌓인다 |
| 2 | 그루터기 무당벌레 | 고목이 쓰러진 뒤 남은 밑동을 클릭하면 새가 쪼고, 무당벌레가 기어 나온다 |
| 3 | 눈 회오리 | 쌓인 눈더미를 클릭하면 새가 그 위를 빙글빙글 돌며 회오리를 만든다 |
| 4 | 눈 속의 꽃 | 빛나는 눈을 클릭하면 새가 쪼아 구멍을 파고 꽃을 보여 준다 |
| 5 | 고드름 실로폰 | 나무의 고드름을 클릭하면 떨어져 아래 바위에 부딪히며 소리를 낸다. 도레미파솔라시도 8개 |
| 6 | 나무 구멍 다람쥐 | 나무 구멍 근처에서 새가 울면 다람쥐가 빼꼼 나왔다가 다시 들어간다 |
| 7 | 산수유 열매 | 나무(덤불)의 열매를 클릭하면 새가 쪼아 먹고 가슴을 부풀린다 |
| 8 | 낭떠러지 메아리 | 마지막 맵에서 낭떠러지를 향해 새가 울면 메아리가 들린다 |
| 9 | 물웅덩이에 비치는 아기 | 스테이지 3 에서 물웅덩이 위를 지날 때 아기가 다른 존재로 비친다. 지금은 만들지 않는다 |
| 10 | 철새 | 카메라를 최대로 줌아웃하면 철새들이 지나간다. 바닥에 그림자가 진다 |

## 3. 스테이지 3 에서 조심할 것

- **물웅덩이**: 안개 아래 숨은 장애물에도 물웅덩이가 있다 (GDD 9.2). 반사 이스터에그의 웅덩이는 장애물 웅덩이와 생김새를 다르게 하거나, 아기 경로 밖이나 3-3 에 두는 게 안전하다.
- **울음에 반응하는 것**: 안개 미로에서는 울면 길 위의 동물이 대답한다. 다람쥐(스테이지 2)와 메아리(3-3)는 미로 밖이라 겹치지 않는다.

## 4. 지금 구현 (2026-11-06)

프리팹은 `Assets/03_Prefabs/EasterEggs/`, 코드는 `Assets/02_Scripts/EasterEggs/`, 빌더는 `AgentScripts/BuildEasterEggs.cs` (`BuildEasterEggs.Run`) 다. 모델과 위치는 프리팹과 씬에서 바꾸면 된다. 프리팹마다 `Discovery` 가 사전 항목과 사진 대상을 가진다.

| 프리팹 | 모델 | 동작 | 사전에 오르는 때 |
|---|---|---|---|
| `SnowOnBird` (`Bird` 아래) | 흰 구 (자리 표시) | 계절 0 에서 새가 땅이나 가지에 1.5 초 가만히 있으면 8 초에 걸쳐 쌓이고, 움직이면 털린다 | 다 쌓였을 때 |
| `StumpLadybug` | 원기둥 그루터기 (자리 표시), 무당벌레 `Ladybug.prefab` | 클릭하면 새가 앉아 2 번 쪼고, 무당벌레가 기어 나온다. 한 번만 | 다 기어 나왔을 때 |
| `SnowWhirl` | `Snowbank` 눈더미 | 클릭하면 새가 앉았다가 4 초 동안 위를 돈다. 눈 파티클 회오리, 소리는 `event:/SFX/spiral`. 끝나면 다시 할 수 있다 | 도는 중간 |
| `SnowFlower` | `Snowbank` 작은 눈더미 + `InteractiveSparkle`, 꽃 `Flower01` | 클릭하면 새가 앉아 3 번 쪼고, 눈이 줄며 꽃이 자란다. 한 번만 | 꽃이 다 자랐을 때 |
| `IcicleXylophone` | 토미의 `icy tree.fbx` (고드름 8 개), 바위 (자리 표시) | 고드름을 클릭하면 떨어져 바위에서 한 음을 내고 3 초 뒤 다시 생긴다. 긴 것부터 도레미파솔라시도. 소리는 `event:/SFX/highpitch_0` 의 pitch 를 바꾼 것이다 | 처음 울릴 때 |
| `HollowSquirrel` | 토미의 `thickTree.obj` (구멍), 다람쥐는 캡슐 (자리 표시) | 구멍에서 6 m 안에서 울면 다람쥐가 나왔다가 1.5 초 뒤 들어간다 | 나왔을 때 |
| `CornelianCherry` | 토미의 `cornelian_cherry` (덤불, 열매 6 개) | 클릭하면 새가 앉아 2 번 쪼고 열매 하나가 없어지고 가슴을 부풀린다. 열매가 남아 있으면 다시 할 수 있다 | 가슴을 부풀린 뒤 |
| `CliffEcho` | 낮은 바위 (낭떠러지 자리 표시) | 8 m 안에서 울면 0.7 초, 1.4 초 뒤 새 울음(`event:/SFX/Bird`)이 작게 돌아온다 | 첫 메아리 |
| `MigratingBirds` | 새 모델 5 마리 (0.4 배) | 최대 줌아웃을 2 초 유지하면 화면 가운데 위 7 m 를 가로질러 날아간다. 게임당 1 번. `From Stage` 부터 (기본 1, 공터의 것은 시험용 0) | 화면 가운데를 지날 때 |

자리 표시와 대신 쓴 것 (`sam` 브랜치에서는 아트·사운드를 새로 만들지 않는다):

- 쪼기와 가슴 부풀리기 클립이 없다. `BirdController.Peck`, `PuffChest` 가 몸을 기울이고 키우는 코드로 대신한다.
- Unity 오디오가 꺼져 있고 소리는 FMOD 다. 실로폰 음, 메아리, 회오리는 기존 FMOD 이벤트를 쓴다. 전용 소리가 오면 프리팹의 이벤트만 바꾸면 된다.
- 토미의 모델은 수채화로 굽지 않았다. 토미의 머티리얼 그대로다.

공터: `Main` 의 `Stages/Intro/EasterEggs`, x −14 ~ 14, z −36.5 ~ −24.5. 인트로의 새 범위를 z −35 까지 늘렸다. 월드 숲은 공터에 Clear 구역을 두고 뒤쪽 패딩을 1.5 m 로 줄였다(공터 뒤 한 줄만 남는다). 카메라가 새로 보게 된 터레인 끝 쪽은 `01_SYSTEM/TreeGenerator_ClearingBack` 이 채운다.
