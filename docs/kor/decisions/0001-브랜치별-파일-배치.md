# 0001. `.agents/` 는 main 에, 개인 파일은 sam 에 둔다

- 상태: 채택
- 날짜: 2026-10-26
- 관련: [ADR 0006](0006-agents-md-를-main-에-공용으로-둔다.md)

## 맥락

레포에 처음 올릴 파일 셋을 어느 브랜치에 둘지 정해야 했다. `.agents/`(Unity 에이전트 스킬), `image.png`, `AGENTS.md` 다.

## 결정

사용자가 정했다.

**`.agents/` 는 `main` 에 두고 `sam` 도 같은 커밋을 가진다. `image.png` 와 `AGENTS.md` 는 `sam` 에만 둔다.**

`AGENTS.md` 부분은 뒤에 [ADR 0006](0006-agents-md-를-main-에-공용으로-둔다.md) 이 바꿨다.

## 대안

**대안 1. 모든 파일을 `sam` 에만 둔다.**
버렸다. 팀원이 스킬을 쓰려면 `sam` 을 받아야 한다.

**대안 2. `AGENTS.md` 도 `main` 에 둔다.**
이때는 버렸다. 그 시점의 `AGENTS.md` 는 확인용 한 줄 규칙이었다.

## 결과

**얻는 것.**

- 팀원은 `main` 만 받아도 스킬을 쓸 수 있다
- 개인 실험 파일이 `main` 을 어지럽히지 않는다

**치르는 것.**

- `main` 에서 시작한 에이전트 세션에는 `AGENTS.md` 규칙이 들어가지 않는다
