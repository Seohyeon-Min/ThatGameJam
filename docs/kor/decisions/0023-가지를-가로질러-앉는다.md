# 0023. 길가 나무 가지에 앉을 때 새는 가지를 가로질러 앉는다

- 상태: 채택
- 날짜: 2026-10-29
- 관련: [`../implementation_plan.md`](../implementation_plan.md) 4.1, [ADR 0009](0009-새는-길가-나무-가지에-앉고-가만히-두면-가까운-가지로.md)

## 맥락

새는 앉을 때 날아온 방향을 그대로 보고 앉았다. 사용자가 앉을 때 가지 방향에 맞추라고 했다.

## 결정

사용자의 지시다. "가지 방향에 맞춘다" 를 어떻게 읽을지는 이 에이전트가 정했다.

**새는 가지를 가로질러 앉는다.** 실제 새처럼 몸이 가지와 직각이고, 발이 가지를 감싼다. 두 방향 중 날아온 방향에 가까운 쪽을 본다. 착지하는 1.2 초 동안 천천히 돈다.

- 가지 방향은 나무마다 앉는 자리에서 줄기 바깥으로 뻗는 방향(yaw)이다. 빌더가 앉는 자리의 forward 를 그와 직각으로 둔다
- `Perchable` 의 `alignBird` 가 켜진 곳에서만 돈다. 길가 나무만 켠다. 고목 같은 장치에서는 전처럼 날아온 방향 그대로다

## 대안

**대안 1. 몸을 가지와 나란히 둔다.**
버렸다. 실제 새는 가지를 가로질러 앉는다. 사용자가 원하면 빌더의 각도 하나(+90)로 바꿀 수 있다.

**대안 2. 앉는 자리마다 바라볼 방향 하나를 정해 둔다.**
버렸다. 날아온 방향과 반대면 크게 돈다. 두 방향 중 가까운 쪽이 덜 어색하다.

## 결과

**얻는 것.**

- 새의 발이 가지를 가로질러 잡는다

**치르는 것.**

- 날아온 방향에 따라 착지하며 최대 90° 돈다
- 새가 나무에 비해 커서, 몸 앞뒤로 가는 가지나 줄기가 지나가는 것은 그대로다
