# 0004. 개인 테스트 씬에서 작업하고 `Main.unity` 는 건드리지 않는다

- 상태: 채택
- 날짜: 2026-10-26
- 관련: [`../../../AGENTS.md`](../../../AGENTS.md) 씬과 폴더

## 맥락

Unity 씬 파일은 git 으로 합치기 어렵다. 여러 사람이 같은 씬을 고치면 충돌이 난다.

## 결정

AI 가 제안하고 사용자가 받아들였다.

**`Main.unity` 는 건드리지 않고 `Assets/00_Scenes/Sam_Test.unity` 에서 작업한다.** 스크립트는 `02_Scripts`, 프리팹은 `03_Prefabs` 에 둔다.

## 대안

**대안 1. 모두 `Main.unity` 에서 작업한다.**
버렸다. 씬 충돌이 난다.

## 결과

**얻는 것.**

- 다른 팀원과 씬 충돌이 나지 않는다

**치르는 것.**

- 나중에 `Main.unity` 로 옮기는 작업이 따로 필요하다. 오브젝트를 프리팹으로 만들어 두면 쉬워진다
