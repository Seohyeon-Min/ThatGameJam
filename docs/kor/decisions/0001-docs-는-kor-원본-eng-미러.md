# 0001. `docs/` 는 kor 를 원본으로 쓰고 eng 로 미러링한다

- 상태: 채택
- 날짜: 2026-10-26
- 관련: [`../../record-format-example.md`](../../record-format-example.md)

## 맥락

작업 기록(`docs/`)의 구조와 언어를 정해야 했다. 개발 워크플로 기본값은 `spec.md`, `plan.md`, `decisions/`, `commit_history/` 를 둔다.

## 결정

사용자가 정했다.

**지금은 `commit_history/` 와 `decisions/` 만 쓴다. `docs/kor/` 와 `docs/eng/` 를 두고 모든 문서를 미러링한다. 한국어를 먼저 쓰고 영어가 따라간다.** 기록 형식은 `docs/record-format-example.md` 를 따른다. 그 파일은 미러링하지 않는다.

## 대안

**대안 1. 기본값대로 `spec.md`, `plan.md` 까지 둔다.**
지금은 버렸다. 게임잼이라 기록에 드는 시간을 줄인다.

**대안 2. 기록을 생략한다.**
버렸다.

**대안 3. 한 언어로만 쓴다.**
버렸다.

## 결과

**얻는 것.**

- 한국어를 쓰지 않는 팀원도 같은 기록을 읽을 수 있다

**치르는 것.**

- 문서를 쓸 때마다 두 번 써야 한다. 한쪽만 고치면 두 언어 버전이 어긋날 수 있다
