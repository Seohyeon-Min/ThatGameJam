# 0022. 눈은 바람 값만 바꾸고, 숲을 x ±33 까지 넓힌다

- 상태: 채택. [ADR 0021](0021-새-범위-1.5배-인트로-뒤-나무-눈-바람.md) 의 눈 상자 이동과 양·수명 변경을 되돌린다
- 날짜: 2026-10-29
- 관련: [`../implementation_plan.md`](../implementation_plan.md) 3.3, 4.9, [ADR 0020](0020-나무-배치와-새-범위를-0013-으로-되돌린다.md), [ADR 0021](0021-새-범위-1.5배-인트로-뒤-나무-눈-바람.md)

## 맥락

ADR 0021 에서 바람 값을 넣으면서, 이 에이전트가 눈 상자를 바람이 불어오는 쪽으로 옮기고 양과 수명도 바꿨다. 사용자는 그것이 자기 의도가 아니라고 했다. 바람 값만 넣고 다른 것은 건드리지 말라고 했다. 사용자 뜻 없이 바꾸면 안 된다.

같은 때 사용자는 숲도 넓히라고 했다. 새의 범위를 x ±19.5 로 넓히자 범위 끝에서 숲(x ±21.4) 너머가 보였기 때문이다.

## 결정

사용자의 지시다.

**눈은 바람 값 (0.5, −5) 만 바뀐다.** 상자(카메라가 보는 땅), 1 m² 당 양(1.5), 수명(11 초)은 ADR 0021 전으로 되돌렸다.

**숲은 x ±33 까지다.** 넓이는 이 에이전트가 정했다. 새의 범위와 같은 비율(1.5배)로 ADR 0013 의 x ±22 를 넓혔다. 나무는 471 그루다.

## 대안

**대안 1. 눈 상자를 바람에 맞춰 옮겨 둔다 (ADR 0021).**
버렸다. 사용자가 원하지 않았다.

## 결과

**얻는 것.**

- 눈은 사용자가 정한 값만 바뀐다
- 새가 범위 끝(x ±19.5)에 가도 숲이 이어진다

**치르는 것.**

- 바람이 세서 눈송이가 떨어지는 동안 −Z 로 37 ~ 47 m 밀린다. 화면 위쪽에 눈이 옅은 곳이 생길 수 있다. 크로스 모델 리뷰도 이것을 짚었다. 사용자가 보고 정한다
- 나무가 345 → 471 그루로 늘었다
