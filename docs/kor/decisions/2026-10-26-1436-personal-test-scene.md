# 개인 테스트 씬에서 작업하고 Main.unity는 건드리지 않는다

Date: 2026-10-26 14:36

## 주제
Unity 씬 파일은 git으로 합치기 어렵다. 여러 사람이 같은 씬을 고치면 충돌이 난다.

## AI의 제안
- `Main.unity`는 건드리지 않는다.
- `Assets/00_Scenes/Sam_Test.unity`에서 작업한다.
- 스크립트는 `02_Scripts`, 프리팹은 `03_Prefabs`에 둔다.

## 사용자의 선택
제안대로 한다.

## Trade-off
- 얻는 것: 다른 팀원과 씬 충돌이 나지 않는다.
- 비용: 나중에 `Main.unity`로 옮기는 작업이 따로 필요하다. 옮기기 쉽게 오브젝트를 프리팹으로 만들어 두는 것이 좋다.
