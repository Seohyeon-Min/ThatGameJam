# docs는 kor을 원본으로 쓰고 eng로 미러링한다

Date: 2026-10-26 14:53

## 주제
작업 기록(`docs/`)의 구조와 언어를 정해야 했다.

## AI의 제안
개발 워크플로 기본값은 `docs/` 아래에 `spec.md`, `plan.md`, `decisions/`, `commit_history/`를 둔다. 게임잼이라 생략할지도 물었다.

## 사용자의 선택
- 지금은 `commit_history/`와 `decisions/`만 만든다.
- `docs/kor/`와 `docs/eng/`를 두고, 모든 문서를 두 언어로 미러링한다.
- 한국어(`kor`)를 먼저 쓰고, 영어(`eng`)는 그것을 따라간다.

## Trade-off
- 얻는 것: 한국어를 쓰지 않는 팀원도 같은 기록을 읽을 수 있다.
- 비용: 문서를 쓸 때마다 두 번 써야 한다. 한쪽만 고치면 두 언어 버전의 내용이 어긋날 수 있다.
