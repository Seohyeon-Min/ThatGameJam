# 0034. 이스터에그를 프리팹으로 만들어 인트로 뒤 공터에 모아 둔다

- 상태: 채택
- 날짜: 2026-11-06
- 관련: [`../easter_eggs.md`](../easter_eggs.md) 4절, [`../implementation_plan.md`](../implementation_plan.md) 6.1

## 맥락

디렉터가 이스터에그 기획을 거의 확정했다(`order_from_director.md`, `easter_eggs.md`). 스테이지 안의 자리와 모델은 나중에 바뀐다. 필요한 모델 일부는 토미 브랜치에 있고, 다람쥐·눈더미·쪼기 클립·전용 소리는 없다. `sam` 브랜치에서는 아트와 사운드를 새로 만들지 않는다. 프로젝트의 Unity 오디오는 꺼져 있고 소리는 FMOD 다.

## 결정

사용자가 정했다.

**이스터에그마다 프리팹을 만들고, `Main` 의 인트로 출발점 뒤(−Z)에 나무를 비운 공터를 만들어 모두 둔다.** 물웅덩이에 비치는 아기는 지금 만들지 않는다.

- 토미 브랜치에서는 필요한 메시(`icy_tree`, `thickTree`, `cornelian_cherry`)만 가져온다. 브랜치를 머지하지 않는다.
- 없는 모델은 기본 도형과 기존 시험 머티리얼, 기존 프리팹(`Snowbank`, `Flower01`, `Ladybug`, 새 모델)으로 대신한다.
- 쪼기와 가슴 부풀리기는 코드로 몸을 기울이고 키워 대신한다. 소리는 기존 FMOD 이벤트의 pitch 와 볼륨을 바꿔 쓴다.
- 새에 쌓이는 눈도 만든다(11-04 에 뺐던 것을 디렉터 기획이 다시 넣었다).
- 발동 조건은 디렉터의 새 목록을 따른다(눈 회오리는 눈더미 클릭, 다람쥐는 구멍 근처에서 울기).
- 사전 항목을 새 목록에 맞춘다. 언 강물, 호랑나비를 빼고, 새에 쌓이는 눈과 눈 회오리를 넣고, 물웅덩이는 남긴다.
- 철새는 공터의 것만 시험용으로 인트로에서도 나온다(`From Stage` 0).

## 대안

**대안 1. 토미 브랜치를 통째로 머지한다.**
버렸다. 토미 쪽 `BirdController.cs` 와 `Tommy_Test` 도 바뀌어 있어 충돌과 되돌림이 생긴다.

**대안 2. 각 이스터에그를 바로 스테이지 안에 둔다.**
버렸다. 자리가 정해지지 않았다. 공터에 모아 두면 한곳에서 시험하고, 자리가 정해지면 프리팹을 옮기면 된다.

**대안 3. Unity AudioSource 로 시험용 wav(`ClickStem`)를 쓴다.**
버렸다. 프로젝트에서 Unity 오디오가 꺼져 있다(`m_DisableAudio: 1`).

## 결과

**얻는 것.**

- 모든 이스터에그를 공터에서 바로 해 볼 수 있고, 프리팹과 씬에서 모델과 위치를 바꿀 수 있다.
- 찾으면 사전에 사진과 함께 오른다.

**치르는 것.**

- 인트로의 새 범위가 z −35 까지 넓어졌다. 출발점 뒤가 열려 인트로에서 새가 공터로 갈 수 있다. 공터에서 울면 근처에서 자는 아기도 깬다.
- 카메라가 터레인 끝 쪽을 보게 되어 숲 생성기를 하나 더 두었다. 월드 숲의 뒤쪽 패딩을 줄이고 다시 생성했다.
- 자리 표시 모델과 대신 쓴 소리라 보기와 듣기가 최종과 다르다. 토미 모델은 수채화로 굽지 않았다.
- 공터와 범위 확장은 이스터에그 자리가 정해지면 되돌려야 한다.
