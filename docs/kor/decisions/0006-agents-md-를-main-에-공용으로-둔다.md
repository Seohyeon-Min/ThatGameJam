# 0006. `AGENTS.md` 에 프로젝트 규칙을 넣고 main 에 공용으로 둔다

- 상태: 채택
- 날짜: 2026-10-26
- 관련: [`../../../AGENTS.md`](../../../AGENTS.md), [ADR 0001](0001-브랜치별-파일-배치.md)

## 맥락

`AGENTS.md` 에 게임 개발에 쓸 규칙을 넣기로 했다. 이 파일은 [ADR 0001](0001-브랜치별-파일-배치.md) 에 따라 `sam` 에만 있었다.

## 결정

사용자가 정했다.

**AI 가 낸 규칙 초안을 그대로 쓰고, `AGENTS.md` 를 팀 공용으로 `main` 에 둔다.** ADR 0001 의 `AGENTS.md` 부분을 바꾼다. 공용 파일이 되었으므로 git 규칙의 "`sam` 브랜치에서 한다" 를 "각자 이름의 브랜치(예: `sam`)에서 한다" 로 바꿨다.

## 대안

**대안 1. `sam` 에만 둔다.**
버렸다. `main` 에서 시작한 세션이 규칙을 읽지 못한다.

**대안 2. 교차 모델 리뷰를 규칙에 넣는다.**
버렸다. 팀원 환경에 `codex` 가 없을 수 있다.

## 결과

**얻는 것.**

- 어느 브랜치에서 시작한 에이전트 세션이든 같은 규칙을 읽는다

**치르는 것.**

- 규칙에 나오는 `docs/kor/`, `docs/eng/`, `AgentScripts/` 는 아직 `sam` 에만 있다. `main` 에서 시작한 세션은 이 폴더들을 새로 만들게 된다
