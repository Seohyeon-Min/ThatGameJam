# 작업 기록 `docs/` 추가 (ADR 0001)

## 왜 했나

사용자가 작업 기록을 남기기로 했다. 지금은 `commit_history/` 와 `decisions/` 만 두고 kor 원본, eng 미러로 쓴다([ADR 0001](../../decisions/0001-docs-는-kor-원본-eng-미러.md)).

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 결정 기록 5개, 세션 기록 1개 (kor, eng) | `docs/kor/`, `docs/eng/` |

결정 시각은 세션 대화 기록의 사용자 메시지 시각에서 가져왔다. 이 파일들은 [08](08-기록-양식-전환과-기획-문서-이동.md) 에서 지금 양식으로 다시 썼다.
