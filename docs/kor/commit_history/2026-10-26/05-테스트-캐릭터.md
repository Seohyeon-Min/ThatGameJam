# 테스트용 새, 아이, 장애물, 쿼터뷰 카메라를 `Sam_Test` 씬에 추가

## 왜 했나

핵심 흐름을 바로 확인하려고 만들었다. 새가 장애물을 치우면 아이가 나아가는 흐름이다. 새는 높이까지 날고 WASD + 휠 + E 로 조작한다. 아이는 일자 도로를 직진한다. 작업은 `Main.unity` 대신 개인 테스트 씬에서 한다.

## 무엇을 바꿨나

| 무엇 | 자리 |

## 크로스 모델 리뷰

Codex. 정확성, 보안, 견고성 렌즈. Unity 6000.4, Input System 전용, WebGL 목표라는 맥락을 같이 주었다. 범위는 `.cs` 5개의 staged diff.

지적 없음. 결과는 `LGTM - no blockers` 였다.

## 겪은 문제

- 에디터 창에 포커스가 없으면 Input System 이 실제 키보드를 꺼 둔다(`backgroundBehavior = ResetAndDisableNonBackgroundDevices`). 상태 이벤트를 넣어도 입력이 먹지 않았다. 테스트 동안만 설정을 바꾸고 가상 장치(`InputSystem.AddDevice`)를 썼다. 끝나고 장치를 지우고 설정을 되돌렸다
- 설치된 Pipeline 의 명령 이름이 스킬 문서와 다르다. `editor_status` 는 `editor status`, `set_autotick` 은 `editor set_auto_tick` 이다
- `capture game_view --save_path Temp/...` 는 `Assets/Temp/` 에 저장한다. 바로 옮기고 지웠다
