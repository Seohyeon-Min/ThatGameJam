# 도로 옆 나무 프리팹과 새의 가지 앉기

## 왜 했나

디렉터가 도로 양옆에 나무를 배치하고, 새가 그 나무에 앉을 수 있기를 원했다. 사용자가 방식을 정했다.

- 도로 쪽으로 뻗은 가지 근처에서 E 를 누르면 앉는다
- 앉아 있을 때 WASD 나 휠을 입력하면 바로 날아오른다
- 앉을 수 있는 범위는 반지름 1.0 인 구다. 새 지름 0.5 의 2배다
- E 는 앉는 지점과 장애물 중 더 가까운 쪽에 반응한다. 앉아 있을 때 E 는 아무 일도 하지 않는다
- 0.2초 동안 날아가서 앉는다
- 가지 방향은 배치할 때 나무를 회전해서 맞춘다
- 범위 안에 들어오면 화려하지 않은 표시를 보여 준다

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 새의 상태를 날기, 내려앉는 중, 앉음으로 나눴다. 앉는 동안은 `isKinematic` 으로 고정한다. 날아오르면 지금 높이에서 다시 시작한다 | `Assets/02_Scripts/BirdController.cs` |
| 앉는 지점. 활성화된 지점을 정적 목록으로 모은다. 새가 범위 안에 있으면 표시(노란 구)가 위아래로 크기를 바꾸며 깜빡인다 | `Assets/02_Scripts/PerchPoint.cs` |
| 나무 프리팹. 기둥(콜라이더 있음), 잎, 로컬 +Z 로 뻗은 가지 하나, 가지 끝의 앉는 지점. 잎과 가지에는 콜라이더가 없다 | `Assets/03_Prefabs/Tree.prefab` |
| 빌더가 프리팹을 만들고, 도로 양옆 z=3, 10, 17 에 가지가 도로를 향하게 나무 6그루를 놓는다 | `AgentScripts/BuildSamTestScene.cs`, `Assets/00_Scenes/Sam_Test.unity` |
| 임시 머티리얼 3개. 표시는 URP Unlit 이다 | `Assets/01_Arts/Materials/Test/Trunk.mat`, `Leaves.mat`, `PerchIndicator.mat` |

## 검증

| 무엇 | 결과 |

| 다시 앉은 뒤 휠 위로 한 칸 | 바로 `Flying`, 높이 3.11 → 3.61. 아직 범위 안이라 표시가 다시 켜졌다 |
| 콘솔 | 경고와 에러 0 |

## 크로스 모델 리뷰

Codex. 정확성, 보안, 견고성 렌즈. 범위는 `.cs` 3개의 staged diff.

| 지적 | 처리 |
|------|------|
| warn. `landDuration` 이 음수이면 보간값이 계속 0 이 되어 새가 `Landing` 에 갇힌다 | **반영.** 필드에 `[Min(0f)]` 를 붙였다. 0 이면 바로 앉으므로 문제없다 |

고친 뒤 확인 리뷰는 `LGTM - no blockers` 였다.

## 남은 것

- 카메라가 도로의 오른쪽 뒤에서 보기 때문에, 카메라 쪽 나무의 잎이 도로와 새를 가린다. 반투명 처리, 카메라 쪽 배치 줄이기, 카메라 높이기 중에서 디렉터와 정해야 한다
- 장애물과 앉는 지점이 둘 다 범위 안일 때의 선택은 코드로만 확인했고 Play Mode 로는 시험하지 않았다
