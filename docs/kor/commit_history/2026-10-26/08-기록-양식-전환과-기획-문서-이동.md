# 기록을 `record-format-example.md` 양식으로 다시 쓰고 기획서를 `docs/` 로 옮김

## 왜 했나

사용자가 `docs/record-format-example.md` 를 올리고, 지금까지 쓴 기록을 그 양식으로 바꾸라고 했다. `rough_game_design.md` 도 `docs/` 로 옮기라고 했다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 세션 파일 하나를 커밋별 파일 8개로 나눴다 | `docs/*/commit_history/2026-10-26/` |
| 날짜 이름 결정 파일과 `INDEX.md` 를 번호 ADR 0001~0006 으로 바꿨다. 절은 맥락 / 결정 / 대안 / 결과 | `docs/*/decisions/` |
| 양식 예시의 README 를 넣었다 | `docs/*/commit_history/README.md`, `docs/*/decisions/README.md` |
| 기획서 원문(영어)을 옮겼다 | `docs/eng/rough_game_design.md` |
| 기획서 한국어 번역 | `docs/kor/rough_game_design.md` |

## 중요한 결정

- 양식 예시 파일은 미러링하지 않는다. 사용자 지시다
- 기획서는 원문이 영어다. 다른 문서처럼 미러링해야 한다고 보고, 한국어 번역을 `kor` 에 두었다. 원문은 `eng` 에 그대로 두었다
- 그때의 ADR 0006 은 ADR 0001 을 바꾸는 결정이었다. 양식 규칙대로 0001 은 고치지 않고, 0006 의 `관련:` 에 0001 을 링크했다. [09](09-결정-기록-정리.md) 에서 0001 은 지웠고 0006 은 0002 가 되었다

## 검증

| 무엇 | 결과 |
|------|------|
| kor 와 eng 의 `commit_history/` 파일 목록 비교 | 같다 |
| kor 와 eng 의 ADR 번호 비교 | 둘 다 0001~0006 |
| `docs/` 안 모든 상대 링크가 가리키는 파일이 있는지 확인 | 깨진 링크 없음 |
