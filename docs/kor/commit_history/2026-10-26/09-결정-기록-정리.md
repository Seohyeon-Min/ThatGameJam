# 결정 기록을 두 개로 정리

## 왜 했나

게임 디자인이 아직 확실하지 않다. 그래서 테스트 단계의 선택까지 결정 기록이 되고 있었다. 사용자가 보기에 중요한 결정은 `docs/` 구성과 `AGENTS.md` 공용화 둘뿐이다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 삭제: 브랜치별 파일 배치, 새의 비행과 조작, 아이의 일자 도로 직진, 개인 테스트 씬 (옛 0001~0004) | `docs/*/decisions/` |
| 번호 변경: 옛 0005 → [ADR 0001](../../decisions/0001-docs-는-kor-원본-eng-미러.md), 옛 0006 → [ADR 0002](../../decisions/0002-agents-md-를-main-에-공용으로-둔다.md) | `docs/*/decisions/` |
| 옛 0006 에서 지운 ADR 0001 링크와 문장 제거 | [ADR 0002](../../decisions/0002-agents-md-를-main-에-공용으로-둔다.md) |
| 지운 ADR 을 가리키던 제목과 링크를 고치거나 뺐다 | `commit_history/2026-10-26/` 01, 02, 03, 05, 06, 07, 08 |

지운 결정의 내용은 05 기록의 본문에 남아 있다. 지우기 전 파일은 커밋 `3471ea7` 에 있다.
