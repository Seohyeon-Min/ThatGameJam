# `AGENTS.md` 에 프로젝트 규칙을 넣고 main 에 공용으로 올림 (ADR 0006)

## 왜 했나

사용자가 게임 개발에 쓸 규칙을 `AGENTS.md` 에 넣고 팀 공용으로 두기로 했다([ADR 0006](../../decisions/0006-agents-md-를-main-에-공용으로-둔다.md)).

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 대화와 기록, 프로젝트, 씬과 폴더, Unity CLI, git 규칙 | `AGENTS.md` (`sam`, 커밋 `7427472`) |
| 같은 내용을 `main` 에 커밋 | `AGENTS.md` (`main`, 커밋 `f0fe1e3`) |
| `main` 을 `sam` 에 병합 | 커밋 `35264c3` |
| 결정 기록 추가 | `docs/` (커밋 `f8c569f`) |

규칙마다 이번 세션에서 실제로 겪은 일을 근거로 붙여 초안을 냈다. 사용자가 승인한 뒤에 썼다.

## 중요한 결정

- 에디터가 `sam` 작업 트리를 열고 있었다. 브랜치를 바꾸면 에셋이 다시 import 된다. 그래서 임시 worktree 에서 `main` 에 커밋하고 worktree 를 지웠다
- 두 브랜치의 `AGENTS.md` 내용이 같아서 병합 충돌은 없었다

## 실수

`f8c569f` 에서 `git add docs` 로 폴더 전체를 stage 했다. 그 사이 사용자가 올린 `docs/record-format-example.md` 가 의도 없이 같이 커밋되었다. push 전이었고, 이 파일은 그대로 두기로 했다. 앞으로는 커밋할 경로를 하나씩 지정한다.
