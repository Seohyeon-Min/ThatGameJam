# 디렉터 스케치(`image.png`)에 맞춰 도로가 화면 왼쪽 아래에서 오른쪽 위로 가게 함

## 왜 했나

`image.png` 는 디렉터가 말하는 화면 방향이다. 길과 진행 화살표가 화면 왼쪽 아래에서 오른쪽 위로 간다. 기울기는 약 24도다. 그런데 기존 테스트에서는 도로가 오른쪽 아래에서 왼쪽 위로 갔다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 카메라 오프셋 `(-8, 10, -8)` → `(6.5, 6, -6.5)`. 도로(+Z)의 뒤쪽 오른편에서 내려다본다. 내려다보는 각도는 약 42도에서 약 33도로 낮아졌다 | `Assets/02_Scripts/QuarterViewCamera.cs` |
| 눈밭 크기 30×40 → 120×120. 카메라 각도가 낮아져서 바닥 끝이 화면에 보였다 | `AgentScripts/BuildSamTestScene.cs` |
| 빌더로 씬을 다시 만들었다 | `Assets/00_Scenes/Sam_Test.unity` |
| Unity 가 머티리얼의 `_Color` 를 `_BaseColor` 와 같게 다시 저장했다 | `Assets/01_Arts/Materials/Test/*.mat` |

## 검증

| 무엇 | 결과 |
|------|------|
| Play Mode 에서 오프셋 두 값을 바꿔 가며 캡처 | `(9, 7.35, -9)` 는 도로 기울기 약 27도. `(6.5, 6, -6.5)` 는 약 25도이고 도로가 화면을 더 넓게 채워서 이 값을 골랐다 |
| 다시 만든 씬을 Play Mode 로 캡처 | 도로가 왼쪽 아래에서 오른쪽 위로 간다 |
| 9.5초 뒤 아이 위치 | z=4.85. 장애물 앞에서 멈추는 동작은 그대로다 |

## 크로스 모델 리뷰

Codex. 정확성, 보안, 견고성 렌즈. 범위는 `.cs` 2개의 staged diff.

지적 없음. 결과는 `LGTM - no blockers` 였다. 리뷰 뒤 주석의 "behind-left" 를 "behind-right of the road" 로 고쳤다. 동작은 바뀌지 않는다.

## 겪은 문제

- 테스트 중 Run In Background 를 켠 상태에서 빌더가 `AssetDatabase.SaveAssets()` 를 불렀다. 그래서 `ProjectSettings.asset` 에 `runInBackground: 1` 이 저장되었다. 끈 뒤 메모리 값은 `False` 였지만 파일은 그대로였다. 파일을 git 에서 되돌렸다
- `capture game_view` 는 절대 경로를 줘도 `Assets/Temp/` 에 저장한다. 캡처마다 옮기고 폴더를 지웠다

## 남은 것

- 스케치 오른쪽 아래의 울퉁불퉁한 선이 무엇인지 아직 모른다. 디렉터에게 확인한 뒤 반영한다
