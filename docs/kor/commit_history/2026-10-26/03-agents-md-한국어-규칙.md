# `AGENTS.md` 에 한국어 대화 규칙 추가, 세션 시작 때 읽히는지 확인 (ADR 0001)

## 왜 했나

사용자가 Prime Agent 가 세션 시작 때 `AGENTS.md` 를 읽는지 물었다. 그때 레포에도 홈 폴더에도 `AGENTS.md` 가 없어서 확인할 수 없었다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| `- 대화는 한국어로 한다.` 한 줄 | `AGENTS.md` |

## 검증

| 무엇 | 결과 |
|------|------|
| 새 세션 `agents-md-probe` 에게 파일을 읽지 말고 이미 받은 지시문만 보고 답하게 했다 | 지시문의 `# Project Context` 절에 `## C:\me\ThatGameJam2\ThatGameJam\AGENTS.md` 와 내용이 그대로 있었다 |

전역 규칙에도 한국어 기본값이 있다. 그래서 한국어로 답한 것만으로는 증거가 되지 않는다. 새 세션에게 규칙이 어디서 왔는지 출처를 적게 했다.

## 알게 된 것

- `AGENTS.md` 는 세션 시작 때만 읽힌다. 파일을 고치면 새 세션부터 적용된다
- 작업 폴더의 파일만 확인했다. 상위 폴더의 `AGENTS.md` 도 읽는지는 보지 않았다
