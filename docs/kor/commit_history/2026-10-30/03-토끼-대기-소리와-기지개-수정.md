# 토끼 앞 대기 소리와 소녀의 기지개 수정

## 왜 했나

사용자가 첫 시연 눈가지 소리 이후 무입력 상태에서 같은 소리가 더 나고, 토끼 앞에서 소녀가 기지개를 켠다고 보고했다. GDD의 쪼그리기 애니메이션 유무도 물었다.

## 원인과 수정

| 원인 | 수정 |
|------|------|
| `SnowBranch.PulseSnow`가 실제 제거와 같은 PlaySnow(눈가루+소리)를 호출 | 대기 PulseSnow는 기존 가루 12개만. 실제 ShedSnow 소리 유지 |
| 새끼/어미 대기 뒤척임에도 같은 BranchRustle 소리를 호출 | RabbitFamily rustle 필드·Play와 빌더의 가족 AudioSource 생성 제거 |
| WaitPose.Crouch가 있어도 소녀는 일반 랜덤 Idle/Hum/Stretch 루프 | Baby가 해당 StopPoint에서 QuietWait를 켜고 이동·잠·dev skip에서 해제. 별도 Animator 상태는 Girl_Idle_Breathing만 반복하고 RandomIdle 없음 |
| 쪼그리기 클립 없음 | 실제 FBX의 9개 클립 재확인: GetUp, LieDown, Sleep, Breathing, Hum, Stretch, LookAround, Walk, Run. 없는 애니메이션을 있다고 하지 않고 숨쉬기 대기로 대체했다고 사용자에게 설명 |

`SetupBabyQuietWait.Run`으로 공유 컨트롤러만 수정한다. 전체 씬 빌더도 같은 Configure를 호출한다. 일반 서서 대기와 새의 랜덤 Idle는 바꾸지 않았다. 대기 신호용 별도 소리는 없어서 현재는 시각만 남긴다.

## 검증

- 실제 FBX 9클립 검사: 쪼그리기 없음.
- `SetupBabyQuietWait.Run` 연속 2회 후 QuietWait 상태 1개, AnyState 전이 1개, RandomIdle 0개 확인.
- `VerifyStage2Waiting.Run`: 실제 30초 자연 대기의 세 단계 모두 추가 소리 없음, 숨쉬기 상태 유지, 자연 해결 뒤 Walk 복귀, 실제 ShedSnow 소리 유지 통과.
- 기존 가상 마우스 회귀는 포인터/카메라가 움직여 다른 나무에 앉으면서 실패했다. 수정한 동작 회귀는 별도 Perched 이벤트 기반 검사로 구분했다.
- 컴파일 에러 0, Unity 콘솔 실행 에러 0.


- `VerifyStage2Waiting.Bird`: 양쪽 Perched 이벤트→도움 해결→조용한 반응→옆길 보행, 토끼 잠 유지 통과. 테스트 후 Play Mode/run in background와 배속 복원.

## 크로스 모델 리뷰

Claude Sonnet 5.5. `LGTM - no blockers`.

대기 가루가 실제 제거와 같은 12개라는 low 지적은 **기각**했다. 소리·눈 덩어리·가지 회전은 서로 다르고, 요청하지 않은 가루 양은 바꾸지 않는다. 이미 열린 정지점에서 관찰 대상이 없을 때 QuietWait로 멈추지 않는 것은 기존 동작 보존으로 확인했다.
