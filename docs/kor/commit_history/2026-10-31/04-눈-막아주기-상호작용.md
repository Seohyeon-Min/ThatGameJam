# 눈 막아주기 상호작용 (ADR 0025)

## 왜 했나

디렉터 오더 "Snow Protection Interaction". 인트로에서 소녀를 클릭하고 있는 동안 새가 소녀 앞쪽 위를 소녀 속도로 날며 날개와 그림자로 눈을 막고, 소녀는 그 새를 보며 걷는다. 방법은 [ADR 0025](../../decisions/0025-눈-막아주기-소녀를-누르면-새가-덮는다.md).

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 걷는 소녀 위에서 좌클릭을 누르기 시작하면 `IsSheltering`. 소녀 앞 0.6 m 위로 날아간 뒤 소녀 속도로 따라간다. 떼거나 소녀가 빛기둥에 누우면 끝 | `BirdController.cs` |
| 새가 덮는 동안 소녀가 고개를 새 쪽으로 돌린다. 가끔 멈추는 것은 그대로지만 그때도 둘러보지 않고 새를 본다 | `Baby.cs` |
| 새가 소녀 위에 닿은 동안 그림자 복제를 해 쪽에 두고 눈 막는 상자를 소녀에게 붙인다. 둘 다 씬에 꺼진 채 저장돼 있다 | `SnowShelter.cs` (새 파일) |
| 스테이지 설정 `snowShelter`, 조정 값 `birdShelterAhead`(0.6), `birdShelterCatchUp`(0.5) | `Stage.cs`, `GameTuning.cs` |
| Main: `Intro.snowShelter` 켬, `SnowShelter` 오브젝트(그림자 복제 `ShelterShadow` 크기 1.6, 눈 막는 상자 `ShelterSnowBlock` 1.8 × 4.8 × 1.8), `World/Snowfall` 의 Trigger 모듈이 그 상자 안의 눈을 지운다(씬 오버라이드, 프리팹은 그대로) | `Main.unity` |
| 한 번 쓰는 배치 스크립트, 플레이 검사 | `AgentScripts/SetupSnowShelter.cs`, `AgentScripts/VerifySnowShelter.cs` |

`GameTuning.asset` 은 고치지 않았다. 새 값 두 개는 코드의 기본값을 쓴다.

## 검증

| 무엇 | 결과 |
|------|------|
| 컴파일 | 에러 0 |
| `VerifySnowShelter.Run` (Main) | 통과. 잠든 소녀 클릭은 평소 클릭. 멀리서 시작하면 닿기 전에는 그림자·눈 막기 없음. 닿은 뒤 목표 위치와 거리 0.00 m, 1 초 동안 새와 소녀가 같은 거리(0.27 ~ 0.97 m) 이동, 소녀 둘레 눈 0 개(옆 기둥 4 개에 11 개), 고개와 새 사이 17°. 떼면 0.6 초 안에 모두 꺼짐. 누른 채로 빛기둥에 닿으면 끝남 |
| 눈 비교(누르지 않음 / 누름) | 소녀 둘레 40 / 0 개, 옆 기둥 88 / 46 개 |
| 화면 캡처 | 소녀와 그 뒤 땅에 날개 모양 그림자. 캡처 파일은 지웠다 |
| Main 스테이지 1·2 검사 8 개 | 모두 통과 |
| Play 중 콘솔 에러 | 0 |
