# Sam_Test의 스테이지 1·2를 Main 씬으로 옮기기, 반복 오브젝트 프리팹화

## 왜 했나

디렉터가 `Main` 씬을 공용 게임 씬으로 정했다. Main 의 스테이지 1 고목은 예전 회색 상자였고, 머지 뒤 `LeaningLog` 의 `animator`, `fallClip` 이 비어 있어 고목이 쓰러질 때 `UnassignedReferenceException` 이 나고 아기가 z 19 에서 멈췄다. 스테이지 2 의 토끼 장면은 Main 에 아예 없었다.

디렉터 지시(`AGENTS.md`)도 지켜야 했다. 반복 오브젝트는 프리팹으로 만들고, 씬은 에디터에서 구성해 저장하고, 런타임에 만들거나 저장된 설정을 덮어쓰지 않는다. 팀원이 Main 에 넣은 새 설정(수채화 컴포넌트, SunlitSpot 프리팹, 눈과 조명, 새 고도 4, 아기 크기 2)은 그대로 둔다.

## 남은 것

- Main 의 아기는 크기 2 다. 스테이지 2 배치는 크기 1 기준이라 아기가 눈둑만큼 크게 보인다. 크기는 팀원 설정이라 바꾸지 않았다. 배치를 다시 볼지는 레벨 디자인에서 정한다.
- `BabyRabbit` 프리팹의 출구 점은 씬 오브젝트라 프리팹에 저장할 수 없다. 새로 놓을 때는 씬에서 출구 점 2개를 이어야 한다.
- `Sam_Test` 는 개인 시험 씬으로 남는다. 앞으로 스테이지 1·2 를 고칠 때는 Main 에서 고친다.
