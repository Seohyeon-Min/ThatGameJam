# 눈 막아주기에서 새 그림자 빼기 (ADR 0026)

## 왜 했나

사용자 피드백. 낮게 나는 것만으로 막아준다는 느낌이 충분해서 그림자는 뺀다. 소녀가 중간에 멈추는 동작은 지금처럼 두고, 사용자가 팀과 상의해서 정한다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 그림자 복제(`ShelterShadow`)를 지웠다 | `Main.unity` |
| `SnowShelter` 는 눈 막는 상자만 켜고 끈다. `sun`, `shadowCaster`, `aimHeight`, `casterDistance`, `fadeTime` 필드를 지웠다 | `SnowShelter.cs` |
| 배치 스크립트와 검사에서 그림자를 뺐다 | `AgentScripts/SetupSnowShelter.cs`, `AgentScripts/VerifySnowShelter.cs` |
