# 스테이지 3: 고도 70%, 길 늘리기, 화면 밖 울음을 가장자리에, 나무는 트리 제너레이터로 (ADR 0031)

## 왜 했나

디렉터의 지시 2번의 1 ~ 4(`order_from_director.md`). 고도 제한 70%, 짧은 길, 화면 밖 동물의 울음이 안 보임, 길 옆에 가지런한 잎 없는 나무. 원인 조사와 사용자의 결정은 [ADR 0031](../../decisions/0031-스테이지-3-길을-늘리고-나무를-트리-제너레이터에.md) 에 있다.

Main 씬. 인트로를 건너뛰고 개발용 "다음 스테이지" 로 스테이지 3(계절 3)에 갔다.

| 무엇 | 결과 |
