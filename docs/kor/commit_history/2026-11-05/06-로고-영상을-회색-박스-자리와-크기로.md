# 로고 영상을 처음 회색 박스의 자리와 크기로

## 왜 했나

디렉터 요청. 앞 커밋에서 화면 전체(16:9)에 띄운 로고 영상을, 처음 회색 타이틀 박스가 있던 위치와 크기에 맞춘다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| `Title` 의 RectTransform 을 원래 값으로. 앵커 (0.5, 0.7), 크기 640×200. `AspectRatioFitter` 를 뺐다 | `Main.unity`, `AgentScripts/SetupTitleVideo.cs` |
| 영상(16:9)이 박스(3.2:1)보다 높으므로 늘리지 않고 `RawImage.uvRect` 로 잘라 보여 준다. 가로 전체, 세로는 아래에서 0.15 ~ 0.71(로고가 0.21 ~ 0.65 에 있다) | 같은 곳 |

## 검증

| 무엇 | 결과 |
|------|------|
| Play Mode 캡처, 영상 끝 프레임(299/300) | 로고가 화면 위쪽 가운데, 예전 박스 자리에 비율 그대로 보인다. 잘린 곳 없음. 콘솔 오류 0 |

## 크로스 모델 리뷰

GPT-6.1 Sol, 정확성·웹 플랫폼·견고성 렌즈. `LGTM - no blockers`.
