# 안개 미로에서 새가 부르면 소녀는 뒤쪽이어도 뛰어간다 (ADR 0033)

## 왜 했나

디렉터의 지시 2번의 5(`order_from_director.md`). 소녀가 틀린 길, 역방향으로는 잘 따라오지 않는다. 확인해 보니 ADR 0028 이 소녀가 갈 수 있는 길을 지금 길과 바로 앞 갈림길의 두 갈래로 막아 두었다. 재현과 결정은 [ADR 0033](../../decisions/0033-안개-미로에서-새가-부르면-소녀는-어디든-뛰어간다.md) 에 있다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 울음에 미로의 모든 길 중 새와 가장 가까운 점으로. `Reachable` 을 지웠다 | `FogMaze.cs` `RunToBird` |
| 길이 나가는 길(`Parent`)과, 함께 거치는 길까지 거슬러 간 뒤 목표 길까지 나가는 `Travel` | `FogMaze.cs` |
| 벽에 가 본 막다른 길의 갈림길에서는 기다리지 않고 맞는 길로 | `FogMaze.cs` `WalkOn` |
| 4.12 | `docs/kor/implementation_plan.md`, `docs/eng/implementation_plan.md` |

## 검증

Main 씬 Play Mode, 스테이지 3. 소녀를 깨우고 3 배속으로 걷게 한 뒤, 새를 옮겨 `CryListener.Broadcast` 로 울렸다. 소녀의 자리와 길 번호를 프레임마다 기록했다.

| 무엇 | 결과 |
|------|------|
| 고치기 전, 소녀는 세 번째 갈림길, 새는 지나온 두 번째 막다른 길 | 갈림길에서 3 초 서 있다가 새와 반대쪽으로 걸어감 |
| 고치기 전, 새가 앞의 막다른 길 | 막다른 길로 뛰어감(정상) |
| 고친 뒤, 소녀는 way 4, 새는 첫 막다른 길(way 7) 한가운데 | way 4 → 3 → 2 → 1 → 0 → 7 로 거슬러 가 새 지점에 도착(0.0 m). 뛰는 속도 2.5 m/s, 길에서 벗어난 거리 최대 0.01 m |
| 고친 뒤, 벽에 가 본 적 없는 첫 막다른 길로 불림 | 새 지점에서 3 초 뒤 벽 앞 끝(z 120.5)까지 갔다가 돌아 나옴 |
| 그 뒤 두 번째 갈림길(그 막다른 길의 벽에 가 본 곳) | 0.8 초 만에 지나 맞는 길로. 세 번째 갈림길(가 본 적 없음)은 다시 50:50 |
| 컴파일, 콘솔 | 오류 0 |
