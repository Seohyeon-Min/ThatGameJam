# 인트로 타이틀의 회색 박스를 로고 영상으로

## 왜 했나

디렉터 요청(`order_from_director.md` 1번). 인트로(새가 구름 위를 나는 첫 장면)의 회색 타이틀 박스를 지우고 게임 로고 영상 `primavis_anim.webm` 을 재생한다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 로고 영상. 웹 빌드는 VideoClip 에셋을 재생하지 못하고 URL 로만 재생하므로 StreamingAssets 에 둔다 | `Assets/StreamingAssets/primavis_anim.webm` |
| `IntroCanvas/Title`: 회색 `Image` 를 지우고 `RawImage`, `AspectRatioFitter`(화면 안에 16:9), `VideoPlayer`(URL, 렌더 텍스처, 소리 없음, 반복 없음), `StreamingVideo` 를 붙임. `IntroSequence.title` 은 새 `RawImage` 를 가리킨다. 페이드와 끄기는 그대로 | `Main.unity` |
| 켜질 때 StreamingAssets URL 을 넣고 재생한다. URL 은 실행할 때만 알 수 있다. 렌더 텍스처는 지난 그림을 들고 있으므로 재생 전에 투명하게 지운다 | `Assets/02_Scripts/Flow/StreamingVideo.cs` |
| 영상을 받는 1920×1080 렌더 텍스처 | `Assets/01_Arts/Video/TitleLogo.renderTexture` |
| 위 설정을 하는 빌더 | `AgentScripts/SetupTitleVideo.cs` |

## 중요한 결정

- 처음 받은 영상은 VP9 였다. Unity 는 webm 을 VP8 만 직접 디코드하므로 에디터에서 `Unsupported video codec 'VP9'` 가 났다. 디렉터가 알파를 살린 VP8 로 다시 인코딩해 넣었다(중간에 받은 VP8 은 알파가 없어 배경이 검었다).
- 크기는 화면 전체에 16:9 로 맞췄다. 영상이 1920×1080 화면 구성이기 때문이다. 한 번만 재생한다.

## 검증

| 무엇 | 결과 |
|------|------|
| Play Mode, 인트로 시작 뒤 캡처 | 구름 위에 투명 배경으로 "primavis" 로고가 나타난다. 콘솔 오류 0 |
| 렌더 텍스처 지우기 전후 | 전에는 지난 Play 의 검은 배경 프레임이 3 초쯤 보였다. 지운 뒤에는 첫 프레임 전까지 아무것도 안 보인다 |

웹 빌드에서는 확인하지 않았다. Safari 는 webm 알파를 지원하지 않을 수 있다.
