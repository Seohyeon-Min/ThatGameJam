# 화면 밖 울음을 거리에 따라, 지나간 동물은 대답하지 않게 (ADR 0032)

## 왜 했나

ADR 0031 뒤 사용자의 피드백. 화면 밖 동물의 울음이 거리와 상관없이 늘 반쯤 같은 크기로 보인다. 첫 번째 동물을 지나서 울어도 첫 번째 동물이 대답한다. 원인과 결정은 [ADR 0032](../../decisions/0032-화면-밖-울음은-거리에-따라-지나간-동물은-대답하지-않는다.md) 에 있다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| `AnswerAhead`: Z 로 새보다 앞의 첫 동물이 대답. 막다른 길 규칙, `animalAt`, `wayStart`, `AllWays` 를 지웠다 | `FogMaze.cs` |
| 화면 밖 울음의 크기와 보이는 폭을 새와의 거리로. 안으로 줄인 화면 사각형까지 가는 자리라 모서리에서도 이어진다 | `FogForkAnimal.cs` `PlaceCry` |
| `ringRadius` 1.8, `nearDistance` 25, `farDistance` 70, `nearShown` 2/3, `farShown` 0.2, `farScale` 0.4, `edgeDepth` 4 | `FogForkAnimal.prefab` |
| 4.12 | `docs/kor/implementation_plan.md`, `docs/eng/implementation_plan.md` |

새 필드를 처음 넣었을 때의 값이 에디터 메모리의 인스턴스에 남아, 코드 기본값을 바꿔도 Play Mode 에 반영되지 않았다. 그래서 값을 프리팹 에셋에 적어 저장했다.

## 검증

Main 씬 Play Mode, 스테이지 3(계절 3).

| 무엇 | 결과 |
|------|------|
| 새의 자리별로 `AnswerAhead` 를 부름 | z 90 → 다람쥐(z 100). 첫 막다른 길 위 z 115, 120 → 새(z 143). z 141 → 새, z 145 → 여우(z 185). z 200 → 사슴(z 231). z 320 → 없음 |
| 사슴이 화면 안(15 m) | 사슴 자리, 크기 1 |
| 사슴이 화면 밖 26.7 m | 화면 오른쪽 가장자리, 크기 0.22. 찍은 그림에서 링 폭의 72% 가 보임(멈춘 순간 링이 아직 커지는 중이라 2/3 보다 조금 큼) |
| 곰이 화면 밖 150 m | 오른쪽 위 가장자리, 크기 0.09. 작은 호만 보임 |
| 컴파일, 콘솔 | 오류 0 |
