# 웹 빌드 최적화 1차: 웹을 PC 품질 레벨로, 다운로드 크기 줄이기 (ADR 0037)

## 왜 했나

디렉터가 웹 빌드 최적화를 시켰다. 읽기 전용 감사 3개(에셋, 렌더링, 스크립트)를 돌렸고, 사용자가 1단계(웹이 쓰는 렌더러 정하기)와 2단계(설정만 바꾸는 크기 줄이기)를 먼저 하라고 했다. 프레임 멈춤을 줄이는 B 단계는 다음 세션에 한다.

## 중요한 결정

- 웹은 `PC` 품질 레벨 하나를 쓴다. 처음에는 `Mobile` 을 웹 렌더러로 맞췄지만 그림자가 크게 나빠져 바꿨다. [ADR 0037](../../decisions/0037-웹-빌드는-PC-품질-레벨과-긴-음악만-Vorbis.md).
- 긴 음악만 Vorbis, 짧은 효과음은 PCM(사용자 결정). JU 가 PCM 으로 바꾼 의도를 지킨다.

## 검증

| 무엇 | 결과 |

| 브라우저 플레이 (사용자, Brotli 헤더를 붙이는 로컬 서버) | 안개와 그림자 정상. 게임 시작, 구름, 계절 전환, 안개 초반, 엔딩에서 소리가 끊긴다. DSP 버퍼를 키운 뒤 끊기는 소리가 더 길어졌다 |
| 에디터 콘솔 | 컴파일 오류 0 |
| 텍스처와 클립 크기(에디터) | `fox_temp` 512 DXT5, 소녀 머리 512 DXT1, Rabbit 클립 16.5 MB → 2.5 MB. `EncyclopediaBase` 는 1024x579 RGBA32 로 남는다(4 의 배수가 아니라 블록 압축 불가) |

빌드하다 찾은 것: FMOD 에 `event:/Ambience/water` 이벤트가 2개 있다(JU, `2f54b8c`). 그래서 FMOD Unity 의 뱅크 갱신이 이벤트 캐시에서 실패하고 `Assets/StreamingAssets/Master.bank` 가 복사되지 않았다. 이 PC 의 웹 빌드에는 그동안 11-02 뱅크가 들어갔다. 이번에는 새 뱅크를 손으로 복사했다(이 파일은 git 이 추적하지 않는다).
