# 이스터에그 공터에 다시 나무 심기

## 왜 했나

이스터에그 자리가 정해져 스테이지 안으로 옮겨졌다. ADR 0034 가 "자리가 정해지면 공터와 범위 확장을 되돌린다"고 적어 둔 대로, 인트로 출발점 뒤 공터를 다시 숲으로 채운다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 월드 숲의 `EasterEgg Clearing` Clear 구역 삭제, 뒤쪽 패딩 1.5 → 13.878445 m (공터 전 값), 다시 생성 | `Main.unity` 의 `01_SYSTEM/TreeGenerator` |
| 공터 뒤 숲 생성기 삭제 (나무 60 그루 포함) | `01_SYSTEM/TreeGenerator_ClearingBack` |
| 인트로의 새 범위 뒤 끝 z −35 → −26 (공터 전 값) | `Stages/Intro` 의 `Stage.area` |
| 빌더 | `AgentScripts/ReplantClearing.cs` |
| 공터 설명 | `easter_eggs.md` 4절, `implementation_plan.md` |

철새(`MigratingBirds`)는 아직 `Stages/Intro/EasterEggs` 아래 z −27.5 에 있다. 최대 줌아웃으로 발동해 위치와 상관이 적어 그대로 두었다.
