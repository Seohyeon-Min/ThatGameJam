# 고드름 실로폰: 가지마다 앉는 자리 하나, 고드름 쪽으로 돌아서 쪼기 (ADR 0038)

## 왜 했나

디렉터가 시켰다. 앉는 가지를 2 개로 하고, 한 가지 위에서 그 아래 고드름을 다 칠 수 있게 한다. 그리고 쪼는 방향을 그 고드름 쪽으로 바꾼다. 예전 빌더도 같은 구조를 만들게 고친다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 고드름마다 있던 `Perchable` 8 개와 `TapFrom` 8 개를 지우고, `Cylinder 8` 아래에 `Branch_Right`, `Branch_Left` 를 둔다 | `Assets/03_Prefabs/EasterEggs/IcicleXylophone.prefab`, `AgentScripts/IcicleBranchPerches.cs` |
| `Perchable.clickedThrough`: 이 목록의 콜라이더를 누르면 새가 이 자리로 온다 | `Assets/02_Scripts/Core/Perchable.cs`, `BirdController.PerchableAt` |
| 앉아 있을 때 제자리에서 도는 `TurnToward`. 내려앉을 때 `facingYaw` 를 실제 방향으로 맞춘다 | `Assets/02_Scripts/Bird/BirdController.cs` |
| 같은 가지의 고드름은 그 자리에서 돌아서 쫀다. 다른 가지의 고드름을 누르면 기억해 두었다가 내려앉을 때 친다 | `Assets/02_Scripts/EasterEggs/IcicleXylophone.cs` |
| 빌더가 고드름을 가장 가까운 가지 메시로 묶어 가지마다 자리를 하나 만든다 | `AgentScripts/BuildEasterEggs.cs` |

## 검증

| 무엇 | 결과 |
|------|------|
| `AgentScripts/VerifyIcicleBranches.cs` (Main, Play Mode, 가상 마우스) | 고드름 8 개 모두 울림. 같은 가지에서 0 m 이동. 방향 차이 0~7°. 새 바로 옆 고드름 두 개는 16°와 31°였다. 흔들리기 시작한 뒤에 쟀기 때문일 수 있다 |
| `BuildEasterEggs.cs` dry run | 컴파일 성공. 실행은 하지 않았다(다른 이스터에그 프리팹도 다시 만든다) |
| 교차 리뷰 (gpt-6.1-sol) | warn 3 개 |

## 리뷰

- `clickedThrough` 가 null 이면 예외가 난다 → `= { }` 로 초기화했다.
- 도는 동안 새가 날아가도 쪼았다 → 다 돈 뒤 다시 확인하고, 새가 없으면 그만둔다.
- 다른 곳으로 가도 `aimed` 가 남는다 → 고치지 않았다. 가지에는 콜라이더가 없어서 새가 그 가지에 내려앉으려면 그 가지의 고드름을 눌러야 한다. 그 클릭이 `aimed` 를 덮어쓴다.
