# origin/JU 머지: 도감 키를 Esc 로

## 왜 했나

JU 브랜치(`origin/JU`)의 새 커밋 `9b30835 esc` 를 `sam` 에 받는다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 도감을 여닫는 키가 `` ` `` 에서 Esc 로 바뀌었다 | `Encyclopedia.cs` |
| 디버그용 인트로·컷신 건너뛰기 키가 Esc 에서 0 으로 바뀌었다 (Esc 는 도감 키) | `IntroSequence.cs`, `Cutscene.cs` |
| 도감 프리팹에 Esc 안내 이미지 `EscHint` 가 추가됐다 | `Assets/03_Prefabs/UI/Encyclopedia.prefab` |

충돌 없이 git 이 합친 그대로다. 씬은 바뀌지 않았다.

## 중요한 결정

- 웹 브라우저에서 Esc 는 전체화면과 포인터 잠금을 푸는 키이기도 하다. 전체화면에서 도감이 같이 열리거나 안 열릴 수 있어 웹 빌드에서 확인이 필요하다. 이번 머지에서는 JU 의 결정을 그대로 받았다.

## 검증

| 무엇 | 결과 |
|------|------|
| 에디터에서 다시 컴파일 | 성공, 컴파일 에러 0 |
| Play Mode, 웹 빌드 | 돌려 보지 않았다 |

## 크로스 모델 리뷰

하지 않았다. 다른 사람 브랜치를 충돌 없이 받은 머지다.
