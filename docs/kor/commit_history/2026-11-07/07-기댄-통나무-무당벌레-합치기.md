# 기댄 통나무 그루터기 하나로 합치기: JU 의 프리팹에 1 초 기어가기와 새 없는 사진

## 왜 했나

사용자가 시켰다. 06 머지에서 무당벌레 그루터기를 둘 다 남긴 것은 잘못 이해한 것이었다. 사용자의 뜻은 JU 의 그루터기와 `sam` 의 변경을 하나로 합치는 것이다. 프리팹 이름과 자리는 JU 를 따르고, `sam` 의 "1 초 기어 나온 뒤 찍힌다"와 "사진에 새가 들어가지 않는다"를 넣는다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 이스터에그 `StumpLadybug` 인스턴스를 씬에서 지웠다 (JU 와 같다). 프리팹 파일은 남아 있다 | `Stages/Stage1/StumpLadybug` |
| `LeaningLogStump` 의 무당벌레 두 마리 모두 `CrawlTo` 를 같은 방향으로 당겨 거리를 `crawlSpeed × 무당벌레 크기 × 1 초` = 0.084 m 로 (4.17 초 → 1 초, 4.79 초 → 1 초). `CrawlTo` 는 씬의 프리팹 오버라이드, `CrawlTo2` 는 씬 오브젝트다 | `Stages/Stage1/LeaningLog/broken tree/LeaningLogStump` |
| 새 없는 사진: 이 그루터기의 `Discovery.showBird` 는 이미 꺼져 있다 (기본값). 바꾼 것 없음 | 같은 자리 |
| 설명 | `easter_eggs.md` |

씬을 저장하면서 개울 메시(`WindingWater`)의 fileID 가 다시 바뀌었다. 내용은 같다.
