# 사전 사진에서 플레이어 새를 빼고, 무당벌레가 1 초만 기어 나온 뒤 찍히게 하기

## 왜 했나

사용자가 시켰다. 눈 속의 꽃은 새가 쪼던 자리에서 바로 찍혀서 사전 사진에서 새가 꽃을 가렸다. 철새를 빼고는 새 없이 찍히게 한다. 그루터기 무당벌레는 사진이 찍히기까지 너무 오래 걸렸다. 나와서 1 초쯤 기어간 뒤 찍히게 거리를 줄인다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| `Discover` 에 `showBird` 를 받는다. 끄면 사진 한 장을 렌더하는 동안만 새의 렌더러를 `forceRenderingOff` 로 끈다. 렌더 요청은 바로 그려지므로 게임 화면에는 영향이 없다 | `Assets/02_Scripts/Encyclopedia/Encyclopedia.cs` |
| `Discovery.showBird` (기본 꺼짐) | `Assets/02_Scripts/EasterEggs/Discovery.cs` |
| 철새와 절벽 메아리(새를 찍는 사진)는 `showBird` 를 켰다 | `Assets/03_Prefabs/EasterEggs/MigratingBirds.prefab`, `CliffEcho.prefab` |
| `CrawlTo` 를 같은 방향으로 당겨 거리를 `crawlSpeed × 무당벌레 크기 × 1 초` 로. 프리팹 1.03 → 0.10 m, 씬의 `broken tree/Tube 1` 0.75 → 0.14 m | `Assets/03_Prefabs/EasterEggs/StumpLadybug.prefab`, `Assets/00_Scenes/Main.unity` |
| 사진에서 새를 뺀다는 설명 | `docs/kor/easter_eggs.md` |

Main 씬을 저장하면서 씬에 들어 있는 메시의 fileID 가 바뀌고 `clickedThrough: []`, `showBird: 0` 이 써졌다. 값이 바뀐 것은 `Tube 1` 의 `CrawlTo` 뿐이다.

## 검증

| 무엇 | 결과 |
|------|------|
| Play Mode, Main. 눈 속의 꽃 위에 새를 두고 `Discover` 를 `showBird` 켜고/끄고 두 번 불러 사진을 PNG 로 저장 | 켜면 새가 화면을 거의 다 가린다. 끄면 새와 그 그림자 없이 눈더미만 찍힌다. 찍은 뒤 새 렌더러는 모두 다시 켜졌다 |
| 무당벌레 두 곳의 거리 / 속도 | 둘 다 1.00 초 |
| 교차 리뷰 (gpt-6.1-sol) | warn 2 개 |

## 리뷰

- 원래 `forceRenderingOff` 가 켜져 있던 렌더러도 꺼짐으로 돌려 놓는다 → 고치지 않았다. 새의 렌더러에 `forceRenderingOff` 를 쓰는 코드는 이것뿐이다(`HiddenUntilSeason` 은 새에 없다).
- 렌더 요청에서 예외가 나면 새가 숨은 채로 남는다 → 고치지 않았다. 그런 실패를 본 적이 없고, 실패를 대비한 코드를 미리 넣지 않는다.

## 남은 것

- 산수유도 이제 새 없이 찍힌다. 새가 가슴을 부풀리는 모습을 넣고 싶으면 그 프리팹의 `showBird` 를 켠다.
