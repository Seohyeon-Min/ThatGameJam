# 사전 로딩 후 웹 Profiler 측정

## 측정

사용자가 구름부터 엔딩, 절벽 메아리까지 플레이. 사전 로딩 포함 Development 웹 빌드. Builds/profile/frames_174526.csv, spikes_174526.txt. 43,571프레임, 마지막 시간 446.057초, 50ms 이상 124프레임(시작 2프레임 포함). tree는 깊이12/2ms 이상만 기록하므로 더 깊은 자식 비용을 알 수 없는 경우가 있다. Development 부하와 WaitForTargetFPS를 실제 연산 지연으로 혼동하지 않는다.
