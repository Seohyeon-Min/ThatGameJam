# 로고 영상을 4.5 초로 자르기: 로고가 다 그려진 뒤 바로 클릭이 열린다

## 왜 했나

사용자가 물었다. 처음 화면에서 로고가 다 보인 뒤에도 한동안 클릭해도 게임이 시작하지 않는다.

`IntroSequence.WaitForLogo` 는 정해진 시간이 아니라 영상이 끝까지 재생되기(`loopPointReached`)를 기다린다. 재생 실패나 `logoMaxSeconds`(15 초)도 클릭을 연다. 영상 `primavis_anim.webm` 은 10.01 초인데, 글씨와 민들레는 약 4.2 초에 다 그려지고 나머지 약 6 초는 거의 멈춘 화면이었다. 헤드폰 문구는 4 초에 나와서, 문구가 보인 뒤에도 6 초쯤 클릭이 막혔다.

사용자가 고치는 방법 셋 중 영상 자르기를 골랐다. `sam` 브랜치는 에셋을 임의로 만들지 않는 규칙이 있으나 사용자가 직접 시켰다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 앞 4.5 초만 남기고 다시 인코딩했다. VP8, 알파 유지(`yuva420p`, `alpha_mode=1`), 목표 400 kb/s. 소리 트랙은 원래 없다 | `Assets/StreamingAssets/primavis_anim.webm` |

코드와 씬은 바꾸지 않았다. 클릭은 여전히 영상 끝에서 열리므로 약 4.5 초(웹에서는 영상 로딩 시간을 더해서)에 열린다.

## 검증

| 무엇 | 결과 |
|------|------|
| `ffprobe` 길이 | 4.504 초 |
| 0.5 초마다 뽑은 프레임 | 그려지는 과정과 마지막 정지 화면이 원본과 같다 |
| 마지막 프레임을 원본과 원래 크기로 비교 | 눈에 띄는 화질 차이 없음 |
| 파일 크기 | 383 KiB (원본 420 KiB) |
| Play Mode, 웹 빌드 | 돌려 보지 않았다 |

## 크로스 모델 리뷰

하지 않았다. 코드가 아니라 영상 파일 하나만 바뀌었다.
