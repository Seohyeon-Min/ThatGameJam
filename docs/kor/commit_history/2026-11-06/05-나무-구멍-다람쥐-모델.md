# 나무 구멍 다람쥐에 다람쥐 모델을 넣음

## 왜 했나

사용자 요청. 사용자가 다람쥐 모델(`SquirrelUnity-Animations-*.zip`, Generic 리그, 클립 `Hop`, `SitIdle`, `SitIdle_LookAround`)을 프로젝트 폴더에 넣었다. `HollowSquirrel` 의 자리 표시 캡슐을 이 모델로 바꾼다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| FBX 와 zip 안 unitypackage 의 `.meta`(클립 이름, 루프), README, 클립 json, 검증 결과를 가져온다. 클립마다 상태를 하나씩 둔 Animator Controller(기본 `SitIdle_LookAround`)와 프리팹을 만든다 | `AgentScripts/SetupSquirrelModel.cs`, `Assets/01_Arts/Models/Squirrel/`, `Assets/03_Prefabs/Squirrel.prefab` |
| 캡슐을 지우고 `Squirrel.prefab` 을 0.35 배로 넣었다(앉은 키 약 0.24 m) | `HollowSquirrel.prefab` 의 `Squirrel` |
| 구멍 위치를 바로잡았다. `thickTree.obj` 의 구멍은 모델의 +Z 쪽(높이 약 0.6 m)에 있는데, 다람쥐는 구멍이 없는 −Z 면에서 나왔다. 나무를 180° 돌려 구멍이 프리팹의 −Z 를 보게 했다. 그래서 `Main` 의 배치(−45°, 카메라 쪽)는 그대로 둔다 | `HollowSquirrel.prefab` 의 `thickTree` |
| `Inside` 는 구멍 입구 아래(나무 속에 숨는 자리), `Peek` 은 입구 가장자리다. 다람쥐가 아래에서 올라와 입구에 앉는다 | `HollowSquirrel.prefab` 의 `Inside`, `Peek` |
| 빌더도 같은 값으로 고쳤다. 쓰지 않게 된 `AnimalMaterial` 을 지웠다 | `AgentScripts/BuildEasterEggs.cs` `HollowSquirrel()` |
| 4 절 표 | `easter_eggs.md` |

## 검증

| 무엇 | 결과 |
|------|------|
| `SetupSquirrelModel.Run` | Generic, 아바타 유효, 클립 3 개 모두 루프, 머티리얼 3 개 URP Lit |
| 프리뷰 씬에서 `Inside`, `Peek` 자세를 앞·옆·위에서 렌더 | `Inside` 에서는 보이지 않고, `Peek` 에서는 입구에 앉아 머리가 나무 밖으로 나온다 |
| Play Mode, `Main`: 인트로를 건너뛰고 새를 옮긴 뒤 가상 마우스 오른쪽 클릭(울음) | 다람쥐가 `Peek` 에 닿음, Animator 가 `SitIdle_LookAround` 재생, 다시 `Inside` 로 돌아감, 사전 `06_HollowSquirrel` 발견 |
| `BuildEasterEggs.cs` dry run 컴파일 | 성공 |

## 남은 것

- 빌더 전체(`BuildEasterEggs.Run`)는 다시 돌리지 않았다. 프리팹만 직접 고쳤고, 빌더는 같은 값을 만들도록 맞췄다.
- 나무를 피벗 기준으로 돌려서 `Main` 에서 나무 줄기가 약 0.4 m 옮겨졌다.
- 게임 카메라 거리에서 다람쥐는 작게 보인다. 크기는 프리팹의 `Squirrel/Squirrel` 스케일로 바꾸면 된다.

크로스 모델 리뷰는 06 과 함께 했다.
