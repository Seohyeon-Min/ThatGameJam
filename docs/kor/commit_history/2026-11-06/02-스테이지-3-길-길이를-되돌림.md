# 스테이지 3 길 길이를 ADR 0031 전으로 되돌림

## 왜 했나

디렉터 요청. ADR 0031 에서 맞는 길을 2배, 막다른 길을 1.5배로 늘렸는데, 이것을 원래대로 줄인다. ADR 0031 의 다른 내용(고도 제한, 화면 가장자리 울음, 트리 제너레이터 나무 등)은 그대로 둔다. 이번 세션은 ADR 과 `implementation_plan.md` 를 쓰지 않기로 해서 기록은 여기만 있다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| `RightMoves`, `DeadMoves` 를 ADR 0028 의 첫 맵 값으로. 맞는 길 22 ~ 28 m, 막다른 길 14 ~ 18 m | `AgentScripts/BuildStage3.cs` |
| `MakeRoom` 이 땅이 너무 길면 줄인다. 길이 넘는 만큼을 `joinZ` 바로 뒤에서 빼는데(`WorldGap.Open` 에 음수), 그 자리가 전에 땅을 늘릴 때 늘어난 곳이다 | `AgentScripts/BuildStage3.cs` `MakeRoom` |
| 빌더를 다시 돌린 스테이지 3. 땅 129.2 m 줄임, 목표 z 227.2, 낭떠러지 z 251.2, 세계 나무·꽃·풀 다시 생성 | `Main.unity`, `SamTestTerrain.asset` |

빌더를 돌리면서 바뀐 구운 나무 에셋(`01_Arts/Baked`)과 줄바꿈만 바뀐 파일은 되돌렸다.
