# 소녀가 화면 밖이면 새의 울음 원이 말풍선이 되어 소녀 쪽을 가리킴

## 왜 했나

디렉터 요청(`order_from_director.md`, 그림 `Untitled.png`). 인트로 스테이지 다음부터, 소녀가 화면에 없을 때 새가 우클릭으로 울면 하얀 원이 소녀가 있는 쪽을 가리키게 한다. 그림은 한쪽 모서리가 뾰족한 말풍선이다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 꼬리를 켜면 원에 삼각형을 더한 말풍선을 그린다. 꼬리 끝은 원 반지름의 `_TailTip`(1.45)배. 꼬리가 꺼져 있으면 전과 같은 원이다 | `GlowRing.shader` |
| 울 때마다 꼬리를 켤지 정한다: 지금 스테이지가 첫 스테이지(인트로)가 아니고, 소녀의 발 0.6 m 위(`girlHeight`)가 화면 밖일 때. 켜면 원 크기를 지키려고 파티클 시작 크기를 `_TailTip` 배로 키운다. 원이 떠 있는 동안 화면에서 소녀 쪽으로 꼬리를 돌린다 | `CryTail.cs` (새 파일) |
| 원을 띄우기 전에 `CryTail.Aim()` | `BirdController.cs` `Cry` |
| `Ring` 에 `CryTail` | `BirdCryPulse.prefab` |

꼬리 방향은 렌더러의 MaterialPropertyBlock 으로 넘긴다. 울음 쿨다운(0.8초)이 원의 수명(0.6초)보다 길어 원이 겹치지 않는다. 안개 동물의 대답도 같은 프리팹을 쓰지만 `Aim` 을 부르지 않아 늘 원이다. 새 텍스처나 머티리얼은 만들지 않았다.

## 검증

Main 씬 Play Mode. 인트로를 건너뛰고 스테이지 1 에서 새를 옮겨 가며 울음을 띄우고 찍었다.

| 무엇 | 결과 |
|------|------|
| 소녀가 화면 왼쪽 아래 밖 | 말풍선, 꼬리가 왼쪽 아래 |
| 소녀가 화면 오른쪽 아래 밖 | 말풍선, 꼬리가 오른쪽 아래 |
| 소녀가 화면 안 | 전과 같은 원, 크기 배율 1 |
| 인트로 스테이지, 소녀가 화면 밖 | 꼬리 없음 |
| 셰이더 컴파일, 스크립트 컴파일, 콘솔 | 오류 0 |

실제 마우스 우클릭이 아니라 스크립트로 `Aim` 과 파티클을 불렀다.
