# 이스터에그 공터 배치 그림

## 왜 했나

사용자 요청. 인트로 뒤 공터에 이스터에그가 어떻게 놓였는지 `easter_eggs.md` 에 아스키 그림으로 남긴다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 위에서 본 전체 그림(인트로 시작, 공터, 새 범위 끝, 공터 뒤 숲), 공터 안 그림, 프리팹별 위치·회전 표 | `easter_eggs.md` 4 절 「공터 배치」 |

## 검증

| 무엇 | 결과 |
|------|------|
| 그림의 좌표와 저장된 `Main.unity` 의 프리팹 인스턴스 위치·회전 | `BuildEasterEggs.PlaceInMain` 의 값과 같다 |

카메라 방향(+X, −Z 에서 봄)은 빌더 주석을 따랐고 화면으로 다시 확인하지 않았다. 문서만 바꿔서 크로스 모델 리뷰는 하지 않았다.
