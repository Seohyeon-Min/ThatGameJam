# Zzz 를 일어나는 동안에는 끄고, 머리 너머에서 작게 나오게

## 왜 했나

사용자 피드백(11 의 Zzz). 일어나는 모션에서는 Zzz 가 없어도 된다. 파티클이 소녀의 중심에서 나오는 것처럼 보이니, 누웠을 때 머리 쪽의 바깥에서 나오게 한다. 크기를 줄인다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 깨어남(`Waking`) 상태에서는 방출하지 않는다. 잠과 눕기의 끝(`Sleeping`, `Resting`)만 | `Baby.UpdateSleepZzz` |
| 방출 위치: 머리 뼈 기준, 잠든 자세(`Girl_Sleep`)에서 머리가 향하는 쪽(몸 바깥)으로 0.5 m, 위로 0.3 m. 빌더가 모델 사본을 그 자세로 놓고 머리 뼈 로컬 위치로 바꿔 넣는다 | `BuildGirlPlay.ZzzLocalPosition` |
| 크기 0.9 ~ 1.1 m → 0.6 ~ 0.75 m | `SleepZzz.prefab` |
| 빌더를 다시 돌려 `Main` 의 놀이 자리도 같은 자리에 다시 만들었다(씬 diff 가 큰 이유) | `Main.unity` |
