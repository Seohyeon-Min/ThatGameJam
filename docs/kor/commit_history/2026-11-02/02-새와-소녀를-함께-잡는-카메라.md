# 새와 소녀가 가까우면 둘을 한 화면에 잡는 카메라

## 왜 했나

디렉터 지시(`order_from_director.md`의 상황 인식형 카메라)와 사용자가 디렉터와 나눈 대화.

- 새 혼자 있으면 새를 화면 정중앙에 둔다.
- 새와 소녀가 가까우면 둘을 한 화면에 둔다. 새가 중앙이 아니어도 된다.
- 새가 멀어지면 다시 새를 중앙에 둔다.
- 카메라는 갑자기 움직이지 않는다.
- 기믹 구간은 지금 동작(세미락) 그대로 둔다.

문서의 "아이의 상호작용에 따른 카메라 동작"(2절)은 디렉터가 빼라고 했다. 사용자가 decisions 는 쓰지 않기로 했다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 카메라가 따라가는 점을 `Framed()`가 정한다. 새와 소녀의 수평 거리가 `cameraTogetherEnterDistance`(7 m) 안이면 함께 잡기로, `cameraTogetherExitDistance`(10 m) 밖이면 새 혼자로 바뀐다. 두 거리는 줌 값을 곱해 쓴다 | `BirdCamera.cs` `Framed` |
| 두 상태 사이는 가중치 0 ~ 1 로 `cameraTogetherEaseTime`(2 초) 동안 SmoothStep 으로 옮긴다. 함께 잡을 때의 점은 새와 소녀 사이, 소녀 쪽 비율 `cameraTogetherBabyShare`(0.5)다. 높이도 포함한다 | `BirdCamera.cs` `Framed` |
| 함께 잡는 동안은 그 점이 지금 카메라 점에서 `cameraTogetherDeadZone`(1.5 m) 안에서 움직이면 카메라가 가만히 있고, 벗어난 만큼만 따라간다 | `BirdCamera.cs` `Framed` |
| 새는 화면 중심에서 화면 짧은 쪽 절반의 `cameraTogetherMaxBirdScreen`(0.8) 안에 있다. 카메라 거리 d, k = 0.8 × tan(FOV/2) × min(1, 화면비)로 카메라 점과 새 사이를 d·k/√(1+k²)(16:9, 줌 1 에서 약 5.1 m) × 가중치 안으로 묶는다. 원근에서 카메라 쪽으로 가까운 새가 크게 보이는 경우까지 넣은 값이다. 새는 화면 밖으로 못 나가므로(`BirdController.Limit`), 카메라가 소녀 쪽에 머물러 새가 화면 가장자리에 갇히는 일을 막는다. 함께 잡기가 끝나면 이 한계가 가중치와 함께 줄어, 카메라가 새를 따라잡는 속도가 정해진다 | `BirdCamera.cs` `Framed` |
| 세미락(`CameraZone`)은 이 점에 그대로 적용한다. 개발용 카메라 고정도 그대로다 | `BirdCamera.cs` `LateUpdate` |
| `Cut()` 은 다음 프레임에 바로 맞는 구도로 간다 | `BirdCamera.cs` `Cut` |
| 위 값 6개 추가 | `GameTuning.cs` |

## 중요한 결정

- 처음에는 새가 화면 안쪽 15% 여유를 벗어나면 함께 잡기를 끝내게 했다. 컷신 카메라나 인트로 전환 중에는 `Camera.main` 이 게임 카메라가 아니어서, 프레임마다 켜졌다 꺼졌다 했다(한 구간에 1048번). 화면 대신 새와 카메라 점 사이의 거리 한계로 바꿨다.
- 처음의 전환 시간 1.2 초에서는 함께 잡기가 끝날 때 카메라 점이 새 속도의 약 3.4배(17 m/s)로 움직였다. 전환 중에 새가 계속 멀어져, 중간점과 새 사이 거리가 커졌기 때문이다. 새와의 거리 한계를 가중치에 비례하게 하고 전환 시간을 2 초로 늘려 약 2배(9 ~ 11 m/s)로 줄였다.
- 에디터 메모리의 `GameTuning` 에는 처음 컴파일 때의 기본값(전환 1.2 초)이 남아 있어, 코드 기본값으로 다시 넣었다. `GameTuning.asset` 파일은 저장하지 않았다(지난 커밋의 새 값들도 파일에 없다).

## 검증

Main 씬 Play Mode. 인트로를 건너뛰고 소녀를 잠든 채로 두었다. 새는 `BirdController.Click` 을 리플렉션으로 불러 실제처럼 날렸다. 검사 스크립트(`AgentScripts/VerifyCameraFraming.cs`)는 끝난 뒤 지웠다. 속도는 0.1 초 구간 평균이고, 새 속도는 5 m/s 다.
