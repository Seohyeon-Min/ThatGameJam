# 새를 화면 중앙에, 휠로 줌·고도·걷기, 이착륙 커브, 물과 도랑에 착륙 금지

## 왜 했나

디렉터 지시(`order_from_director.md`).

1. 새가 화면 중앙보다 위에 있다. 중앙에 맞춘다.
2. 휠로 확대하면 내려가고 축소하면 올라간다. 걷기도 넣는다. 걷기 애니메이션은 아직 없으니 다른 애니메이션으로 걷는 것처럼 보이게 한다.

디렉터가 결과를 본 뒤 두 가지를 더 요청했다.

- 이륙과 착륙 때 카메라가 부자연스럽다. 애니메이션 커브를 넣는다. 휠로 땅에 내려앉고 떠오를 때와 가지에 앉고 떠날 때 둘 다 해당한다.
- 물과, 땅과 물 사이의 도랑에 착륙하지 못하게 한다.

사용자가 decisions 는 쓰지 않기로 했다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 카메라가 바라보는 점의 높이를 땅 높이에서 새 높이로 바꿨다 | `BirdCamera.cs` |
| `FollowCamera` 의 오프셋 (10, 11.5, -10) → (10.5, 10.5, -10.5). 카메라 회전(35.26°, 315°)과 방향이 어긋나 바라보는 점이 화면 세로 0.41 에 왔다. 거리 18.19 는 같다 | `Main.unity` `CinemachineFollow.FollowOffset` |
| 휠 한 칸의 줌을 `motionCurve` 를 따라 `cameraZoomDuration` 동안 바꾼다. 새에게 줌 값과 향하는 줌 값을 넘긴다 | `BirdCamera.cs` |
| 새 비행 고도를 줌으로 정한다. 줌 1 은 스테이지 고도, 최대 축소는 땅 위 높이 × `birdZoomedOutHeightScale`, 최대 확대는 스테이지 땅 위 `birdLowFlightHeight`. 땅의 굴곡 대신 스테이지 땅 높이(날 수 있는 범위의 중심 높이)를 기준으로 해서 통나무나 물 위에서 튀지 않는다 | `BirdController.cs` `FlightAltitude` |
| 높이 변화(이륙, 착륙, 스테이지 고도 변경)는 `motionCurve` 를 따라 `birdClimbDuration` 동안 바뀐다. 목표가 움직여도 그 목표로 수렴한다 | `BirdController.cs` `StartClimb`, `Climb` |
| 가지로 날아갈 때 높이를 직선 위 진행도에 커브를 씌워 바꾼다 | `BirdController.cs` `FlyToPerch` |
| 끝까지 확대하면 서 있을 수 있는 곳에 내려앉아 `Walking` 상태가 된다. 좌클릭하면 `birdWalkSpeed` 로 걷는다. 걷기 클립 대신 서 있는 클립(PerchIdle)에 몸을 튀기는 움직임을 더했다 | `BirdController.cs` `Walk`, `Hop` |
| 서 있을 수 있는 곳은 경사 `birdLandMaxSlope` 이하의 터레인뿐이다. 물(`ClickPlane`), 물가 도랑(경사 60° 이상), 통나무와 눈둑은 안 된다 | `BirdController.cs` `Landable` |
| 낮게 날 때는 아래와 앞 3m 안의 가장 높은 표면(통나무, 둑, 물)보다 `birdLowFlightHeight` 위를 난다. 그 표면보다 0.2m 이상 위가 아니면 앞으로 가지 않는다 | `BirdController.cs` `Clearance`, `Fly` |
| 걷다가 서 있을 수 없는 곳에 닿으면 날아올라 넘고, 건너편에 내려앉아 계속 걷는다. 0.5m 앞까지 서 있을 수 있어야 내려앉는다 | `BirdController.cs` `Walk`, `CanComeDown` |
| 가지에서 다른 가지로 갈 때도 이륙 동작이 끝날 때까지 제자리에 있는다. 원래는 이 경우에 대기를 무시했다 | `BirdController.cs` `HoldingForTakeoff` |
| 화면 안에 붙잡는 계산(`Limit`)을 비행 고도 대신 새의 실제 높이로 | `BirdController.cs` `Limit` |
| `motionCurve`, `cameraZoomDuration`, `birdZoomedOutHeightScale`, `birdLowFlightHeight`, `birdLandMaxSlope`, `birdClimbDuration`, `birdWalkSpeed`, `birdWalkHopHeight`, `birdWalkHopRate` 추가. `cameraZoomSpeed` 삭제 | `GameTuning.cs` |

## 중요한 결정

- 걷는 새가 물에 닿으면 물가에서 멈추지 않고 날아서 건넌다. 사용자가 제안대로 골랐다.
- 통나무와 눈둑에는 내려앉지 않는다. 처음에는 `Ground` 레이어면 서게 했다. 그랬더니 통나무 앞에서 "내려앉기 → 오르지 못해 날아오르기" 를 반복했고, 낮게 날며 통나무를 뚫고 지나갔다.
- 가지에 앉아 있을 때 카메라는 새의 실제 높이를 따라간다. 새가 커브로 움직이니 카메라도 같은 커브로 움직인다. 사용자가 골랐다.

## 남은 것

- 진짜 걷기 클립이 오면 `BirdController.Hop` 과 `Walking` 의 애니메이터 처리를 바꾼다.
- 카메라 구간이 잠긴 곳에서는 새가 중앙에서 벗어난다. 제안대로 그대로 두었다.
