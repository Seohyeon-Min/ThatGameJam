# 스테이지 3 끝에 낭떠러지와 쉼돌, 새가 화면 가장자리에 가면 엔딩 (ADR 0029)

## 왜 했나

디렉터의 지시(`order_from_director.md`). 안개 미로를 나오면 빛나는 공간 없이 낭떠러지 앞의 큰 돌까지 가고, 새가 낭떠러지 너머로 화면 가장자리 가까이 가면 엔딩을 튼다. 엔딩 애니메이션이 없으니 소녀가 처음 일어나는 클립을 튼다. 작업 전에 질문 아홉 개를 했고 사용자가 답했다. 결정은 [ADR 0029](../../decisions/0029-안개-스테이지-끝에-낭떠러지와-쉼돌을-둔다.md) 에 있다.

## 검증

Main 씬 Play Mode. 인트로를 건너뛰고 개발용 "다음 스테이지" 로 스테이지 3 에 간 뒤 8 배속으로 미로를 혼자 걷게 했다.

| 무엇 | 결과 |
|------|------|
| 미로를 나온 뒤 | 장치가 `CliffEnding` 으로 바뀌고, 소녀가 돌 옆(−1.4, 247.85)까지 걸어가 `QuietWait` |
| 돌 옆에서 새가 소녀 옆(0, 244)과 미로 위(0, 200)에서 울음 | 소녀는 그대로 서 있고, 대답한 동물 0 |
| 화면 오른쪽 위(뷰포트 0.95, 0.9)의 허공을 누름 (새의 `Click` 을 직접 불렀다. 아래 참고) | 클릭 평면(−2.2, 278.6)에 맞음. 카메라 구간이 잠기고, 새는 뷰포트 0.92 에서 멈춤. 엔딩이 시작돼 `IntroGetUp` 재생, 끝나면 `Idle` |
| 계절 | 엔딩 뒤에도 3 |
| 화면 아래를 두 번 눌러 미로 쪽으로 | 두 번째에 카메라 구간이 풀림 |
| 컴파일 | 오류 0 |

가상 마우스(`InputSystem.AddDevice`)로 누르려 했으나 위치가 (0, 0) 으로 읽혀 새가 엉뚱한 곳으로 갔다. 그래서 같은 레이를 쏴서 `BirdController.Click` 을 리플렉션으로 불렀다. 입력 코드는 바꾸지 않았다. 가상 마우스는 지우고 실제 마우스는 다시 켰고, Run In Background 도 껐다.

## 남은 것

- 낭떠러지는 터레인 끝의 곧은 선이다. 절벽 면이 없다.
- 돌은 납작한 구이고, 소녀는 앉지 않고 서 있다. 앉는 클립과 엔딩 애니메이션은 아트가 만든다.
- 기획서 §9.6 의 고도 상승, 구름 뚫기, 해피·노말 엔딩은 하지 않았다.
- 실제 마우스로는 시험하지 않았다.
