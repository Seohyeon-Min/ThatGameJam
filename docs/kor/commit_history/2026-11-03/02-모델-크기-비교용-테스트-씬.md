# 모델 크기 비교용 테스트 씬 Sam_model_test

## 왜 했나

사용자가 무당벌레 모델(`01-무당벌레-모델과-애니메이션.md`)을 볼 곳을 원했다. 처음에는 Main 인트로 스테이지에 두 마리를 두었다. 그 뒤 사용자가 Main 대신 따로 씬을 만들라고 했다. 조건은 다음과 같다.

- 씬 이름은 `Sam_model_test`
- 크기 비교용 소녀, 고목, 주위에 나무 몇 그루. 나중에 새도 넣으라고 했다
- 소녀는 천천히 앞으로 걷는다
- Main의 인트로 연출(처음에 새가 날아다니는 것 등)은 넣지 않는다
- 인트로에 둔 무당벌레는 빼서 이 씬으로 옮긴다

## 중요한 결정

- **컴포넌트 이름.** 처음 만든 `LadybugCrawler`는 터레인 높이를 따랐다. 새 씬은 평평한 Plane이고 소녀도 같이 움직여야 한다. 그래서 `WaypointWalker`로 바꾸고 애니메이터 Bool 이름을 설정으로 뺐다. 높이는 점의 높이를 따른다.
- **소녀 시작 상태.** Girl 컨트롤러의 기본 상태는 `Sleep`이다. `Asleep`이 꺼져 있으면 12.6초짜리 `GetUp`부터 재생하고, 그동안 걸어가면 미끄러진다. 그래서 `startState`를 `Idle`로 두어 서 있는 상태로 바로 시작한다.
- **소녀 속도.** 게임의 `babyWalkSpeed`는 1.2 m/s다. "천천히"에 맞춰 0.6 m/s로 두었다. 걷기 애니메이션은 그대로라 발이 조금 미끄러질 수 있다.

## 펄럭이는 소리

사용자가 새가 없는데 펄럭이는 소리가 계속 난다고 했다. Play Mode에서 FMOD의 모든 이벤트 인스턴스를 확인했다. 재생 중인 것은 `event:/SFX/footstep_snow` 하나뿐이었다. 소녀 `Girl_Walk` 클립의 `Footstep` 이벤트(0초, 0.6초)가 `BabyAnimationEvents`를 거쳐 재생한다. FMOD 프로젝트에서 이 이벤트는 `footstep_snow_0 ~ 3.wav`를 쓴다. 새의 `event:/SFX/flap`은 `Bird_Flap` 클립에서만 나는데, 새를 넣기 전에는 씬에 없었다. 그래서 들린 소리는 소녀의 눈 발소리로 본다. 새를 넣은 뒤에도 `Hover` 클립에는 이벤트가 없어서 flap은 나지 않는다.
