# 무당벌레 모델과 Idle, Crawl 애니메이션

## 왜 했나

사용자가 게임잼에서 쓸 상호작용 생물로 간단한 무당벌레 모델을 원했다. 요청 범위는 블렌더로 만들어 FBX로 내보내고, Unity 임포트 설정과 프리팹까지 만들고, git 커밋은 하지 않는 것이다. 정한 조건은 다음과 같다.

- 애니메이션은 정지와 기어가기 두 개
- 크기는 토끼의 절반 정도
- 머티리얼은 단색

`sam` 브랜치에서는 아트 에셋을 임의로 만들지 않는다는 규칙이 있다. 이번 모델은 사용자가 직접 요청한 것이다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|

## 중요한 결정

- **크기.** 토끼 README에 따르면 어른 토끼 몸길이는 약 1.2 m이고, 게임에서도 Scale 1로 쓴다. 그래서 무당벌레는 모델 자체를 몸길이 약 0.6 m(더듬이까지 약 0.7 m), 높이 약 0.3 m로 만들고 프리팹 Scale은 1로 뒀다.
- **방향과 리그.** 토끼처럼 Unity +Z를 보도록 내보냈다. 리그는 Generic이고 루트 뼈는 `Root`, 애니메이션은 제자리다. 블렌더에서는 발을 IK로 움직였다. FBX에는 IK 결과만 구워 넣었고, 변형하지 않는 IK 뼈는 내보내지 않았다.
- **기어가기.** 삼각 보행으로 앞 L, 가운데 R, 뒤 L과 반대쪽 셋이 번갈아 딛는다. 한 주기는 0.8초이고, 디딘 발은 0.4초 동안 0.08 m 뒤로 간다. 그래서 **0.2 m/s**로 옮기면 발이 미끄러지지 않는다.
- **머티리얼.** 처음에는 `Pastel/WC_FlowerRed`(SoftPastel)를 복사한 `WC_Ladybug*` 머티리얼 3개를 만들어 다시 연결했다. 그런데 Main 씬에서 쓰는 수채화 머티리얼(`SoftPastel`, `WatercolorFlat`, `WatercolorLit`)이 아직 하나로 정해지지 않았다. 토끼와 새도 FBX 단색 머티리얼(URP Lit)을 그대로 쓴다. 그래서 다시 연결한 것을 되돌리고, 만든 머티리얼 3개도 지웠다. 지금은 FBX에 들어 있는 단색 머티리얼이다.

## 검증

| 무엇 | 결과 |

| 블렌더에서 FBX를 다시 임포트해 Crawl 프레임별 최저점 확인 | 모든 프레임에서 -0.002로, 발이 땅에서 뜨거나 묻히지 않는다 |
| 미리보기 렌더(블렌더 Workbench, Unity 미리보기 씬 카메라) | 앞, 위, 옆과 Crawl 0.2초 자세를 눈으로 확인했다 |

## 남은 것

- 원본 `Ladybug.blend`와 생성 스크립트 `build_ladybug.py`는 저장소에 넣지 않았다. 토끼 원본 `.blend`도 저장소 밖에 있다. 넣을지는 팀이 정한다.
- 무당벌레를 움직이는 스크립트와 상호작용, 씬 배치는 하지 않았다. 이동은 스크립트로 하고, 속도는 0.2 m/s에 맞춘다.
- 수채화 머티리얼이 정해지면 머티리얼 슬롯 3개를 다시 연결해야 한다.
