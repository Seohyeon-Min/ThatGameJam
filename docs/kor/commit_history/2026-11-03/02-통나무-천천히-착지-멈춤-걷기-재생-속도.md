# 통나무 위에서 천천히, 뛰어내린 뒤 잠깐 멈춤, 걷기 클립 속도를 이동 속도에 맞춤

## 왜 했나

사용자 피드백:

1. 아이의 걷기 애니메이션과 이동 속도가 맞지 않는다.
2. 걸을 때 팔이 움직이지 않는다.
3. 통나무를 건널 때는 더 조심해서 천천히 걸으면 좋겠다.
4. 통나무에서 내려온 뒤 잠깐 멈췄다가 걸어가면 좋겠다.

1 의 원인은 아트 노트(`Assets/01_Arts/Models/Girl/README_Animations_KO.md`)에 있다. 발이 미끄러지지 않는 속도가 Walk 약 0.1 m/s, BalanceWalk 약 0.05 m/s 다(모델 크기 1 기준). Main 의 아이는 크기 2 라 약 0.2 m/s, 0.1 m/s 다. 지금 걷는 속도는 0.9 m/s(`GameTuning.asset`)이고, 통나무 위에서도 같은 속도였다. 다리가 땅보다 4 ~ 9 배 느리게 움직인다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 통나무 위(BalanceWalk) 이동 속도를 따로 둔다. 기본 0.45 m/s(땅의 절반) | `GameTuning.babyBalanceWalkSpeed`, `Baby.StepToward` |
| 통나무 끝에서 땅으로 뛰어내린 뒤 `Idle` 로 0.8 초 서 있다가 걷는다. 통나무에 올라탈 때는 멈추지 않는다 | `GameTuning.babyLandPause`, `Baby.WakeAndWalk` |
| Walk 와 BalanceWalk 의 재생 속도(`animator.speed`)를 실제 이동 속도 ÷ "그 클립이 1 배로 도는 속도" 로 둔다. 0.5 ~ 2.5 배로 자른다. 걷기 속도의 흔들림(±15%)과 통나무 위 느린 걸음에 다리 속도가 같이 따라간다 | `GameTuning.babyWalkClipSpeed`(0.9), `babyBalanceClipSpeed`(0.45), `babyClipRateMin`/`Max`, `Baby.StepToward` |
| 서 있을 때(`StandStill`), 눕기, 잠들기, 잠든 채 옮기기에서는 재생 속도를 1 로 되돌린다. 일어나기·눕기·점프는 클립 길이로 시간을 재기 때문이다 | `Baby.StandStill`, `LieDown`, `Sleep`, `RestAt` |

기본값으로는 땅 위 걷기가 예전과 같다(0.9 m/s 에서 Walk 1 배). 통나무 위는 0.45 m/s 에 BalanceWalk 1 배라, 예전보다 걸음 박자는 같고 미끄러짐은 절반이다. `GameTuning.asset` 은 고치지 않았다. 새 값은 코드의 기본값을 쓴다.

## 중요한 결정

- 걷기 미끄러짐은 코드로 다 없앨 수 없다. 0.9 m/s 에서 미끄러지지 않으려면 Walk 를 약 4.5 배로 돌려야 해 다리가 너무 빨라진다. 그래서 재생 속도를 이동 속도에 연결하는 자리만 만들고, 기본값은 예전 모습 그대로 두었다. 근본 해결은 보폭이 큰 걷기 클립이다(아트 요청).
- 재생 속도는 Animator 컨트롤러의 상태 속도 파라미터가 아니라 `animator.speed` 로 바꾼다. 에디터가 열린 동안 컨트롤러 에셋을 고치지 않기 위해서다(`AGENTS.md`).

## 검증

이 기록을 쓴 세션에서는 Unity 를 실행할 수 없었다. 컴파일도 하지 않았다. 확인할 것:

| 무엇 | 확인할 것 |
|------|------|
| 컴파일 | 에러 0 |
| Main Play, Stage1 | 첫 통나무와 쓰러진 고목 위에서 땅보다 느리게 걷는다. 두 통나무 끝에서 뛰어내린 뒤 약 0.8 초 서 있다가 걷는다 |
| 다른 동작 | 일어나기, 눕기, 점프, 기다리기 자세가 예전 속도로 재생된다 |
| `VerifyStage1Logs.Play`, `Natural` | 통과 |
| 미끄러짐 조정 | Play 중 `GameTuning` 의 `babyWalkClipSpeed` 를 0.9 에서 낮추며 발을 본다. 다리가 너무 빨라지기 전의 값으로 정한다 |

## 남은 것

- 팔이 움직이지 않는 것: `Girl_Walk` 를 FBX 인스펙터 미리보기에서 재생해 본다. 미리보기에서도 팔이 가만히 있으면 클립 문제(아트 요청), 미리보기에서는 움직이는데 게임에서만 안 움직이면 코드나 컨트롤러 문제다. 확인 전이라 고치지 않았다.
- 아트 요청 후보: 0.9 m/s 정도에 맞는 보폭의 걷기, 팔 흔들기, 통나무 위 조심스러운 걷기.
- 통나무 착지점(01 기록의 `FixStage1LogLanding`)이 적용되지 않으면 첫 통나무의 점프가 여전히 4.9 m 다. 착지 멈춤은 그 뒤에 온다.
