# 새를 아트의 모델과 애니메이션으로 바꾼다

## 왜 했나

아트가 새 모델과 애니메이션 7개를 Unity 패키지(`Bird-Animated.unitypackage`)로 보냈다. 사용자가 이것을 넣고, 플레이어인 새의 회색 공을 바꾸기를 원했다. 써 보고 활공 중에도 2초마다 날갯짓을 한 번 넣기를 원했다.

## 중요한 결정

- 이동 중에는 활공, 제자리에 떠 있으면 날갯짓. 떠 있으려면 날개를 쳐야 하고, 활공은 움직일 때만 된다
- 활공 중 날갯짓은 Animator 의 상태 하나(`GlideFlap`)로 넣었다. 활공 클립이 2초 재생되면 날갯짓 한 번을 하고 활공으로 돌아간다. 코드는 바꾸지 않았다
- 앉음 판정 시간은 애니메이션 이벤트가 아니라 `GameTuning` 값으로 둔다. 이벤트에 묶으면 Animator 전환이 늦거나 끊길 때 새가 내려앉는 중에 멈춘다
- 크기는 처음 0.3 배(날개 폭 약 1.6)로 넣었으나 쿼터뷰에서 너무 작아 0.4 배(약 2.2)로 키웠다

## 검증

Play Mode 에서 코드로 새를 움직이고 Animator 상태를 읽었다. 화면은 캡처해 보고 지웠다. 실제 마우스로는 하지 않았다.

| 무엇 | 결과 |
|------|------|
| Import 결과 | Generic 아바타 유효, 클립 7개의 길이·반복·이벤트가 위 표와 같다. 재질은 모두 URP 기본 Lit(회색) |
| `script recompile`, 빌더 `Build`, `BuildFog` | 에러와 진단 없음 |
| z -1 에서 z 19 까지 날기 | 날갯짓 → 활공 → 2 초 뒤 날갯짓 한 번(0.8 초) → 활공 → 도착하자 날갯짓 |
| 고목에 앉기 | 도착 0.27 초 뒤 내려앉기를 재생하고 발이 꼭대기 눈 위에 놓였다. 1.2 초 뒤 고목이 쓰러지고 날아오르기 → 날갯짓 |
| 앉은 상태만 따로 50 초 | 대기 3종이 무작위로 바뀌었다. 발이 땅에 붙어 있었다 |
| 콘솔 | 경고와 에러 0 |
| 시험 뒤 정리 | Run In Background 원래대로, 캡처와 임시 파일 삭제 |

## 크로스 모델 리뷰

Codex. 정확성(전환 조건과 exit time, 멈출 수 있는 상태, Moving 깜빡임, 앉음 시간과 내려앉기 클립, Animator 가 없을 때의 null), 견고성, 보안 렌즈. 범위는 staged diff 의 `.cs` 파일.

| 지적 | 처리 |
|------|------|
| warn. Animator 가 연결되지 않은 씬에서 매 프레임 NullReferenceException | 기각. 새가 있는 씬은 두 시험 씬뿐이고 빌더가 Animator 를 연결한다. `Main.unity` 에는 아직 새가 없다 |
| warn. 비행 전환이 착지 전환보다 먼저 검사되어, 도착하는 순간 `Moving` 이 바뀌면 내려앉기가 늦게 시작된다 | 반영. 비행 전환 5개에 `Perched` 가 꺼져 있을 조건을 붙였다 |
| warn. 1.2 초는 도착부터 세어 `GripComplete` 와 어긋난다 | 기각. 위를 고친 뒤 내려앉기는 도착 직후(0.1 초 전환) 시작한다. 이벤트에 묶으면 전환이 끊길 때 새가 내려앉는 중에 멈춘다 |
| warn. 날아오르기의 `FootRelease` 전에 새가 움직인다 | 기각(뒤로 미룸). 남은 것에 적었다 |
| warn. 빌더가 컨트롤러를 지우고 다시 만들면 GUID 가 바뀌어 참조가 끊긴다 | 반영. 지우지 않고 그 자리에서 파라미터와 상태를 비우고 다시 채운다. GUID 가 그대로이고 상태 8개, 전환 23개만 남는 것을 확인했다 |

고친 뒤 다시 돌린 리뷰:

| 지적 | 처리 |
|------|------|
| warn. 비행 전환은 중간에 끊을 수 없어(`interruptionSource` 없음), 블렌드 중에 도착하면 내려앉기가 늦다 | 반영. 비행 전환은 도착 상태의 전환(내려앉기)이 끊을 수 있게 했다. 도착 0.27 초 뒤 내려앉기, 그 1.2 초 뒤 날아오르기 |
| warn. `FootRelease` (위와 같은 지적) | 기각. 위와 같은 이유 |

마지막 staged diff 의 확인 리뷰는 `LGTM - no blockers` 였다.

## 남은 것

- 재질이 없어 회색이다. 아트에게 재질이나 텍스처가 있는지 물어야 한다
- 날아오르기 동안에도 새가 바로 움직인다. 아트 안내는 `FootRelease`(0.367 초)부터 움직이라고 한다
- 울음 애니메이션이 없다. 울음은 아직 크기가 잠깐 커지는 임시 효과다
- 고목에서는 앉자마자 고목이 쓰러져 대기 동작이 보이지 않는다(Q5). 눈 쌓인 가지(스테이지 2)에서 보인다
- 크기와 활공 중 날갯짓 간격은 시험용 값이다
