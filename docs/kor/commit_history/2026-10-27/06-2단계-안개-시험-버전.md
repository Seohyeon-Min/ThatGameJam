## 중요한 결정

- 안개는 스테이지 1 과 떨어진 시험 씬 `Sam_Fog_Test` 에서 만들었다. 계획대로다. 같은 빌더 파일에 진입점을 하나 더 두었다
- 안개 격자와 셰이더는 감독 세션이 쓰고, 안개 구간의 논리는 코더 하위 에이전트 1명이 동시에 썼다
- 시험하면서 궤적 규칙 둘을 바꿨다
  - 처음에는 새가 아기 근처에 오면 언제나 궤적을 새로 시작했다. 그러면 걷는 아기 바로 앞에 새가 떠 있을 때 궤적이 계속 끊겨 아기가 출구 바로 앞에서 멈췄다. 이제 아기가 따라갈 궤적이 남아 있지 않을 때만 새로 시작한다
  - 새가 구간 끝에서 더 날아갈 수 없을 때도 아기를 출구까지 이끌도록, 가까이 떠 있는 새가 아기를 그 아래까지 데려간다. 처음에는 뒤쪽으로도 데려가서, 아기가 이전 카메라 구간으로 되돌아가 새의 이동 범위가 바뀌고 둘 다 멈췄다. 이제 출구 쪽일 때만 데려간다
- 자연 해결 때 아기가 정답 길의 뒤쪽 점으로 한 걸음 돌아가던 것을, 가장 가까운 구간의 끝 점으로 가게 바꿨다
- 안개가 너무 옅어 길과 바위가 비쳤다. 층의 불투명도를 0.35 에서 0.75 로 올리고 층을 조금 낮췄다

## 크로스 모델 리뷰

Codex 세 번. 렌즈는 정확성(궤적과 길의 기하, 인덱스, 아기가 출구에 못 가고 멈추는 상태), 견고성, WebGL 성능, URP 셰이더, 보안. 범위는 staged diff 의 `.cs` 와 `.shader`.

| 지적 | 처리 |
|------|------|
| blocker. 걸을 수 있는지를 목적지 점의 땅으로만 보아, 양 끝이 땅인 긴 구간이 물을 가로질러도 걷는다 | **반영.** 구간 전체를 0.25m 간격으로 땅을 확인한다 |
| blocker. 루프를 자를 때 교차 구간의 시작점에서 새 점으로 바로 이어 원래 궤적에 없던 지름길이 생긴다 | **반영.** 교차점을 계산해 그 점에서 잇는다 |
| warn. 자연 해결 앞머리가 프레임마다 원 하나만 걷어, 긴 프레임이면 원 사이에 안개가 남는다 | **반영.** 지난 위치부터 반지름의 절반 간격으로 걷는다 |
| warn. 되짚을 궤적에 안개 앞에서 멈춘 자리가 없어, 첫 점이 정답 길에서 멀면 물을 가로질러 합류할 수 있다 | **반영.** 기다리기 시작할 때 아기의 자리를 첫 점으로 넣는다 |
| warn. `pointSpacing` 이나 `clearRadius` 가 0 이하이면 반복문이 끝나지 않는다 | **반영.** 두 필드에 `[Min(0.1f)]` 를 붙였다 |
| warn (두 번). 정답 길이 비었거나 같은 점이 겹치면 자연 해결 뒤 멈추거나 0 으로 나눈다 | 기각. 정답 길은 레벨 데이터이고 언제나 점들과 출구가 있다. 빌더도 그렇게 만든다 |
| warn (두 번). 교차를 엄격하게만 판정해, 기존 점을 정확히 지나거나 같은 구간을 되짚는 루프는 잘리지 않는다 | 기각. 실수 좌표가 정확히 겹치는 일은 거의 없고, 생겨도 아기가 잠깐 되돌아갈 뿐 멈추지 않는다 |
| warn. 검사한 점을 목적지로만 기억해, 다시 이은 뒤 같은 점이 다른 출발점에서 나오면 검사를 건너뛴다 | 기각. 새의 실수 좌표가 정확히 같은 점이 다시 나오는 일은 거의 없다 |
| warn. `SphereCastAll` 이 검사마다 배열을 만든다 | 기각. 아기가 다음 점으로 갈 때만 검사한다. 초당 2~3번이다 |

마지막 `[Min]` 반영은 필드 속성만 바꾼 것이라 다시 리뷰하지 않았다.

## 남은 것

- 안개 모양은 회색 상자 수준이다. 투명한 판 4장을 쌓았다. 아트와 같이 다듬어야 한다
- 걷히는 폭(1.3), 다시 잇는 범위(1.5), 동물의 대답 범위(5)는 기획 미정 값이라 임시 값이다
- 동물의 울음 범위는 새와의 3D 거리로 잰다. 새의 비행 고도만큼 범위가 줄어든다
- 개발용 F3(새가 푼 것으로)은 안개에서는 타이머만 멈춘다. 안개는 F2 로 저절로 풀어야 한다
- 시험 중에 에디터가 연 씬 파일을 `git checkout` 으로 되돌려 에디터가 멈췄다. 사용자가 다시 불러오기 창을 눌러 풀었다. `AGENTS.md` 의 "에디터가 열려 있으면 씬 파일을 직접 고치지 않는다" 를 어긴 것이다
