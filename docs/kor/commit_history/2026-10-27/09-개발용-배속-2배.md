## 왜 했나

사용자가 F1 개발용 배속을 2배로 바꿔 달라고 했다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| `fastTimeScale` 기본값 4 → 2 | `Assets/02_Scripts/Flow/DevTools.cs` |
| 두 시험 씬에 저장된 값도 2 로. 에디터 API 로 바꿨다 | `Assets/00_Scenes/Sam_Test.unity`, `Sam_Fog_Test.unity` |
| 배속 문장 | `implementation_plan.md` 4.18 |

## 검증

| 무엇 | 결과 |
|------|------|
