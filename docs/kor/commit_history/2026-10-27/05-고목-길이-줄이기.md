# 기울어진 고목을 짧게 해서 꼭대기를 클릭하기 쉽게 함

## 왜 했나

사용자가 1-2 구간을 해 보니, 카메라가 고정이라 새가 앉아야 하는 고목 꼭대기가 화면 위쪽 끝에 있어 클릭하기 불편했다. 사용자가 고목 길이를 줄이라고 했다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 기울어진 고목 길이 5 → 3.4. 꼭대기 높이 약 5.3 → 약 3.8. 새의 비행 고도 2.5 와 가까워졌다 | `AgentScripts/BuildSamTestScene.cs` `LeaningLogLength` |
| 쓰러진 고목이 다리가 되도록 두 번째 개울 폭 4 → 2.5 (z 20 ~ 22.5). 건너편 둑과 아기의 길 점, 구간 1-2·1-3 의 경계를 그에 맞췄다 | 같은 파일 `BuildStage1` |
| 빌더로 씬을 다시 만들었다 | `Assets/00_Scenes/Sam_Test.unity` |

## 검증

| 무엇 | 결과 |
|------|------|
| 빌더 실행 | 진단 없음 |
| 구간 1-2 화면 | 고목 꼭대기가 화면 가운데 위쪽에 있다 |
| Play Mode, 새가 도운 경우 (가상 마우스) | 울음으로 깨움 → 고목 앞 `Waiting` → 고목 클릭 → 쓰러짐 → 고목 위로 건넘 → 스테이지 2 로 전환. 고목의 `OpenedByBird=True` |
| 콘솔 | 경고와 에러 0 |
