# 비교용 브랜치: 구간별 고정 카메라

## 왜 했나

사용자가 고정 카메라 버전과 새를 따라가는 카메라 버전을 팀원들에게 나란히 보여 주려고 한다. 고정 버전은 이 브랜치(`sam-fixed-camera`), 따라가는 버전은 `sam` 에 둔다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| `sam` 의 `95e482e` 에서 시작해, ADR 0005 의 카메라 코드만 되돌렸다(`743f27a` 되돌림). 빛나는 공간 위치(ADR 0006)와 2배속은 그대로다. 그래서 두 브랜치는 카메라만 다르다 | `Assets/02_Scripts/Flow/`, `Assets/02_Scripts/Bird/BirdController.cs` |
| 문서는 되돌리지 않았다. 이 브랜치의 문서는 `sam` 과 같고, 카메라 설명은 따라가는 버전 기준이다 | `docs/` |
| 빌더의 구간 카메라를 줄어든 스테이지 1 에 맞췄다. 1-1(z -2 ~ 13)과 1-2(z 13 ~ 27, 기울어진 고목과 빛나는 지점) 두 구간 | `AgentScripts/BuildSamTestScene.cs` |
| 두 시험 씬을 다시 만들었다 | `Assets/00_Scenes/Sam_Test.unity`, `Sam_Fog_Test.unity` |

## 검증

| 무엇 | 결과 |
|------|------|
| `script recompile`, 빌더 `Build`, `BuildFog` | 에러와 진단 없음 |
| Play Mode, 기다린 경우를 배속으로 | 고목 앞 `Waiting` 때 구간 1-2 카메라였다. 고목, 빛나는 지점이 한 화면에 보인다. 스테이지 2 로 넘어갔다 |
| 콘솔 | 경고와 에러 0 |

## 크로스 모델 리뷰

하지 않았다. 리뷰를 거친 이전 코드로 되돌린 것이고, 바뀐 것은 빌더의 구간 좌표뿐이다.
