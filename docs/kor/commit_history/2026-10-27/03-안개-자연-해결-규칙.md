# 안개 자연 해결 규칙을 정함 (ADR 0004)

## 왜 했나

사용자가 미정으로 남겼던 Q10 을 AI 의 제안대로 정했다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 결정과 버린 대안 | ADR 0004 |
| Q10 을 "남은 질문" 에서 "정한 것" 으로 옮겼다. 안개의 자연 해결 문장을 결정 문장으로 바꿨다 | `implementation_plan.md` 머리말, 4.12, 5장 |

## 검증

| 무엇 | 결과 |
|------|------|
| kor 와 eng 의 제목 줄 수와 표 줄 수 비교 | 같다 |
| `docs/` 안 상대 링크가 가리키는 파일이 있는지. 양식 예시 파일은 뺀다 | 깨진 링크 없음 |
