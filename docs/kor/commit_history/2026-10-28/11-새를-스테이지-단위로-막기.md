# 새를 스테이지 단위로 막는다. 지금 스테이지의 빛나는 공간까지만 간다 (ADR 0012)

## 왜 했나

디렉터 요청(Bird Boundary Interaction 수정). 장치 단위로 막던 것을 스테이지 단위로 바꾼다. 스테이지마다 있는 빛 기둥 너머로 이동하려 하면, 지금처럼 가까운 가지에 앉아 고개를 젓는다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 앞쪽 한계는 지금 스테이지의 빛나는 공간(아기 길의 마지막 점)의 Z. 장치는 새를 막지 않는다 | `Assets/02_Scripts/Flow/Stage.cs` (`BirdForwardLimit`), `Assets/02_Scripts/Flow/GameFlow.cs` |
| 장치마다 두던 한계선(`birdLimit`)과 빌더의 고목 한계선을 지웠다 | `Assets/02_Scripts/Core/PathBlocker.cs`, `AgentScripts/BuildSamTestScene.cs`, `Assets/00_Scenes/Sam_Test.unity` |
| 주석 | `Assets/02_Scripts/Bird/BirdController.cs`, `Assets/02_Scripts/Flow/BirdCamera.cs` |
| 결정과 버린 대안 | ADR 0012 |
| 새 범위와 거절 | `implementation_plan.md` 4.1, 4.6, 6.1 |

## 검증

Play Mode 에서 스크립트로 했다. 클릭은 `Click` 을 리플렉션으로, 실제 레이캐스트로 불렀다.

| 무엇 | 결과 |
|------|------|
| `script recompile`, 빌더 `Build` | 에러 0 |
| 고목이 서 있을 때 앞쪽 한계 | z 25(스테이지 1 의 빛나는 공간). 전에는 z 21 |
| 고목 너머 z 23 클릭 | 그리로 날아갔다 |
| 빛나는 공간 너머 z 26.5 클릭 | 가까운 가지(z 22.34)에 앉고, 다시 누르자 그 자리에서 `Refuse` |
| 콘솔 | 에러와 경고 0 |

## 크로스 모델 리뷰

Codex. 정확성(범위, 거절, 스테이지 전환), 보안, 견고성 렌즈. 범위는 `Assets/02_Scripts` 와 빌더의 diff.

| 지적 | 처리 |
|------|------|
| blocker. 고목의 카메라 구간이 잠기면 카메라가 z 18 이하에 머물고 새는 화면 안(±5)에 있어야 해서, 고목이 서 있는 동안 새는 z 23 까지만 가고 빛나는 공간(z 25)에 닿지 못한다 | 기각(사용자에게 물음). 카메라 구간 잠금은 따로 정한 디렉터의 요청이다 (ADR 0007, 0008, 아직 시험 중). 이 변경은 앞쪽 한계만 바꾼다. 잠금을 그대로 둘지는 사용자에게 묻는다 |

## 남은 것

- 고목의 카메라 구간이 잠겨 있는 동안 새는 z 23 에서 조용히 멈춘다. 카메라 구간을 그대로 둘지 정해야 한다
