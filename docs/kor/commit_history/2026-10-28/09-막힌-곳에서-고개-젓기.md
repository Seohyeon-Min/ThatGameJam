# 막힌 곳으로 가려 하면 새가 가까운 가지에 앉아 고개를 젓는다. 제자리 비행은 Hover (ADR 0011)

## 왜 했나

디렉터 요청(Bird Boundary Interaction). 투명벽 대신, 새가 진행할 수 없는 곳으로 가려 하면 근처 나뭇가지에 내려앉아 고개를 흔든다. 장치를 풀면 평소처럼 움직인다. 가지는 가장 가까운 가지 로직을 다시 써도 된다. 애니메이션은 프로젝트 폴더의 zip(`BirdUnity-Animations-...zip`)에 있다. 사용자는 제자리 비행도 새 `Bird_Hover` 로 바꿔 보고 정하기로 했다.

## 받은 것

zip 의 새 `Bird-Animated.fbx` 는 전의 클립 7개에 둘을 더했다. `Bird_Hover`(1.2초, 반복)와 `Bird_Refuse`(0.767초, 한 번). README 는 Refuse 가 앉은 대기 자세로 시작하고 끝나서 앉아 있을 때 언제든 끼울 수 있다고 한다. 같이 온 `unity_validation.txt` 는 포즈 이음새 오차 0 으로 통과했다.

## 검증

Play Mode 에서 스크립트로 했다. 클릭은 `Click` 을 리플렉션으로, 땅을 향한 실제 레이캐스트로 불렀다. 짧은 동작이라 시간을 0.1 ~ 0.2 배로 늦춰 봤다.

| 무엇 | 결과 |
|------|------|
| Import | 클립 9개. Hover 반복, Refuse 한 번, Landing·Takeoff 의 이벤트 그대로 |
| 시작 | 제자리에서 `Hover` |
| 한계선 앞(z 12) 클릭 | 평소처럼 날아갔다 |
| 앉은 채 한계선 너머(z 24) 클릭 | 그 자리에서 `Refuse` |
| 날고 있다가(z 15) z 24 클릭 | 가장 가까운 가지(z 15.96)로 가서 내려앉고 `Refuse` |
| 고목 꼭대기로 가던 중 z 24 클릭 | 고목을 버리고 가지(z 8.04)에 앉아 `Refuse`. 고목은 쓰러지지 않았다 |
| 고목 꼭대기에 내려앉는 중에 z 24 클릭 | 가지(z 18.78)로 옮겨 앉아 `Refuse`. 고목은 쓰러지지 않았다 |
| 콘솔 | 에러와 경고 0 |

## 크로스 모델 리뷰

Codex. 정확성(상태별 거절, 트리거, 전환 시간), 보안, 견고성 렌즈. 범위는 `Assets/02_Scripts` 와 `AgentScripts` 의 diff.

| 지적 | 처리 |
|------|------|
| warn. 앉을 곳으로 가던 중(`ToPerch`)에 한계선 너머를 누르면 원래 목적지(장치일 수도 있다)에 앉는다 | 반영. 가던 곳을 버리고 가장 가까운 가지를 다시 고른다. 가지가 없으면 그 자리에 멈춘다 |
| warn(확인 리뷰 1). 장치(고목 꼭대기)에 내려앉는 중에 한계선 너머를 누르면, 다 앉아 장치가 풀리고 고개 젓기도 취소된다 | 반영. 장치에 가거나 내려앉는 중이면 그것을 버리고 가지를 다시 고른다. 가지에 내려앉는 중이면 그대로 앉아 젓는다. 고목 꼭대기에 내려앉는 중에 눌러 확인했다. 가지로 옮겨 앉아 저었고 고목은 그대로였다 |
| warn. 전환에 `hasFixedDuration` 을 켜지 않아 0.3 이 초가 아니라 비율이다 | 기각. `AddTransition` 으로 만든 전환은 이미 켜져 있다. 만든 컨트롤러에서 읽어 확인했다 |

고친 뒤 두 번째 확인 리뷰는 `LGTM - no blockers` 였다.
