# AGENTS.md: "main 에는 팀 공용 파일만" 규칙 삭제

## 왜 했나

사용자가 `sam` 전체를 `main` 에 올리기로 했다(`411cc45`). 그러면 "`main`에는 팀 공용 파일만 올린다" 는 규칙과 맞지 않는다. 사용자가 이 규칙을 지우라고 했다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| git 절의 "`main`에는 팀 공용 파일만 올린다." 를 지웠다. "개인 작업은 각자 이름의 브랜치에서 한다" 는 남겼다 | `AGENTS.md` |

`sam` 에 커밋하고 `sam` 과 `main` 에 함께 올렸다.
