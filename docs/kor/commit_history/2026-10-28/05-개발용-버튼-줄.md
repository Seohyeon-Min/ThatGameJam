# 개발용 기능을 화면 위쪽 버튼 줄로, 배속은 1·2·3배

## 왜 했나

디렉터 요청(Stage Debug Controls). 지금 쓰는 개발용 기능(F1 ~ F4)을 게임 화면 안에서 버튼으로 쓰고 싶다. 배속은 누를 때마다 X1, X2, X3 으로 바뀐다. 버튼은 화면 위쪽에 두고, 마우스를 올리면 설명이 나온다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 화면 위쪽 가운데에 버튼 넷: 배속(`x1` → `x2` → `x3` → `x1`), `Natural`(저절로 풀기), `By bird`(새가 푼 것으로), `Next stage`. 마우스를 올리면 버튼 아래에 설명이 나온다. 아기 상태와 타이머 줄은 버튼 아래로 옮겼다 | `Assets/02_Scripts/Flow/DevTools.cs` |
| F1 ~ F4 는 그대로 둔다. 버튼과 같은 일을 한다. F1 도 1·2·3배를 돈다 | `DevTools.cs` |
| 버튼 줄 위의 좌클릭은 새를 움직이지 않는다 | `Assets/02_Scripts/Bird/BirdController.cs` |
| 배속과 개발용 도구 문장 | `implementation_plan.md` 4.18, 6.1 |

## 중요한 결정

- IMGUI(`OnGUI`)로 그린다. 이미 `DevTools` 가 `OnGUI` 로 상태를 그리고 있었다. 개발 빌드에서만 켜지는 도구라 Canvas, EventSystem, 폰트 에셋을 따로 만들지 않았다
- 글자는 영어다. 기본 폰트에는 한글이 없어 웹 빌드에서 한글이 보이지 않는다
- 키보드 단축키를 지우지 않았다. 디렉터는 버튼을 바랐고, 키를 없애 달라고 하지는 않았다

## 검증

Play Mode 에서 스크립트와 화면 캡처로 했다. 실제 마우스로는 하지 않았다.

| 무엇 | 결과 |
|------|------|
| `script recompile` | 에러 0 |
| 배속 함수를 네 번 부름 | x2, x3, x1, x2 |
| `DevTools.Covers`: 버튼 줄 가운데 / 화면 가운데 / 왼쪽 위 | true / false / false |
| 화면 캡처 | 위쪽 가운데에 `x1`, `Natural`, `By bird`, `Next stage` 버튼과 그 아래 `Walking -` |
| 콘솔 | 에러와 경고 0 |

마우스를 올렸을 때의 설명과 버튼 클릭은 실제 마우스가 있어야 보인다. 가상 마우스는 IMGUI 에 닿지 않는다.
