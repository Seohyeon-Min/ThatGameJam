# 길가 나무를 길 양쪽 두 줄로, 한 스테이지에는 일부 종류만

## 왜 했나

디렉터가 길을 가려도 카메라 쪽에도 나무를 두라고 했다. 사용자는 길 너머의 나무가 너무 많으니 길가에 있는 느낌으로만 두고, 한 스테이지에서 모든 종류를 보일 필요는 없다고 했다. 다른 종류는 다른 스테이지에서 쓴다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 길 건너편의 깊은 숲(11)을 길 양쪽 가장자리의 두 줄로 바꿨다. 줄은 길 가장자리(x ±5) 안쪽 0.4 부터 바깥 3.4 까지다. 카메라 쪽(+X)에도 둔다. 둑과 개울은 양쪽으로 4 씩 늘린다. `PlaceForest` 를 `PlaceRoadsideTrees` 로 바꾸고 X 범위를 여러 개 받는다 | `AgentScripts/BuildSamTestScene.cs` |
| 스테이지 1 은 8종 중 `Tree_1` ~ `Tree_5` 만 쓴다 | 같은 곳 |
| `Sam_Test` 만 다시 만들었다. 나무 56 그루, 양쪽 28 그루씩 | `Assets/00_Scenes/Sam_Test.unity` |
| 에디터가 `Tree_*.mat` 의 `_Color` 를 `_BaseColor` 와 맞췄다. 그대로 커밋한다 | `Assets/01_Arts/Materials/Test/` |
| 나무 줄 | `implementation_plan.md` 6.1 |

## 중요한 결정

- 카메라 쪽 나무는 길과 아기를 가린다. 디렉터가 받아들였다
- 이웃끼리 종류가 다르다는 규칙과 고정 시드는 그대로다
- 안개 맵(`Sam_Fog_Test.unity`)은 바꾸지 않았다

## 검증

에디터에서 빌더를 돌리고, Play Mode 의 카메라 화면을 찍어 보았다. 실제 마우스로는 하지 않았다.

| 무엇 | 결과 |
|------|------|
| 빌더 `Build` | 에러와 진단 없음 |
| 나무 수와 종류별 수 | 56 그루(양쪽 28). `Tree_1` ~ `Tree_5` 가 10 ~ 13 |
| 같은 종류끼리 가장 가까운 거리 | 2.72. 이웃 판정 거리(2.72 미만) 밖이다 |
| 아무 두 나무의 가장 가까운 거리 | 0.85. 줄기가 겹치지 않는다 |
| 시작 화면과 고목 구간 화면 | 길 양쪽에 나무 줄이 있다. 카메라 쪽 나무가 길 일부를 가린다. 고목 꼭대기는 보인다 |
| 콘솔 | 경고와 에러 0 |
