# 계절 단계 시스템과 디버그용 빨간 칠

## 왜 했나

디렉터 요청(Season Transition System). 아기가 빛나는 공간에서 잠들면 계절 단계가 오르는 공통 시스템을 만든다. `AdvanceSeason()`, `OnSeasonChanged(int stage)` 같은 함수와 이벤트를 두어 나중에 VFX 와 환경 변화 에셋을 붙인다. 지금은 에셋이 없으므로 실제 환경 변화는 넣지 않는다. 인스펙터에서 단계를 바꾸고 이벤트를 시험할 수 있어야 한다. 디버그로 주변 환경을 빨갛게 바꾸되, 나중에 뺄 수 있어야 한다.

## 검증

Play Mode 에서 스크립트와 화면 캡처로 했다.

| 무엇 | 결과 |
|------|------|
| `script recompile`, 빌더 `Build` | 에러와 경고 0 |
| 시작 | 단계 0, 칠 없음 |
| 개발용 건너뛰기 두 번 | 단계 1(땅이 옅은 분홍), 단계 2(더 빨강). 새와 아기에는 칠이 없다 |
| `SetSeason(0)`, `SetSeason(4)` | 칠이 사라졌다가 가장 진한 빨강 |
| `SeasonDebugTint` 끄기, 다시 켜기 | 칠이 사라졌다가 지금 단계로 돌아왔다 |
| 마지막 스테이지 뒤 건너뛰기를 더 누르기 | 단계가 2 에 머문다 |
| 화면 | 땅, 나무, 고목, 빛나는 공간이 빨갛고 새는 그대로 |

인스펙터 버튼은 직접 누르지 않았다. 같은 함수를 스크립트로 불렀다.

## 크로스 모델 리뷰

Codex. 정확성(계절이 오르는 때, 칠과 되돌리기), 보안, 견고성 렌즈. 범위는 `Assets/02_Scripts` 와 빌더의 diff.

| 지적 | 처리 |
|------|------|
| blocker. 이 Unity 에는 인자 없는 `FindObjectsByType<T>()` 가 없어 컴파일되지 않는다 | 기각. 6000.4 에 있고 경고 0 으로 컴파일된다. 오히려 `FindObjectsSortMode` 를 받는 쪽이 낡았다는 경고가 나서 바꾼 것이다 |
| warn. `Sam_Fog_Test` 의 `GameFlow` 에는 `Season` 이 없어 스테이지가 끝날 때 예외가 난다 | 기각. 안개 맵은 사용자 지시로 다시 만들지 않는다. 그 씬은 아기도 예전 캡슐이라 이미 동작하지 않는다 |
| warn. 마지막 스테이지 뒤에도 건너뛰기를 누를 때마다 계절이 오른다 | 반영. 마지막 스테이지가 끝나면 그 뒤의 끝남은 무시한다. 세 번 건너뛰어 단계 2 에 머무는 것을 확인했다 |
| warn. 다른 시스템의 property block 을 덮어쓰고 지운다 | 기각. 지금 property block 을 쓰는 곳이 없고, 이 칠은 디버그용이다 |
| warn. 껐다 켜면 다음 변화까지 칠이 돌아오지 않는다 | 반영. 켤 때 지금 단계로 다시 칠한다. 껐다 켜서 확인했다 |
