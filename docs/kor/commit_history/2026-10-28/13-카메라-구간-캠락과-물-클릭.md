# 카메라 구간: 트리거에 들어오면 잠그고 캠락 구간을 나가면 푼다. 물을 눌러도 새가 간다 (ADR 0014)

## 왜 했나

ADR 0012 로 새를 스테이지 단위로 막은 뒤, 고목의 카메라 구간이 잠기면 새가 z 23 에서 조용히 멈추는 문제를 사용자에게 물었다. 디렉터가 그림(`2.png`)과 함께 답했다. 멀리 날면 풀려야 한다. 트리거에 들어오면 잠기고, 캠락 구간을 빠져나오면 풀린다. 들어갈 때와 나갈 때 구간 크기가 다르다. 그리고 물 위치를 클릭해도 이동하게 한다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 카메라 구간: 트리거 띠 안에 들어오면 잠그고, 더 넓은 캠락 구간을 나가면 푼다. 장치가 안 풀렸으면 다시 들어올 때 또 잠근다. 장치가 풀리면 그만. 씬 뷰에 트리거(빨강), 캠락 구간(하늘색), 카메라 범위(자홍)를 그린다 | `Assets/02_Scripts/Flow/CameraZone.cs` |

## 검증

Play Mode 에서 스크립트로 했다.

| 무엇 | 결과 |
|------|------|
| `script recompile`, 빌더 `Build` | 에러 0 |
| 트리거(z 16)로 | 잠김 |
| 옆으로 멀리(x −20) | x −13.9 의 가지에 앉음, 풀림 |
| 다시 트리거로 | 잠김. 그 뒤 길가 가지(x −5.5)에 앉아도 잠긴 채 |
| 앞으로 멀리(z 30) | z 24.7 에서 풀림 |
| 오른쪽 멀리(x 20), 뒤로(z 0) | 둘 다 풀림 |
| 물(냇물 1)의 두 자리를 화면에서 클릭 | 맞은 것이 `Stream_1`, 수면의 그 자리(y −0.3)로 갔다 |
| 콘솔 | 에러와 경고 0 |

화면 밖 가지의 앉기 영역을 뚫고 가는 경우는 첫 조사에서 한 번 보였으나, 고친 뒤 같은 경우를 다시 만들어 확인하지는 않았다.

## 크로스 모델 리뷰

Codex. 정확성(잠금과 풀림, 다시 잠김, 클릭 판정), 보안, 견고성 렌즈. 범위는 `Assets/02_Scripts` 와 빌더의 diff.

| 지적 | 처리 |
|------|------|
| warn. 다시 만들지 않은 `Sam_Fog_Test` 에도 새 로직이 쓰이는데, 기본 캠락 구간이 그 씬의 트리거를 덮지 않아 잠금과 풀림이 매 프레임 되풀이된다 | 기각. 안개 맵은 사용자 지시로 다시 만들지 않는다. 그 씬은 아기가 예전 캡슐이라 이미 지금 코드로 동작하지 않는다. 빌더의 안개 구간 값은 새 방식에 맞췄다 |
| warn. 지금 위치만 보므로, 속도 6 에서 한 프레임이 0.17 초를 넘으면 깊이 1 의 트리거 띠를 건너뛸 수 있다 | 반영(간단히). 띠의 깊이를 2 로 늘렸다. 0.33 초 프레임까지 건너뛰지 않는다. 지난 위치에서 지금 위치까지의 선분 검사는 코드 값어치가 없다고 봤다 |

고친 뒤 확인 리뷰는 `LGTM - no blockers` 였다.

## 남은 것

- 트리거 띠를 옆(x ±8 밖)으로 돌아가면 잠기지 않는다
- 실제 마우스로 물 클릭과 잠금, 풀림을 확인한다
