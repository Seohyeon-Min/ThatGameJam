# 거절은 새가 막힌 선에 닿았을 때 (ADR 0016)

## 왜 했나

사용자 요청. 거절(가까운 가지에 앉아 고개 젓기)을 누른 자리 기준으로 하지 말고, 새가 거절하는 선에 닿았을 때 하기로 했다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 클릭과 끌기에서 선 너머인지 보던 것을 없앴다. 새는 누른 곳을 향해 평소처럼 날고(범위와 화면 안으로 잘린 채), 목표가 선 너머인 채로 선(날 수 있는 범위의 앞 끝)에 닿으면 거절한다 | `Assets/02_Scripts/Bird/BirdController.cs` (`Fly`, `Refuse`) |
| 거절은 날고 있을 때만 일어나므로, 앉아 있을 때와 내려앉는 중의 경우를 지웠다 | `BirdController.cs` (`Refuse`) |
| 결정과 버린 대안 | ADR 0016 |
| 새 조작 | `implementation_plan.md` 4.1, 6.1 |

## 검증

Play Mode 에서 스크립트로 했다. 클릭은 `Click` 을 리플렉션으로, 실제 레이캐스트로 불렀다.

| 무엇 | 결과 |
|------|------|
| `script recompile` | 에러 0 |
| 가지에 앉아 있다가 빛나는 공간 너머(z 30) 클릭 | 날아올라 z 24.6 까지 날아간 뒤 가까운 가지(z 24.66)에 앉아 `Refuse` |
| 콘솔 | 에러와 경고 0 |

## 크로스 모델 리뷰

Codex. 정확성(거절 시점, 끌기, 상태), 보안, 견고성 렌즈. 범위는 `Assets/02_Scripts` 의 diff. 결과는 `LGTM - no blockers` 였다.
