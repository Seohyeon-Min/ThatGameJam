# 길가 나무: 색으로 나눈 8종, 잎 없는 줄기, 빽빽한 무작위 숲

## 왜 했나

디렉터가 길가 나무를 7 ~ 8 종으로 하고, 사용자가 올린 참고 그림처럼 빽빽하게, 무작위로 배치하라고 했다. 사용자는 한 나무 옆에 다른 종류의 나무를 두고, 지금은 종류를 색으로 나누고, 동그란 잎은 없애자고 했다. 안개 맵에는 이번에도 적용하지 않는다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| `Tree.prefab`(줄기와 동그란 잎)을 지우고 나무 8종 `Tree_1` ~ `Tree_8` 을 만든다. 잎 없는 긴 줄기(높이 10, 굵기 0.35)이고 색만 다르다. 머티리얼 `Tree_1` ~ `Tree_8` 을 새로 만들고 `Leaves.mat` 을 지웠다 | `Assets/03_Prefabs/Trees/`, `Assets/01_Arts/Materials/Test/` |
| 스테이지 1 의 길 건너편(-X)에 숲을 둔다. 둑과 개울을 그쪽으로 11 더 늘리고, 둑 위(개울 제외)에 간격 1.7 의 격자에서 조금씩 흔든 자리에 나무를 놓는다. 이웃(2.72 안)과 같은 종류는 고르지 않는다. 굵기 0.8 ~ 1.4 배, 높이 0.8 ~ 1.2 배를 무작위로 준다. 시드는 고정이라 다시 만들어도 같은 숲이다 | `AgentScripts/BuildSamTestScene.cs` |
| `Sam_Test` 만 다시 만들었다. 나무 98 그루 | `Assets/00_Scenes/Sam_Test.unity` |
| 나무 줄 | `implementation_plan.md` 2장, 6.1 |

## 중요한 결정

- 나무는 지금처럼 길 건너편에만 둔다. 카메라 쪽(+X)에 두면 길을 가린다
- 종류마다 프리팹을 따로 둔다. 아트의 나무 모델이 오면 프리팹 안의 줄기만 바꾸면 된다
- 줄기 굵기와 높이는 한 그루마다 조금씩 다르다. 종류의 구분은 색만으로 한다
- 스테이지 2(전환 확인용 임시 스테이지)에는 나무를 두지 않았다
- 안개 맵(`Sam_Fog_Test.unity`)은 바꾸지 않았다. 안개 빌더는 나무를 쓰지 않고, 빌더의 `Ground`, `Water` 는 새 인자의 기본값으로 예전과 같다
- 빌더를 돌리면 바뀌는 `Bird.controller`(내부 ID)와 `ClickMarker.mat`, `RestLight.mat` 은 커밋하지 않았다

## 검증

에디터에서 빌더를 돌리고, Play Mode 의 카메라 화면을 찍어 보았다. 실제 마우스로는 하지 않았다.

| 무엇 | 결과 |
|------|------|
| 빌더 `Build` | 에러와 진단 없음 |
| 나무 수와 종류별 수 | 98 그루. 종류별 9 ~ 14 |
| 같은 종류끼리 가장 가까운 거리 | 2.81. 이웃 판정 거리 2.72 보다 멀다 |
| 아무 두 나무의 가장 가까운 거리 | 0.80. 줄기가 겹치지 않는다(가장 굵은 줄기 0.49) |
| 시작 화면과 고목 구간 화면 | 길 건너편이 빽빽한 숲이다. 아기, 새, 고목을 가리지 않는다 |
| 콘솔 | 경고와 에러 0 |
