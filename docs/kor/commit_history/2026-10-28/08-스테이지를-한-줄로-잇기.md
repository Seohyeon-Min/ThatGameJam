# 스테이지를 한 줄의 길로 잇고 순간이동을 없앤다. 새는 다음 장치까지만 간다 (ADR 0010)

## 왜 했나

디렉터 요청(Seamless World Layout). 한 씬 안에서 스테이지별 맵을 실제 땅으로 길게 잇고, 순간이동 없이 다음 구간으로 넘어간다. 각 스테이지는 따로 루트 오브젝트로 둔다. 새의 이동 범위는 구역에 맞춰 막고, 스테이지를 깨면 풀어 준다. 디렉터가 말한 메인 씬의 긴 맵은 아직 어느 브랜치에도 없어서, 사용자와 정해 `Sam_Test` 에서 먼저 잇고 나중에 옮긴다.

## 크로스 모델 리뷰

Codex. 정확성(범위, 스테이지 시작, 건너뛰기), 보안, 견고성 렌즈. 범위는 `Assets/02_Scripts` 와 빌더의 diff.

| 지적 | 처리 |
|------|------|
| warn. 앉는 범위에는 앞쪽 한계가 없어, 새가 닫힌 장치 너머나 아직 안 열린 스테이지의 나무에 앉을 수 있다 | 반영. 앉는 범위의 Z 를 날 수 있는 범위로 자른다. X 는 화면 전체 그대로 |
| warn. 마지막 스테이지에서 건너뛰면 깨우기 타이머가 다시 돌아, 아기가 깨어 길을 다시 걷고 계절 연출이 되풀이된다 | 반영. 건너뛰기는 `RestAt` 으로 아기를 쉬는 상태로만 둔다. 다음 스테이지가 있을 때만 `Sleep` 으로 타이머를 돌린다 |
| warn. 카메라 구간이 잠겨 있으면 새가 뒤로도 멀리 못 간다 | 기각. 새는 화면 밖으로 나가지 않는다(ADR 0007, 0008). "뒤로는 늘 간다" 는 뒤에 한계선이 없다는 뜻이다 |

고친 뒤 확인 리뷰는 `LGTM - no blockers` 였다.

## 남은 것

- 디렉터의 메인 맵이 올라오면 스테이지 시작점, 범위, 한계선을 그 맵에 맞춰 옮긴다
- 스테이지 2 는 아직 걷기만 하는 임시 구간이다
