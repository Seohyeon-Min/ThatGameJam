# 아기를 아트의 소녀 모델과 애니메이션으로

## 왜 했나

디렉터 요청(Implement - Girl Animations). 프로젝트 폴더의 `NPC-GirlUnity-Animations-...zip` 을 풀어 아기 모델을 넣고, 그 안의 README 와 지금까지의 게임 흐름에 맞춰 애니메이션을 넣는다. 끝나면 zip 을 지운다.

## 받은 것

zip 안에는 `NPC-Girl-Animated.fbx`(메시, 리그, 클립 9개, 내장 텍스처 7장, 눈 깜빡임·꽃 블렌드셰이프), `clips.json`, `README_KO.md` 가 있었다. README 의 요점:

- 클립(30 FPS, 모두 제자리): `Girl_Walk` 1.2 초, `Girl_Run` 0.667 초, `Girl_Idle_Breathing` 4 초, `Girl_Idle_LookAround` 8 초, `Girl_Idle_Hum` 6 초, `Girl_Idle_Stretch` 8 초, `Girl_Sleep` 3 초(이상 반복), `Girl_LieDown` 7.267 초, `Girl_GetUp` 12.567 초
- 흐름: Idle/Walk/Run → LieDown → Sleep(반복) → GetUp → Idle. 이어지는 포즈가 정확히 같다
- Generic 리그, 이 모델로 아바타. 앞은 Blender +X. 발이 미끄러지지 않는 속도는 Walk 약 0.1 m/s, Run 약 0.59 m/s

## 중요한 결정

- 모델의 방향은 리그로 확인했다. 두 발이 Z 로 나란하고 X 로 움직이며, 머리카락이 머리보다 +X 쪽이라 얼굴은 -X 다. 화면으로도 걸어가는 쪽을 보는 것을 확인했다
- 클립이 없는 자세(쪼그려 앉기, 앉아 쉬기, 올려다보기)는 서서 숨쉬기로 둔다. 회색 캡슐 때의 기울이기 흉내는 지웠다. 잠든 동안 대기 신호에 맞춰 흔들던 것도 같이 없어졌다
- `Girl_Run` 은 쓰지 않는다. 아기는 걷기만 한다
- 걷는 속도(1.2 m/s)와 걷기 재생 속도는 바꾸지 않았다. 발이 미끄러진다(남은 것)
- 일어나기는 잘라 내지 않고 끝까지 재생한다. 아트가 만든 길이 그대로다
- README 와 `clips.json` 은 `Assets` 에 넣지 않았다. 필요한 내용은 이 기록에 옮겼다
- `Sam_Fog_Test` 는 다시 만들지 않았다(사용자 지시: 안개 맵은 기본 사항이 정해질 때까지 다시 만들지 않는다)

## 남은 것

- 발이 미끄러진다. 걷기 클립은 보폭이 작아 미끄러지지 않는 속도가 약 0.1 m/s(이 크기로 0.08 m/s)다. 아기는 1.2 m/s 로 걷는다. 아트에게 보폭이 큰 걷기를 받거나 걷는 속도를 다시 정해야 한다
- 깨어날 때마다 일어나기 12.6 초를 기다린다. 4번이면 약 50 초가 플레이타임에 더해진다
- 클립이 없는 것: 쪼그려 앉기(토끼), 앉아 쉬기(쉼돌), 대기 신호 3단계(뒤척임, 눈 비비기, 기지개), 올려다보기, 들여다보기, 바라보기
- `Sam_Fog_Test` 의 아기는 예전 캡슐이라 지금 코드로는 동작하지 않는다. 안개 맵을 다시 만들 때 바뀐다
