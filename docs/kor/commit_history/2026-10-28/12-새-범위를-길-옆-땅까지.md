# 새가 다니는 범위를 길 옆 땅까지 넓히고, 땅과 나무를 늘린다 (ADR 0013)

## 왜 했나

디렉터 요청(새가 다닐 수 있는 공간 확장). 그림(`image.png`)의 초록 사각형처럼 새가 돌아다닐 공간을 넓힌다. 땅을 늘리고, 나무를 더 두고, 나무 사이로도 다닐 수 있게 한다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 새의 범위(`Stage.area`)를 길(x ±5)에서 길과 그 옆 땅(x ±13)으로 | `AgentScripts/BuildSamTestScene.cs`, `Assets/02_Scripts/Flow/Stage.cs`(주석) |
| 땅과 냇물을 x ±22 까지 넓힘 | 빌더 |
| 나무 두 겹: 길가 두 줄(간격 1.7, 시드 1, 전과 같은 설정)과 그 바깥 땅의 듬성한 나무(간격 3.2, 시드 2). 스테이지마다 `TreeGenerator` 둘 | 빌더 (`Forest`, `Trees`) |
| `Sam_Test` 다시 만듦 | `Assets/00_Scenes/Sam_Test.unity` |
| 주석 | `Assets/02_Scripts/Flow/BirdCamera.cs` |
| 결정과 버린 대안 | ADR 0013 |
| 새 범위, 나무 | `implementation_plan.md` 4.1, 4.6, 6.1 |

## 검증

| 무엇 | 결과 |
|------|------|

| 화면 | 범위 끝에서는 카메라 가장자리에 땅의 끝이 조금 보인다 |
| 콘솔 | 에러와 경고 0 |

## 크로스 모델 리뷰

Codex. 정확성(범위, 나무 배치), 보안, 견고성 렌즈. 범위는 `Assets/02_Scripts` 와 빌더의 diff. 결과는 `LGTM - no blockers` 였다.

## 남은 것

- 나무와 렌더러가 많이 늘었다. 웹 빌드에서 성능을 본다
- 범위 끝에서 땅의 끝이 보이면 땅을 더 넓히거나 범위를 줄인다
