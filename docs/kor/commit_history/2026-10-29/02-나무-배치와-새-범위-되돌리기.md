# 나무 배치와 새의 범위를 되돌린다 (ADR 0020)

## 왜 했나

사용자가 나무를 너무 많이 깔았다고 보고(터레인 전체 1645 그루), 범위의 폭과 나무를 일단 이전으로 되돌리라고 했다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 새의 범위 x ±25 → ±13 | 빌더 `BirdAreaHalfWidth` |
| 나무를 다시 스테이지마다: 스테이지의 Z 범위에서 냇물을 뺀 곳에, 길가 두 줄과 x ±21.4 까지의 듬성한 나무. 인트로에도. 출발점 뒤 길 위의 나무는 없앴다 | 빌더 `Forest`, `ForestWidth`. 생성기는 각 스테이지 루트 아래 |
| 터레인은 그대로다. 범위가 줄어 넓이가 약 99 × 140 m 로 줄었다 | `Assets/04_Data/SamTestTerrain.asset`, `Sam_Test` |
| 결정과 계획 | ADR 0020, `implementation_plan.md` 3.3, 4.1, 4.6, 6.1 |

토미의 나무 모델, 인트로, 눈은 바꾸지 않았다.

## 검증

| 무엇 | 결과 |
|------|------|
| 빌더 `Build` | 에러 0. 나무 280 그루(스테이지 1·2 는 이전과 같은 168, 인트로 112), 렌더러 1688 |
| Play: 시작, 새를 (−13, −10), (13, 10) 으로 | 길 양쪽에만 숲이 있고, 그 너머는 눈밭이다. 터레인의 끝은 보이지 않았다 |
| 눈의 `wind` | `World/Snowfall` 의 `autoRegenerate` 가 켜져 있어, 인스펙터에서 바꾸면 `OnValidate` 가 설정을 다시 넣는다 |

## 크로스 모델 리뷰

Codex. 정확성(냇물로 나눈 Z 범위, 범위), 보안, 견고성 렌즈. 범위는 빌더의 diff. 결과는 `LGTM - no blockers` 였다.
