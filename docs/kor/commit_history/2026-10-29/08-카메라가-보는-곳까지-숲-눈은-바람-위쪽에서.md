# 카메라가 볼 수 있는 곳까지 숲, 눈은 바람 위쪽에서 (ADR 0024)

## 왜 했나

사용자 보고. 가장 앞쪽까지 가면 화면 위쪽에 나무가 없다. 인트로에서 가장 아래나 위로 가면 눈발이 덜 보인다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 숲의 왼쪽·오른쪽 끝, 출발점 뒤, 마지막 스테이지 너머(`TreesAhead`)를 카메라가 볼 수 있는 곳 + 3 m(`ForestPastView`)로. 나무 471 → 1089 | 빌더 `BuildWorld`, `Forest`(좌우 끝을 받는다) |
| 눈 상자를 바람이 불어오는 쪽으로(가장 느린·빠른 눈송이), 길 방향 앞뒤 8 m(`SnowMoveMargin`) 더. 1 m² 당 1.5 → 0.9 | 빌더 `Snow`, `SnowPerSquareMetre` |
| 결정과 계획 | ADR 0024, `implementation_plan.md` 3.3, 4.9, 6.1 |

## 검증

화면 안의 눈은 눈송이를 카메라 화면에 투영해 화면 안이고 땅 위인 것만 셌다. 화면을 3 × 3 칸으로 나눠 칸마다도 셌다.

| 무엇 | 전 | 후 |
|------|------|------|
| 화면 안의 눈, 가운데에서 멈춰 있을 때 | 약 1470 | 약 2730 |
| 아래 끝으로 간 직후 | — | 약 2720 |
| 위 끝으로 간 직후 | 약 270(순간이동 1 초 뒤) | 약 2810 |
| 화면 위 줄 / 가운데 줄 / 아래 줄(가운데에서) | 약 260 / 140 / 85 | 약 660 / 180 / 65 |
| 눈송이 전체 | 약 3 만 | 약 5.5 만 |
| 에디터 FPS | 약 130 | 약 113 |

| 무엇 | 결과 |
|------|------|
| 빌더 `Build` | 에러 0. 나무 1089 |
| 스테이지 2 의 가장 앞(z 38.5)에서 x 0, −19.5, 19.5 | 화면 위쪽까지 숲이 차 있다 |
