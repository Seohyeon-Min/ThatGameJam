# 눈은 바람 값만, 숲을 x ±33 까지 (ADR 0022)

## 왜 했나

사용자 지시. 작업 기록 03 에서 바람 값을 넣으며 눈 상자, 양, 수명까지 바꾼 것은 사용자의 의도가 아니었다. 바람 값만 넣고 다른 것은 건드리지 말라고 했다. 숲도 넓히라고 했다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 눈 상자(카메라가 보는 땅), 1 m² 당 1.5, 수명 11 초를 작업 기록 02 때로 되돌림. 바람만 (0.5, −5) | 빌더 `Snow`, `SnowWind`, `SnowPerSquareMetre` |
| 숲 x ±21.4 → 약 ±32.4(`ForestWidth` 17 → 28). 나무 345 → 471 그루 | 빌더 `ForestWidth` |
| 결정과 계획 | ADR 0022, `implementation_plan.md` 3.3, 4.9, 6.1 |

새의 범위(x ±19.5)와 출발점 뒤 나무는 그대로다.

## 검증

| 무엇 | 결과 |
|------|------|
| 빌더 `Build` | 에러 0. 나무 471, 눈 상자 53 × 34 m, 초당 약 2720 개, 수명 11 초, 바람 (0.5, −5) |
| Play: 시작 화면 | 눈송이 약 3 만 개, 에디터 약 130 FPS. 화면 위쪽 가운데에 디버그 버튼 줄이 보인다 |
| 새를 (−19.5, −15), (19.5, −15) 로 | 범위 끝에서도 숲이 화면을 채운다 |

## 크로스 모델 리뷰
