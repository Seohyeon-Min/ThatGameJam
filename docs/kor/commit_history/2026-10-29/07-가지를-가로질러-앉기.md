# 길가 나무 가지에 앉을 때 가지를 가로질러 앉는다 (ADR 0023)

## 왜 했나

사용자 지시. 앉을 때 가지 방향에 맞춘다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| `Perchable.alignBird`: 켜져 있으면 새가 착지하는 동안 앉는 자리의 forward 축을 따라 돈다(날아온 방향에 가까운 쪽) | `Assets/02_Scripts/Core/Perchable.cs` |
| 착지 시작 때의 방향에서 목표 방향으로, 착지 시간(`birdPerchDuration`) 동안 Slerp | `Assets/02_Scripts/Bird/BirdController.cs` (`FlyToPerch`, `Land`, `AlongPerch`) |
| 나무마다 가지가 줄기 바깥으로 뻗는 방향(1번 −167°, 2번 −40°, 3번 65°). 앉는 자리의 forward 는 그와 직각. 나무 프리팹의 `alignBird` 켬 | 빌더 `TreeModels`, `SaveTree`, `Assets/03_Prefabs/Trees` |
| 결정과 계획 | ADR 0023, `implementation_plan.md` 4.1 |

가지 방향은 앉는 자리 주변 가지 윗면을 레이로 찍어 구한 주성분 방향과 줄기에서 바깥 방향을 둘 다 그려 보고 골랐다. 1·2번은 둘이 같았고, 3번은 점이 적어 주성분이 틀어져 줄기 바깥 방향을 썼다.

## 검증

| 무엇 | 결과 |
|------|------|
| `script recompile`, 빌더 `Build` | 에러 0 |
| Play: 세 종류에 두 방향에서 날아와 앉힘(6번) | 모두 새의 앞 방향이 가지와 직각이다(앉는 자리 forward 와의 내적 ±1.00). 앞에서 찍으면 발이 가지를 가로질러 잡고 있다 |

## 크로스 모델 리뷰

Codex. 정확성, 보안, 견고성 렌즈. 범위는 `Perchable`, `BirdController`, 빌더의 diff.

| 등급 | 지적 | 처리 |
|------|------|------|
| warn | `birdPerchDuration` 이 0 이하면 보간값이 0 이나 NaN 이 된다 | **기각.** 이 값은 착지 클립에서 발이 가지를 잡는 시간(1.2 초)이다. 0 이하로 둘 일이 없고, 없는 경우를 막는 코드는 넣지 않는다 |
