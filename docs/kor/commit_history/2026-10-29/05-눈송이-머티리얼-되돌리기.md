# 눈송이 머티리얼과 텍스처를 되돌린다

## 왜 했나

사용자 지시. 눈송이 머티리얼과 텍스처는 나중에 아트가 만든다. 작업 기록 01 에서 빌더가 만들게 한 것을 되돌린다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 빌더가 눈송이 텍스처와 머티리얼을 만들어 `Snowfall` 에 넣던 것을 뺐다. `Mat` 의 셰이더 인자도 이것 때문에 더했던 것이라 뺐다 | 빌더 `Snow`, `Mat` |
| `Snowflake.mat`, `Snowflake.png` 삭제 | `Assets/01_Arts/Materials/Test` |
| 계획의 남은 일 | `implementation_plan.md` 6.1 |

눈의 다른 값(크기 0.26, 양, 수명, 바람)은 바꾸지 않았다.

## 검증

| 무엇 | 결과 |
|------|------|
| 빌더 `Build` | 에러 0 |
| Play | 눈이 `Snowfall` 이 만든 머티리얼(`Sprites/Default`)로 내린다. 눈송이 약 3 만 개 |

## 크로스 모델 리뷰

Codex. 정확성, 보안, 견고성 렌즈. 범위는 빌더의 diff. 결과는 `LGTM - no blockers` 였다.

- `Snowfall` 이 만드는 머티리얼은 에디터에서만 생기고 저장되지 않는다. 아트의 머티리얼이 오기 전에 웹 빌드를 하면 눈이 보이지 않을 수 있다
